## 9. 搜索命令模板

在仓库根目录使用：

```bash
rg -n "函数名" init kernel mm fs arch/x86 include
rg -n "trace_sched_process_(fork|exec|exit)" kernel fs
rg -n "CLONE_(VM|FILES|FS|SIGHAND|THREAD|VFORK)" kernel/fork.c include
rg -n "TASK_(NEW|RUNNING|INTERRUPTIBLE|UNINTERRUPTIBLE)" kernel include
```

读宏时先 `rg` 定义，再看当前架构展开路径；不要靠函数名猜测实际语义。
