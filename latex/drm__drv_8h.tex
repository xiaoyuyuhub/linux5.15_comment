This allocates and initialize a new D\+RM device. No device registration is done. Call \mbox{\hyperlink{drm__drv_8h_aa400aa845e16d611d6db9ee0e7e6726e}{drm\+\_\+dev\+\_\+register()}} to advertice the device to user space and register it with other core subsystems. This should be done last in the device initialization sequence to make sure userspace can\textquotesingle{}t access an inconsistent state.

\mbox{\hyperlink{classThe}{The}} initial ref-\/count of the object is 1. Use \mbox{\hyperlink{drm__drv_8h_a418367d57acc44a5ada58e66043d5c23}{drm\+\_\+dev\+\_\+get()}} and \mbox{\hyperlink{drm__drv_8h_a5b0c8887bb312b86a1a98a450af7d507}{drm\+\_\+dev\+\_\+put()}} to take and drop further ref-\/counts.

It is recommended that drivers embed \&struct \mbox{\hyperlink{structdrm__device}{drm\+\_\+device}} into their own device structure.

Note that this manages the lifetime of the resulting \&\mbox{\hyperlink{structdrm__device}{drm\+\_\+device}} automatically using devres. \mbox{\hyperlink{classThe}{The}} D\+RM device initialized with this function is automatically put on driver detach using \mbox{\hyperlink{drm__drv_8h_a5b0c8887bb312b86a1a98a450af7d507}{drm\+\_\+dev\+\_\+put()}}.
