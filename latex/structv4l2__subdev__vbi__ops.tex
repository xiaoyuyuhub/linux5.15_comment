\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structv4l2__subdev__vbi__ops}{v4l2\+\_\+subdev\+\_\+vbi\+\_\+ops}} -\/ Callbacks used when v4l device was opened in video mode via the vbi device node.

@decode\+\_\+vbi\+\_\+line\+: video decoders that support sliced V\+BI need to implement this ioctl. Field p of the \&struct \mbox{\hyperlink{structv4l2__decode__vbi__line}{v4l2\+\_\+decode\+\_\+vbi\+\_\+line}} is set to the start of the V\+BI data that was generated by the decoder. \mbox{\hyperlink{classThe}{The}} driver then parses the sliced V\+BI data and sets the other fields in the struct accordingly. \mbox{\hyperlink{classThe}{The}} pointer p is updated to point to the start of the payload which can be copied verbatim into the data field of the \&struct \mbox{\hyperlink{structv4l2__sliced__vbi__data}{v4l2\+\_\+sliced\+\_\+vbi\+\_\+data}}. If no valid V\+BI data was found, then the type field is set to 0 on return.

@s\+\_\+vbi\+\_\+data\+: used to generate V\+BI signals on a video signal. \&struct \mbox{\hyperlink{structv4l2__sliced__vbi__data}{v4l2\+\_\+sliced\+\_\+vbi\+\_\+data}} is filled with the data packets that should be output. Note that if you set the line field to 0, then that V\+BI signal is disabled. If no valid V\+BI data was found, then the type field is set to 0 on return.

@g\+\_\+vbi\+\_\+data\+: used to obtain the sliced V\+BI packet from a readback register. Not all video decoders support this. If no data is available because the readback register \mbox{\hyperlink{protocolcontains-p}{contains}} invalid or erroneous data \%-\/E\+IO is returned. Note that you must fill in the \textquotesingle{}id\textquotesingle{} member and the \textquotesingle{}field\textquotesingle{} member (to determine whether CC data from the first or second field should be obtained).

@g\+\_\+sliced\+\_\+vbi\+\_\+cap\+: callback for \mbox{\hyperlink{uapi_2linux_2videodev2_8h_a4e4fed6848ef553c3e01fc6a220bc566}{V\+I\+D\+I\+O\+C\+\_\+\+G\+\_\+\+S\+L\+I\+C\+E\+D\+\_\+\+V\+B\+I\+\_\+\+C\+A\+P()}} ioctl handler code.

@s\+\_\+raw\+\_\+fmt\+: setup the video encoder/decoder for raw V\+BI.

@g\+\_\+sliced\+\_\+fmt\+: retrieve the current sliced V\+BI settings.

@s\+\_\+sliced\+\_\+fmt\+: setup the sliced V\+BI settings.
