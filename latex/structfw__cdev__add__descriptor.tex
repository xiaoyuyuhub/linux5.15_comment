\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structfw__cdev__add__descriptor}{fw\+\_\+cdev\+\_\+add\+\_\+descriptor}} -\/ Add contents to the local node\textquotesingle{}s config R\+OM @immediate\+: If non-\/zero, immediate key to insert before pointer @key\+: Upper 8 bits of root directory pointer @data\+: Userspace pointer to contents of descriptor block @length\+: Length of descriptor block data, in quadlets @handle\+: Handle to the descriptor, written by the kernel

Add a descriptor block and optionally a preceding immediate key to the local node\textquotesingle{}s Configuration R\+OM.

\mbox{\hyperlink{classThe}{The}} @key field specifies the upper 8 bits of the descriptor root directory pointer and the @data and @length fields specify the contents. \mbox{\hyperlink{classThe}{The}} @key should be of the form 0x\+X\+X000000. \mbox{\hyperlink{classThe}{The}} offset part of the root directory entry will be filled in by the kernel.

If not 0, the @immediate field specifies an immediate key which will be inserted before the root directory pointer.

@immediate, @key, and @data array elements are C\+P\+U-\/endian quadlets.

If successful, the kernel adds the descriptor and writes back a @handle to the kernel-\/side object to be used for later removal of the descriptor block and immediate key. \mbox{\hyperlink{classThe}{The}} kernel will also generate a bus reset to signal the change of the Configuration R\+OM to other nodes.

This ioctl affects the Configuration R\+O\+Ms of all local nodes. \mbox{\hyperlink{classThe}{The}} ioctl only succeeds on device files which represent a local node.
