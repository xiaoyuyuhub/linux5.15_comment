\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__crtc}{drm\+\_\+crtc}} -\/ central C\+R\+TC control structure

Each C\+R\+TC may have one or more connectors associated with it. This structure allows the C\+R\+TC to be controlled.
