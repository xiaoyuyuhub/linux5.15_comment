\doxysubsection{Detailed Description}
\mbox{\hyperlink{classThe}{The}} ring buffer debug console aims to be a substitute for the U\+A\+RT debug console. \mbox{\hyperlink{classThe}{The}} debug console is implemented with two ring buffers in the B\+P\+M\+P-\/\+FW, the RX (receive) and TX (transmit) buffers. Characters can be read and written to the buffers by the host via the M\+RQ interface.
