\mbox{\hyperlink{classThe}{The}} result of \mbox{\hyperlink{fse_8h_aaca3dda2d78980dbaaf7bf9139193299}{F\+S\+E\+\_\+normalize\+Count()}} will be saved into a table, called \textquotesingle{}normalized\+Counter\textquotesingle{}, which is a table of signed short. \textquotesingle{}normalized\+Counter\textquotesingle{} must be already allocated, and have at least \textquotesingle{}max\+Symbol\+Value+1\textquotesingle{} cells. \mbox{\hyperlink{classThe}{The}} return value is table\+Log if everything proceeded as expected.
