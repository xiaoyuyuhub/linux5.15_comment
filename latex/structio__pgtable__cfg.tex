\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structio__pgtable__cfg}{io\+\_\+pgtable\+\_\+cfg}} -\/ Configuration data for a set of page tables.

@quirks\+: A bitmap of hardware quirks that require some special action by the low-\/level page table allocator. @pgsize\+\_\+bitmap\+: A bitmap of page sizes supported by this set of page tables. @ias\+: Input address (iova) size, in bits. @oas\+: Output address (paddr) size, in bits. @coherent\+\_\+walk A flag to indicate whether or not page table walks made by the I\+O\+M\+MU are coherent with the C\+PU caches. @tlb\+: T\+LB management callbacks for this set of tables. @iommu\+\_\+dev\+: \mbox{\hyperlink{classThe}{The}} device representing the D\+MA configuration for the page table walker.
