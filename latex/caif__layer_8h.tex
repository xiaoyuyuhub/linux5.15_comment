\begin{Indent}\textbf{ \+: Name of the layer.}\par
{\em struct cflayer -\/ C\+A\+IF Stack layer. Defines the framework for the C\+A\+IF Core Stack. @up\+: Pointer up to the layer above. @dn\+: Pointer down to the layer below. @node\+: List node used when layer participate in a list. @receive\+: \mbox{\hyperlink{protocolPacket-p}{Packet}} receive function. @transmit\+: \mbox{\hyperlink{protocolPacket-p}{Packet}} transmit funciton. @ctrlcmd\+: Used for control signalling upwards in the stack. @modemcmd\+: Used for control signaling downwards in the stack. @id\+: \mbox{\hyperlink{classThe}{The}} identity of this layer

This structure defines the layered structure in C\+A\+IF.

It defines C\+A\+IF layering structure, used by all C\+A\+IF Layers and the layers interfacing C\+A\+IF.

In order to integrate with C\+A\+IF an adaptation layer on top of the C\+A\+IF stack and P\+HY layer below the C\+A\+IF stack must be implemented. These layer must follow the design principles below.

Principles for layering of \mbox{\hyperlink{protocolprotocol-p}{protocol}} layers\+:
\begin{DoxyItemize}
\item All layers must use this structure. If embedding it, then place this structure first in the layer specific structure.
\item Each layer should not depend on any others layer\textquotesingle{}s private data.
\item In order to send data upwards do layer-\/$>$up-\/$>$receive(layer-\/$>$up, packet);
\item In order to send data downwards do layer-\/$>$dn-\/$>$transmit(layer-\/$>$dn, info, packet); 
\end{DoxyItemize}}\begin{DoxyCompactItemize}
