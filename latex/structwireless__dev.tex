\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structwireless__dev}{wireless\+\_\+dev}} -\/ wireless device state

For netdevs, this structure must be allocated by the driver that uses the ieee80211\+\_\+ptr field in struct \mbox{\hyperlink{structnet__device}{net\+\_\+device}} (this is intentional so it can be allocated along with the netdev.) It need not be registered then as netdev registration will be intercepted by cfg80211 to see the new wireless device, however, drivers must lock the wiphy before registering or unregistering netdevs if they pre-\/create any netdevs (in ops called from cfg80211, the wiphy is already locked.)

For non-\/netdev uses, it must also be allocated by the driver in response to the cfg80211 callbacks that require it, as there\textquotesingle{}s no netdev registration in that case it may not be allocated outside of callback operations that return it.
