\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdtv__fe__stats}{dtv\+\_\+fe\+\_\+stats}} -\/ store Digital TV frontend statistics

@len\+: length of the statistics -\/ if zero, stats is disabled. @stat\+: array with digital TV statistics.

On most standards, @len can either be 0 or 1. However, for I\+S\+DB, each layer is modulated in separate. So, each layer may have its own set of statistics. If so, stat\mbox{[}0\mbox{]} carries on a global value for the property. Indexes 1 to 3 means layer A to B.
