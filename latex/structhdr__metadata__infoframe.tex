\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structhdr__metadata__infoframe}{hdr\+\_\+metadata\+\_\+infoframe}} -\/ H\+DR Metadata Infoframe Data.

H\+DR Metadata Infoframe as per C\+TA 861.\+G spec. This is expected to match exactly with the spec.

Userspace is expected to pass the metadata information as per the format described in this structure.
