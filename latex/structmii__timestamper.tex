\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structmii__timestamper}{mii\+\_\+timestamper}} -\/ Callback interface to M\+II time stamping devices.

@rxtstamp\+: Requests a Rx timestamp for \textquotesingle{}skb\textquotesingle{}. If the skb is accepted, the M\+II time stamping device promises to deliver it using \mbox{\hyperlink{linux_2netdevice_8h_a0afd633f3ffb63cf097d8bef878c90cd}{netif\+\_\+rx()}} as soon as a timestamp becomes available. One of the P\+T\+P\+\_\+\+C\+L\+A\+S\+S\+\_\+ values is passed in \textquotesingle{}type\textquotesingle{}. \mbox{\hyperlink{classThe}{The}} function must return true if the skb is accepted for delivery.

@txtstamp\+: Requests a Tx timestamp for \textquotesingle{}skb\textquotesingle{}. \mbox{\hyperlink{classThe}{The}} M\+II time stamping device promises to deliver it using skb\+\_\+complete\+\_\+tx\+\_\+timestamp() as soon as a timestamp becomes available. One of the P\+T\+P\+\_\+\+C\+L\+A\+S\+S\+\_\+ values is passed in \textquotesingle{}type\textquotesingle{}.

@hwtstamp\+: Handles S\+I\+O\+C\+S\+H\+W\+T\+S\+T\+A\+MP ioctl for hardware time stamping.

@link\+\_\+state\+: Allows the device to respond to changes in the link state. \mbox{\hyperlink{classThe}{The}} caller invokes this function while holding the \mbox{\hyperlink{structphy__device}{phy\+\_\+device}} mutex.

@ts\+\_\+info\+: Handles ethtool queries for hardware time stamping. @device\+: Remembers the device to which the instance belongs.

Drivers for P\+HY time stamping devices should embed their \mbox{\hyperlink{structmii__timestamper}{mii\+\_\+timestamper}} within a private structure, obtaining a reference to it using \mbox{\hyperlink{linux_2kernel_8h_af8c317a42292b61c93aae91e59118a46}{container\+\_\+of()}}.

Drivers for non-\/\+P\+HY time stamping devices should return a pointer to a \mbox{\hyperlink{structmii__timestamper}{mii\+\_\+timestamper}} from the probe\+\_\+channel() callback of their \mbox{\hyperlink{structmii__timestamping__ctrl}{mii\+\_\+timestamping\+\_\+ctrl}} interface.
