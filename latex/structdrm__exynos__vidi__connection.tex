\doxysubsection{Detailed Description}
A structure for user connection request of virtual display.

@connection\+: indicate whether doing connection or not by user. @extensions\+: if this value is 1 then the vidi driver would need additional 128bytes edid data. @edid\+: the edid data pointer from user side.
