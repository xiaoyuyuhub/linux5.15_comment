\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__dsc__picture__parameter__set}{drm\+\_\+dsc\+\_\+picture\+\_\+parameter\+\_\+set}} -\/ Represents 128 bytes of Picture Parameter Set

\mbox{\hyperlink{classThe}{The}} V\+E\+SA D\+SC standard defines picture parameter set (P\+PS) which display stream compression encoders must communicate to decoders. \mbox{\hyperlink{classThe}{The}} P\+PS is encapsulated in 128 bytes (P\+PS 0 through P\+PS 127). \mbox{\hyperlink{classThe}{The}} fields in this structure are as per Table 4.\+1 in Vesa D\+SC specification v1.\+1/v1.2. \mbox{\hyperlink{classThe}{The}} P\+PS fields that span over more than a byte should be stored in Big Endian format.
