\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structp9__qid}{p9\+\_\+qid}} -\/ file system entity information @type\+: 8-\/bit type \&p9\+\_\+qid\+\_\+t \begin{DoxyVersion}{Version}
\+: 16-\/bit monotonically incrementing version number @path\+: 64-\/bit per-\/server-\/unique ID for a file system element
\end{DoxyVersion}
qids are identifiers used by 9P servers to track file system entities. \mbox{\hyperlink{classThe}{The}} type is used to differentiate semantics for operations on the entity (ie. read means something different on a directory than on a file). \mbox{\hyperlink{classThe}{The}} path provides a server unique index for an entity (roughly analogous to an inode number), while the version is updated every time a file is modified and can be used to maintain cache coherency between clients and serves. Servers will often differentiate purely synthetic entities by setting their version to 0, signaling that they should never be cached and should be accessed synchronously.
