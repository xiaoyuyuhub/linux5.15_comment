\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structgenwqe__mem}{genwqe\+\_\+mem}} -\/ Memory pinning/unpinning information @addr\+: virtual user space address @size\+: size of the area pin/dma-\/map/unmap direction\+: 0\+: read/1\+: read and write

Avoid pinning and unpinning of memory pages dynamically. Instead the idea is to pin the whole buffer space required for D\+D\+CB opertionas in advance. \mbox{\hyperlink{classThe}{The}} driver will reuse this pinning and the memory associated with it to setup the sglists for the D\+D\+CB requests without the need to allocate and free memory or map and unmap to get the D\+MA addresses.

\mbox{\hyperlink{classThe}{The}} inverse operation needs to be called after the pinning is not needed anymore. \mbox{\hyperlink{classThe}{The}} pinnings else the pinnings will get removed after the device is closed. Note that pinnings will required memory.
