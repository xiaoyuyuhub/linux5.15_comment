D\+OC\+: Single Block Cipher A\+PI

\mbox{\hyperlink{classThe}{The}} single block cipher A\+PI is used with the ciphers of type C\+R\+Y\+P\+T\+O\+\_\+\+A\+L\+G\+\_\+\+T\+Y\+P\+E\+\_\+\+C\+I\+P\+H\+ER (listed as type \char`\"{}cipher\char`\"{} in /proc/crypto).

Using the single block cipher A\+PI calls, operations with the basic cipher primitive can be implemented. These cipher primitives exclude any block chaining operations including IV handling.

\mbox{\hyperlink{classThe}{The}} purpose of this single block cipher A\+PI is to support the implementation of templates or other concepts that only need to perform the cipher operation on one block at a time.
