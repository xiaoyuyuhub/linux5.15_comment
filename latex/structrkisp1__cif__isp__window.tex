\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structrkisp1__cif__isp__window}{rkisp1\+\_\+cif\+\_\+isp\+\_\+window}} -\/ measurement window.

Measurements are calculated per window inside the frame. This struct represents a window for a measurement.

@h\+\_\+offs\+: the horizontal offset of the window from the left of the frame in pixels. @v\+\_\+offs\+: the vertical offset of the window from the top of the frame in pixels. @h\+\_\+size\+: the horizontal size of the window in pixels @v\+\_\+size\+: the vertical size of the window in pixels.
