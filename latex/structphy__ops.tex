@validate\+:

Optional.

Used to check that the current set of parameters can be handled by the phy. Implementations are free to tune the parameters passed as arguments if needed by some implementation detail or constraints. It must not change any actual configuration of the P\+HY, so calling it as many times as deemed fit by the consumer must have no side effect.

Returns\+: 0 if the configuration can be applied, an negative error code otherwise
