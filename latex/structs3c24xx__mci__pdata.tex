\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structs3c24xx__mci__pdata}{s3c24xx\+\_\+mci\+\_\+pdata}} -\/ sd/mmc controller platform data @no\+\_\+wprotect\+: Set this to indicate there is no write-\/protect switch. @no\+\_\+detect\+: Set this if there is no detect switch. @wprotect\+\_\+invert\+: Invert the default sense of the write protect switch. @use\+\_\+dma\+: Set to allow the use of D\+MA. @gpio\+\_\+detect\+: G\+P\+IO number for the card detect line. @gpio\+\_\+wprotect\+: G\+P\+IO number for the write protect line. @ocr\+\_\+avail\+: \mbox{\hyperlink{classThe}{The}} mask of the available power states, non-\/zero to use. @set\+\_\+power\+: Callback to control the power mode.

\mbox{\hyperlink{classThe}{The}} @gpio\+\_\+detect is used for card detection when @no\+\_\+wprotect is unset, and the default sense is that 0 returned from \mbox{\hyperlink{linux_2gpio_8h_a22fe8682226799a869dc150f8c78169c}{gpio\+\_\+get\+\_\+value()}} means that a card is inserted. If @detect\+\_\+invert is set, then the value from \mbox{\hyperlink{linux_2gpio_8h_a22fe8682226799a869dc150f8c78169c}{gpio\+\_\+get\+\_\+value()}} is inverted, which makes 1 mean card inserted.

\mbox{\hyperlink{classThe}{The}} driver will use @gpio\+\_\+wprotect to signal whether the card is write protected if @no\+\_\+wprotect is not set. A 0 returned from \mbox{\hyperlink{linux_2gpio_8h_a22fe8682226799a869dc150f8c78169c}{gpio\+\_\+get\+\_\+value()}} means the card is read/write, and 1 means read-\/only. \mbox{\hyperlink{classThe}{The}} @wprotect\+\_\+invert will invert the value returned from \mbox{\hyperlink{linux_2gpio_8h_a22fe8682226799a869dc150f8c78169c}{gpio\+\_\+get\+\_\+value()}}.

Card power is set by @ocr\+\_\+availa, using M\+C\+C\+\_\+\+V\+D\+D\+\_\+ constants if it is set to a non-\/zero value, otherwise the default of 3.\+2-\/3.\+4V is used.
