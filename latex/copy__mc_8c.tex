copy\+\_\+mc\+\_\+to\+\_\+kernel -\/ memory copy that handles source exceptions

@dst\+: destination address @src\+: source address @len\+: number of bytes to copy

Call into the \textquotesingle{}fragile\textquotesingle{} version on systems that benefit from avoiding corner case poison consumption scenarios, For example, accessing poison across 2 cachelines with a single instruction.
