intlog10 -\/ computes log10 of a value; the result is shifted left by 24 bits

@value\+: \mbox{\hyperlink{classThe}{The}} value (must be != 0)

to use rational values you can use the following method\+:

intlog10(value) = intlog10(value $\ast$ 10$^\wedge$x) -\/ x $\ast$ 2$^\wedge$24

An usecase example\+:

intlog10(1000) will give 3 $<$$<$ 24 = 3 $\ast$ 2$^\wedge$24
