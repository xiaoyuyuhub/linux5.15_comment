\mbox{\hyperlink{sync_8c_afb3bf9da62b25629bf76aa540d1cbdb1}{rcu\+\_\+sync\+\_\+enter()}} -\/ Force readers onto slowpath @rsp\+: Pointer to \mbox{\hyperlink{structrcu__sync}{rcu\+\_\+sync}} structure to use for synchronization

This function is used by updaters who need readers to make use of a slowpath during the update. After this function returns, all subsequent calls to \mbox{\hyperlink{rcu__sync_8h_a4c65217bb3ef94cb7a301f219f52547f}{rcu\+\_\+sync\+\_\+is\+\_\+idle()}} will return false, which tells readers to stay off their fastpaths. A later call to \mbox{\hyperlink{sync_8c_a648625017a03c3a546b9ef0ba310c9a9}{rcu\+\_\+sync\+\_\+exit()}} re-\/enables reader slowpaths.

When called in isolation, \mbox{\hyperlink{sync_8c_afb3bf9da62b25629bf76aa540d1cbdb1}{rcu\+\_\+sync\+\_\+enter()}} must wait for a grace period, however, closely spaced calls to \mbox{\hyperlink{sync_8c_afb3bf9da62b25629bf76aa540d1cbdb1}{rcu\+\_\+sync\+\_\+enter()}} can optimize away the grace-\/period wait via a state machine implemented by \mbox{\hyperlink{sync_8c_afb3bf9da62b25629bf76aa540d1cbdb1}{rcu\+\_\+sync\+\_\+enter()}}, \mbox{\hyperlink{sync_8c_a648625017a03c3a546b9ef0ba310c9a9}{rcu\+\_\+sync\+\_\+exit()}}, and \mbox{\hyperlink{sync_8c_a0f8b04b71866ba0c71660767f9a66640}{rcu\+\_\+sync\+\_\+func()}}.
