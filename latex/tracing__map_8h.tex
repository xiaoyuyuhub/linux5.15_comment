A \mbox{\hyperlink{structtracing__map}{tracing\+\_\+map}} is a special-\/purpose map designed to aggregate or \textquotesingle{}sum\textquotesingle{} one or more values associated with a specific object of type \mbox{\hyperlink{structtracing__map__elt}{tracing\+\_\+map\+\_\+elt}}, which is attached by the map to a given key.

All tracing\+\_\+map\+\_\+elts for a given map have the same set of sums and keys, which are defined by the client using the functions \mbox{\hyperlink{tracing__map_8c_a2ce70b992c976ea46f27a5b6773f8d9d}{tracing\+\_\+map\+\_\+add\+\_\+key\+\_\+field()}} and \mbox{\hyperlink{tracing__map_8c_a080c3bc934c7fe4cce9abebfee8922bb}{tracing\+\_\+map\+\_\+add\+\_\+sum\+\_\+field()}}. Once the fields are defined, the pool of elements allocated for the map can be created, which occurs when the client code calls \mbox{\hyperlink{tracing__map_8c_a4fcdd469dd754bfcd72f5e2a34908554}{tracing\+\_\+map\+\_\+init()}}.

When \mbox{\hyperlink{tracing__map_8c_a4fcdd469dd754bfcd72f5e2a34908554}{tracing\+\_\+map\+\_\+init()}} returns, \mbox{\hyperlink{structtracing__map__elt}{tracing\+\_\+map\+\_\+elt}} elements can be inserted into the map using \mbox{\hyperlink{tracing__map_8c_aee74920521c440390da6ab4eefca457f}{tracing\+\_\+map\+\_\+insert()}}. When called, \mbox{\hyperlink{tracing__map_8c_aee74920521c440390da6ab4eefca457f}{tracing\+\_\+map\+\_\+insert()}} grabs a free \mbox{\hyperlink{structtracing__map__elt}{tracing\+\_\+map\+\_\+elt}} from the pool, or finds an existing match in the map and in either case returns it. \mbox{\hyperlink{classThe}{The}} client can then use \mbox{\hyperlink{tracing__map_8c_a432dfc503a5f21ee833216aaff3f1729}{tracing\+\_\+map\+\_\+update\+\_\+sum()}} and \mbox{\hyperlink{tracing__map_8c_af17ea54da5a8eec10c370d8d26088a48}{tracing\+\_\+map\+\_\+read\+\_\+sum()}} to update or read a given sum field for the \mbox{\hyperlink{structtracing__map__elt}{tracing\+\_\+map\+\_\+elt}}.
