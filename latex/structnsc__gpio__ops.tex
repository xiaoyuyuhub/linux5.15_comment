\doxysubsection{Detailed Description}
nsc\+\_\+gpio.\+c

National Semiconductor G\+P\+IO common access methods.

struct \mbox{\hyperlink{structnsc__gpio__ops}{nsc\+\_\+gpio\+\_\+ops}} abstracts the low-\/level access operations for the G\+P\+IO units on 2 N\+SC chip families; the G\+E\+O\+DE integrated C\+PU, and the P\+C-\/8736\mbox{[}03456\mbox{]} integrated P\+C-\/peripheral chips.

\mbox{\hyperlink{classThe}{The}} G\+P\+IO units on these chips have the same pin architecture, but the access methods differ. Thus, scx200\+\_\+gpio and pc8736x\+\_\+gpio implement their own versions of these routines; and use the common file-\/operations routines implemented in nsc\+\_\+gpio module.

NB\+: this work was tested on the Geode S\+C-\/1100 and P\+C-\/87366 chips. N\+SC sold the G\+E\+O\+DE line to A\+MD, and the P\+C-\/8736x line to Winbond.
