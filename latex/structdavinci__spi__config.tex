\mbox{\hyperlink{structdavinci__spi__config}{davinci\+\_\+spi\+\_\+config}} -\/ Per-\/chip-\/select configuration for S\+PI slave devices

@wdelay\+: amount of delay between transmissions. Measured in number of S\+PI module clocks. @odd\+\_\+parity\+: polarity of parity flag at the end of transmit data stream. 0 -\/ odd parity, 1 -\/ even parity. @parity\+\_\+enable\+: enable transmission of parity at end of each transmit data stream. @io\+\_\+type\+: type of IO transfer.
