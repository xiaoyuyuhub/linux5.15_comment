\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__private__state__funcs}{drm\+\_\+private\+\_\+state\+\_\+funcs}} -\/ atomic state functions for private objects

These hooks are used by atomic helpers to create, swap and destroy states of private objects. \mbox{\hyperlink{classThe}{The}} structure itself is used as a vtable to identify the associated private object type. Each private object type that needs to be added to the atomic states is expected to have an implementation of these hooks and pass a pointer to its \mbox{\hyperlink{structdrm__private__state__funcs}{drm\+\_\+private\+\_\+state\+\_\+funcs}} struct to \mbox{\hyperlink{drm__atomic_8h_a64c00b8a8fe73dd58a8737068f9a15a0}{drm\+\_\+atomic\+\_\+get\+\_\+private\+\_\+obj\+\_\+state()}}.
