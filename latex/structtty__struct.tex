\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structtty__struct}{tty\+\_\+struct}} -\/ state associated with a tty while open

@flow.lock\+: lock for flow members @flow.stopped\+: tty stopped/started by tty\+\_\+stop/tty\+\_\+start @flow.tco\+\_\+stopped\+: tty stopped/started by T\+C\+O\+O\+F\+F/\+T\+C\+O\+ON ioctls (it has precedense over @flow.stopped) @flow.unused\+: alignment for Alpha, so that no members other than @flow.$\ast$ are modified by the same 64b word store. \mbox{\hyperlink{classThe}{The}} @flow\textquotesingle{}s \+\_\+\+\_\+aligned is there for the very same reason. @ctrl.lock\+: lock for ctrl members @ctrl.pgrp\+: process group of this tty (setpgrp(2)) @ctrl.session\+: session of this tty (setsid(2)). Writes are protected by both @ctrl.lock and legacy mutex, readers must use at least one of them. @ctrl.pktstatus\+: packet mode status (bitwise OR of T\+I\+O\+C\+P\+K\+T\+\_\+$\ast$ constants) @ctrl.packet\+: packet mode enabled

All of the state associated with a tty while the tty is open. Persistent storage for tty devices is referenced here as @port in struct \mbox{\hyperlink{structtty__port}{tty\+\_\+port}}.
