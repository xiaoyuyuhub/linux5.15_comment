mutex\+\_\+lock -\/ acquire the mutex @lock\+: the mutex to be acquired

Lock the mutex exclusively for this task. If the mutex is not available right now, it will sleep until it can get it.

\mbox{\hyperlink{classThe}{The}} mutex must later on be released by the same task that acquired it. Recursive locking is not allowed. \mbox{\hyperlink{classThe}{The}} task may not exit without first unlocking the mutex. Also, kernel memory where the mutex resides must not be freed with the mutex still locked. \mbox{\hyperlink{classThe}{The}} mutex must first be initialized (or statically defined) before it can be locked. \mbox{\hyperlink{arch_2x86_2boot_2string_8h_ad4e6d318532881885b389253f6d35b6f}{memset()}}-\/ing the mutex to 0 is not allowed.

(\mbox{\hyperlink{classThe}{The}} C\+O\+N\+F\+I\+G\+\_\+\+D\+E\+B\+U\+G\+\_\+\+M\+U\+T\+E\+X\+ES .config option turns on debugging checks that will enforce the restrictions and will also do deadlock debugging)
