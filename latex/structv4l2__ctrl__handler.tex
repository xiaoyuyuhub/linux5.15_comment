\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structv4l2__ctrl__handler}{v4l2\+\_\+ctrl\+\_\+handler}} -\/ \mbox{\hyperlink{classThe}{The}} control handler keeps track of all the controls\+: both the controls owned by the handler and those inherited from other handlers.

@\+\_\+lock\+: Default for \char`\"{}lock\char`\"{}. @lock\+: Lock to control access to this handler and its controls. May be replaced by the user right after init. @ctrls\+: \mbox{\hyperlink{classThe}{The}} list of controls owned by this handler. @ctrl\+\_\+refs\+: \mbox{\hyperlink{classThe}{The}} list of control references. @cached\+: \mbox{\hyperlink{classThe}{The}} last found control reference. It is common that the same control is needed multiple times, so this is a simple optimization. @buckets\+: Buckets for the hashing. Allows for quick control lookup. @notify\+: A notify callback that is called whenever the control changes value. Note that the handler\textquotesingle{}s lock is held when the notify function is called! @notify\+\_\+priv\+: Passed as argument to the \mbox{\hyperlink{structv4l2__ctrl}{v4l2\+\_\+ctrl}} notify callback. @nr\+\_\+of\+\_\+buckets\+: Total number of buckets in the array. @error\+: \mbox{\hyperlink{classThe}{The}} error code of the first failed control addition. @request\+\_\+is\+\_\+queued\+: True if the request was queued. @requests\+: List to keep track of open control handler request objects. For the parent control handler (@req\+\_\+obj.ops == N\+U\+LL) this is the list header. When the parent control handler is removed, it has to unbind and put all these requests since they refer to the parent. @requests\+\_\+queued\+: List of the queued requests. This determines the order in which these controls are applied. Once the request is completed it is removed from this list. @req\+\_\+obj\+: \mbox{\hyperlink{classThe}{The}} \&struct \mbox{\hyperlink{structmedia__request__object}{media\+\_\+request\+\_\+object}}, used to link into a \&struct \mbox{\hyperlink{structmedia__request}{media\+\_\+request}}. This request object has a refcount.
