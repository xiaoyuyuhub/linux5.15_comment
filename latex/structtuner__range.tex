\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structtuner__range}{tuner\+\_\+range}} -\/ define the frequencies supported by the tuner

@limit\+: Max frequency supported by that range, in 62.\+5 k\+Hz (TV) or 62.\+5 Hz (Radio), as defined by V4\+L2\+\_\+\+T\+U\+N\+E\+R\+\_\+\+C\+A\+P\+\_\+\+L\+OW. @config\+: Value of the band switch byte (BB) to setup this mode. @cb\+: Value of the CB byte to setup this mode.

Please notice that digital tuners like xc3028/xc4000/xc5000 don\textquotesingle{}t use those ranges, as they\textquotesingle{}re defined inside the driver. This is used by analog tuners that are compatible with the \char`\"{}\+Philips way\char`\"{} to setup the tuners. On those devices, the tuner set is done via 4 bytes\+:

\#) divider byte1 (D\+B1) \#) divider byte 2 (D\+B2) \#) Control byte (CB) \#) band switch byte (BB)

Some tuners also have an additional optional Auxiliary byte (AB).
