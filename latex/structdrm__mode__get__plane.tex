\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__mode__get__plane}{drm\+\_\+mode\+\_\+get\+\_\+plane}} -\/ Get plane metadata.

Userspace can perform a G\+E\+T\+P\+L\+A\+NE ioctl to retrieve information about a plane.

To retrieve the number of formats supported, set @count\+\_\+format\+\_\+types to zero and call the ioctl. @count\+\_\+format\+\_\+types will be updated with the value.

To retrieve these formats, allocate an array with the memory needed to store @count\+\_\+format\+\_\+types formats. Point @format\+\_\+type\+\_\+ptr to this array and call the ioctl again (with @count\+\_\+format\+\_\+types still set to the value returned in the first ioctl call).
