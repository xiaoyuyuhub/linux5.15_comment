\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__hdmi__info}{drm\+\_\+hdmi\+\_\+info}} -\/ runtime information about the connected H\+D\+MI sink

Describes if a given display supports advanced H\+D\+MI 2.\+0 features. This information is available in C\+E\+A-\/861-\/F extension blocks (like H\+F-\/\+V\+S\+DB).
