\doxysubsection{Detailed Description}
Data to be supplied by the platform to initialise the W\+M8350.

@init\+: Function called during driver initialisation. Should be used by the platform to configure G\+P\+IO functions and similar. @irq\+\_\+high\+: Set if W\+M8350 I\+RQ is active high. @irq\+\_\+base\+: Base I\+RQ for genirq (not currently used). @gpio\+\_\+base\+: Base for gpiolib.
