parport\+\_\+register\+\_\+driver -\/ register a parallel port device driver @driver\+: structure describing the driver

This can be called by a parallel port device driver in order to receive notifications about ports being found in the system, as well as ports no longer available.

If devmodel is true then the new device model is used for registration.

\mbox{\hyperlink{classThe}{The}} @driver structure is allocated by the caller and must not be deallocated until after calling \mbox{\hyperlink{include_2linux_2parport_8h_a35d1cec36fe46bf3627ff760065ebc0a}{parport\+\_\+unregister\+\_\+driver()}}.

If using the non device model\+: \mbox{\hyperlink{classThe}{The}} driver\textquotesingle{}s attach() function may block. \mbox{\hyperlink{classThe}{The}} port that attach() is given will be valid for the duration of the callback, but if the driver wants to take a copy of the pointer it must call \mbox{\hyperlink{include_2linux_2parport_8h_a09e3db933a5a79da62326bb7a56aa808}{parport\+\_\+get\+\_\+port()}} to do so. Calling parport\+\_\+register\+\_\+device() on that port will do this for you.

\mbox{\hyperlink{classThe}{The}} driver\textquotesingle{}s detach() function may block. \mbox{\hyperlink{classThe}{The}} port that detach() is given will be valid for the duration of the callback, but if the driver wants to take a copy of the pointer it must call \mbox{\hyperlink{include_2linux_2parport_8h_a09e3db933a5a79da62326bb7a56aa808}{parport\+\_\+get\+\_\+port()}} to do so.

parport\+\_\+yield -\/ relinquish a parallel port temporarily @dev\+: a device on the parallel port

This function relinquishes the port if it would be helpful to other drivers to do so. Afterwards it tries to reclaim the port using \mbox{\hyperlink{include_2linux_2parport_8h_a45ad38c569863e93903e7e0b26b27be3}{parport\+\_\+claim()}}, and the return value is the same as for \mbox{\hyperlink{include_2linux_2parport_8h_a45ad38c569863e93903e7e0b26b27be3}{parport\+\_\+claim()}}. If it fails, the port is left unclaimed and it is the driver\textquotesingle{}s responsibility to reclaim the port.

\mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{include_2linux_2parport_8h_aa5159d252e9cb1f7180c7ef6dd3c5c19}{parport\+\_\+yield()}} and \mbox{\hyperlink{include_2linux_2parport_8h_a26eda7c925527cf52760b8f4848b7b7e}{parport\+\_\+yield\+\_\+blocking()}} functions are for marking points in the driver at which other drivers may claim the port and use their devices. Yielding the port is similar to releasing it and reclaiming it, but is more efficient because no action is taken if there are no other devices needing the port. In fact, nothing is done even if there are other devices waiting but the current device is still within its \char`\"{}timeslice\char`\"{}. \mbox{\hyperlink{classThe}{The}} default timeslice is half a second, but it can be adjusted via the /proc interface.
