Iterate through E\+PC sections and borrow a free E\+PC page to the caller. When a page is no longer needed it must be released with \mbox{\hyperlink{arch_2x86_2kernel_2cpu_2sgx_2main_8c_aad7fdd4831fa0bf3d82eb2f54fe4a1d1}{sgx\+\_\+free\+\_\+epc\+\_\+page()}}. If @reclaim is set to true, directly reclaim pages when we are out of pages. No mm\textquotesingle{}s can be locked when @reclaim is set to true.

Finally, wake up ksgxd when the number of pages goes below the watermark before returning back to the caller.
