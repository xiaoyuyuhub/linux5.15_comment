struct \mbox{\hyperlink{structnetlbl__lsm__secattr}{netlbl\+\_\+lsm\+\_\+secattr}} -\/ Net\+Label L\+SM security attributes @flags\+: indicate structure attributes, see N\+E\+T\+L\+B\+L\+\_\+\+S\+E\+C\+A\+T\+T\+R\+\_\+$\ast$ @type\+: indicate the N\+L\+T\+Y\+PE of the attributes @domain\+: the Net\+Label L\+SM domain @cache\+: Net\+Label L\+SM specific cache @attr.mls\+: M\+LS sensitivity label @attr.mls.\+cat\+: M\+LS category bitmap @attr.mls.\+lvl\+: M\+LS sensitivity level @attr.secid\+: L\+SM specific secid token
