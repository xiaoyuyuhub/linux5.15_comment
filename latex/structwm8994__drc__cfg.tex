\doxysubsection{Detailed Description}
D\+RC configurations are specified with a label and a set of register values to write (the enable bits will be ignored). At runtime an enumerated control will be presented for each D\+RC block allowing the user to choose the configuration to use.

Configurations may be generated by hand or by using the D\+RC control panel provided by the W\+I\+S\+CE -\/ see \href{http://www.wolfsonmicro.com/wisce/}{\texttt{ http\+://www.\+wolfsonmicro.\+com/wisce/}} for details.
