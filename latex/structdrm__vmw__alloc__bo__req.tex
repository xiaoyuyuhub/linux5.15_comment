\doxysubsection{Detailed Description}
D\+R\+M\+\_\+\+V\+M\+W\+\_\+\+A\+L\+L\+O\+C\+\_\+\+BO

Allocate a buffer object that is visible also to the host. N\+O\+TE\+: \mbox{\hyperlink{classThe}{The}} buffer is identified by a handle and an offset, which are private to the guest, but useable in the command stream. \mbox{\hyperlink{classThe}{The}} guest kernel may translate these and patch up the command stream accordingly. In the future, the offset may be zero at all times, or it may disappear from the interface before it is fixed.

\mbox{\hyperlink{classThe}{The}} buffer object may stay user-\/space mapped in the guest at all times, and is thus suitable for sub-\/allocation.

Buffer objects are mapped using the mmap() syscall on the drm device. struct \mbox{\hyperlink{structdrm__vmw__alloc__bo__req}{drm\+\_\+vmw\+\_\+alloc\+\_\+bo\+\_\+req}}

@size\+: Required minimum size of the buffer.
