\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structcond__snapshot}{cond\+\_\+snapshot}} -\/ conditional snapshot data and callback

\mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structcond__snapshot}{cond\+\_\+snapshot}} structure encapsulates a callback function and data associated with the snapshot for a given tracing instance.

When a snapshot is taken conditionally, by invoking tracing\+\_\+snapshot\+\_\+cond(tr, cond\+\_\+data), the cond\+\_\+data passed in is passed in turn to the \mbox{\hyperlink{structcond__snapshot_a92791c6c07f4d3799781a3b837ab9f8f}{cond\+\_\+snapshot.\+update()}} function. That data can be compared by the \mbox{\hyperlink{structcond__snapshot_a92791c6c07f4d3799781a3b837ab9f8f}{update()}} implementation with the cond\+\_\+data contained within the struct \mbox{\hyperlink{structcond__snapshot}{cond\+\_\+snapshot}} instance associated with the \mbox{\hyperlink{structtrace__array}{trace\+\_\+array}}. Because the tr-\/$>$max\+\_\+lock is held throughout the \mbox{\hyperlink{structcond__snapshot_a92791c6c07f4d3799781a3b837ab9f8f}{update()}} call, the \mbox{\hyperlink{structcond__snapshot_a92791c6c07f4d3799781a3b837ab9f8f}{update()}} function can directly retrieve the \mbox{\hyperlink{structcond__snapshot}{cond\+\_\+snapshot}} and cond\+\_\+data associated with the per-\/instance snapshot associated with the \mbox{\hyperlink{structtrace__array}{trace\+\_\+array}}.

\mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structcond__snapshot_a92791c6c07f4d3799781a3b837ab9f8f}{cond\+\_\+snapshot.\+update()}} implementation can save data to be associated with the snapshot if it decides to, and returns \textquotesingle{}true\textquotesingle{} in that case, or it returns \textquotesingle{}false\textquotesingle{} if the conditional snapshot shouldn\textquotesingle{}t be taken.

\mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structcond__snapshot}{cond\+\_\+snapshot}} instance is created and associated with the user-\/defined cond\+\_\+data by tracing\+\_\+cond\+\_\+snapshot\+\_\+enable(). Likewise, the \mbox{\hyperlink{structcond__snapshot}{cond\+\_\+snapshot}} instance is destroyed and is no longer associated with the trace instance by tracing\+\_\+cond\+\_\+snapshot\+\_\+disable().

\mbox{\hyperlink{classThe}{The}} method below is required.

@update\+: When a conditional snapshot is invoked, the \mbox{\hyperlink{structcond__snapshot_a92791c6c07f4d3799781a3b837ab9f8f}{update()}} callback function is invoked with the tr-\/$>$max\+\_\+lock held. \mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structcond__snapshot_a92791c6c07f4d3799781a3b837ab9f8f}{update()}} implementation signals whether or not to actually take the snapshot, by returning \textquotesingle{}true\textquotesingle{} if so, \textquotesingle{}false\textquotesingle{} if no snapshot should be taken. Because the max\+\_\+lock is held for the duration of \mbox{\hyperlink{structcond__snapshot_a92791c6c07f4d3799781a3b837ab9f8f}{update()}}, the implementation is safe to directly retrieved and save any implementation data it needs to in association with the snapshot.
