\doxysubsection{Detailed Description}
D\+OC\+: Scanning and B\+SS list handling

\mbox{\hyperlink{classThe}{The}} scanning process itself is fairly simple, but cfg80211 offers quite a bit of helper functionality. To start a scan, the scan operation will be invoked with a scan definition. This scan definition \mbox{\hyperlink{protocolcontains-p}{contains}} the channels to scan, and the S\+S\+I\+Ds to send probe requests for (including the wildcard, if desired). A passive scan is indicated by having no S\+S\+I\+Ds to probe. Additionally, a scan request may contain extra information elements that should be added to the probe request. \mbox{\hyperlink{classThe}{The}} I\+Es are guaranteed to be well-\/formed, and will not exceed the maximum length the driver advertised in the wiphy structure.

When scanning finds a B\+SS, cfg80211 needs to be notified of that, because it is responsible for maintaining the B\+SS list; the driver should not maintain a list itself. For this notification, various functions exist.
