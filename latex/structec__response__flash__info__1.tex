struct \mbox{\hyperlink{structec__response__flash__info__1}{ec\+\_\+response\+\_\+flash\+\_\+info\+\_\+1}} -\/ Response to the flash info v1 command. @flash\+\_\+size\+: Usable flash size in bytes. @write\+\_\+block\+\_\+size\+: Write block size.
