D\+OC\+: I\+DA description

\mbox{\hyperlink{classThe}{The}} I\+DA is an ID allocator which does not provide the ability to associate an ID with a pointer. As such, it only needs to store one bit per ID, and so is more space efficient than an I\+DR. To use an I\+DA, define it using \mbox{\hyperlink{idr_8h_a6dbb78c0cf94a1fb4e65fc11c3ca5fbf}{D\+E\+F\+I\+N\+E\+\_\+\+I\+D\+A()}} (or embed a \&struct ida in a data structure, then initialise it using \mbox{\hyperlink{idr_8h_a1eadaf2a4338ce8b878eb546df4d061b}{ida\+\_\+init()}}). To allocate a new ID, call \mbox{\hyperlink{idr_8h_a3cd736f4277047a42d8701dd86787577}{ida\+\_\+alloc()}}, \mbox{\hyperlink{idr_8h_a3bac3aba61388425d00a284c0d2a144c}{ida\+\_\+alloc\+\_\+min()}}, \mbox{\hyperlink{idr_8h_a6c21fb490d0bf640bb3faa26f2efaf3f}{ida\+\_\+alloc\+\_\+max()}} or \mbox{\hyperlink{idr_8c_a6010752eedda26b7ad2d516364fbf2ae}{ida\+\_\+alloc\+\_\+range()}}. To free an ID, call \mbox{\hyperlink{idr_8c_ad1c6fd7f295b69eeea892f92e8bb7d83}{ida\+\_\+free()}}.

\mbox{\hyperlink{idr_8c_abe42491c9004eeb7b8a12aec66675d22}{ida\+\_\+destroy()}} can be used to dispose of an I\+DA without needing to free the individual I\+Ds in it. You can use \mbox{\hyperlink{idr_8h_a2b7fd937ce8920ddef3819156b458608}{ida\+\_\+is\+\_\+empty()}} to find out whether the I\+DA has any I\+Ds currently allocated.

\mbox{\hyperlink{classThe}{The}} I\+DA handles its own locking. It is safe to call any of the I\+DA functions without synchronisation in your code.

I\+Ds are currently limited to the range \mbox{[}0-\/I\+N\+T\+\_\+\+M\+AX\mbox{]}.
