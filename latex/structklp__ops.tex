\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structklp__ops}{klp\+\_\+ops}} -\/ structure for tracking registered ftrace ops structs

A single ftrace\+\_\+ops is shared between all enabled replacement functions (klp\+\_\+func structs) which have the same old\+\_\+func. This allows the switch between function versions to happen instantaneously by updating the \mbox{\hyperlink{structklp__ops}{klp\+\_\+ops}} struct\textquotesingle{}s func\+\_\+stack list. \mbox{\hyperlink{classThe}{The}} winner is the klp\+\_\+func at the top of the func\+\_\+stack (front of the list).
