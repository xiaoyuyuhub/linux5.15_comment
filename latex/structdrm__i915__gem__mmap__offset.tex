\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__i915__gem__mmap__offset}{drm\+\_\+i915\+\_\+gem\+\_\+mmap\+\_\+offset}} -\/ Retrieve an offset so we can mmap this buffer object.

This struct is passed as argument to the {\ttfamily D\+R\+M\+\_\+\+I\+O\+C\+T\+L\+\_\+\+I915\+\_\+\+G\+E\+M\+\_\+\+M\+M\+A\+P\+\_\+\+O\+F\+F\+S\+ET} ioctl, and is used to retrieve the fake offset to mmap an object specified by \&handle.

\mbox{\hyperlink{classThe}{The}} legacy way of using {\ttfamily D\+R\+M\+\_\+\+I\+O\+C\+T\+L\+\_\+\+I915\+\_\+\+G\+E\+M\+\_\+\+M\+M\+AP} is removed on gen12+. {\ttfamily D\+R\+M\+\_\+\+I\+O\+C\+T\+L\+\_\+\+I915\+\_\+\+G\+E\+M\+\_\+\+M\+M\+A\+P\+\_\+\+G\+TT} is an older supported alias to this struct, but will behave as setting the \&extensions to 0, and \&flags to {\ttfamily I915\+\_\+\+M\+M\+A\+P\+\_\+\+O\+F\+F\+S\+E\+T\+\_\+\+G\+TT}.
