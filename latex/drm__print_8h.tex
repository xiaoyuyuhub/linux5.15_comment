enum drm\+\_\+debug\+\_\+category -\/ \mbox{\hyperlink{classThe}{The}} D\+RM debug categories

Each of the D\+RM debug logging macros use a specific category, and the logging is filtered by the drm.\+debug module parameter. This enum specifies the values for the interface.

Each D\+R\+M\+\_\+\+D\+E\+B\+U\+G\+\_\+$<$\+C\+A\+T\+E\+G\+O\+R\+Y$>$ macro logs to D\+R\+M\+\_\+\+U\+T\+\_\+$<$\+C\+A\+T\+E\+G\+O\+R\+Y$>$ category, except \mbox{\hyperlink{drm__print_8h_a95462136c3f254bcfe6fba01134eb45f}{D\+R\+M\+\_\+\+D\+E\+B\+U\+G()}} logs to D\+R\+M\+\_\+\+U\+T\+\_\+\+C\+O\+RE.

Enabling verbose debug messages is done through the drm.\+debug parameter, each category being enabled by a bit\+:


\begin{DoxyItemize}
\item drm.\+debug=0x1 will enable C\+O\+RE messages
\item drm.\+debug=0x2 will enable D\+R\+I\+V\+ER messages
\item drm.\+debug=0x3 will enable C\+O\+RE and D\+R\+I\+V\+ER messages
\item ...
\item drm.\+debug=0x1ff will enable all messages
\end{DoxyItemize}
