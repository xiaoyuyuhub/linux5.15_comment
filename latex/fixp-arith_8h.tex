\mbox{\hyperlink{fixp-arith_8h_ade93d521a7bd7fc2f7cbab9ea4655269}{fixp\+\_\+sin32\+\_\+rad()}} -\/ calculates the sin of an angle in radians

@radians\+: angle, in radians @twopi\+: value to be used for 2$\ast$pi

Provides a variant for the cases where just 360 values is not enough. This function uses linear interpolation to a wider range of values given by twopi var.

Experimental tests gave a maximum difference of 0.\+000038 between the value calculated by sin() and the one produced by this function, when twopi is equal to 360000. That seems to be enough precision for practical purposes.
