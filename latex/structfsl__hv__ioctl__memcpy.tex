\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structfsl__hv__ioctl__memcpy}{fsl\+\_\+hv\+\_\+ioctl\+\_\+memcpy}} -\/ copy memory between partitions @ret\+: return error code from the hypervisor @source\+: the partition ID of the source partition, or -\/1 for this partition @target\+: the partition ID of the target partition, or -\/1 for this partition @reserved\+: reserved, must be set to 0 @local\+\_\+addr\+: user-\/space virtual address of a buffer in the local partition @remote\+\_\+addr\+: guest physical address of a buffer in the remote partition @count\+: the number of bytes to copy. Both the local and remote buffers must be at least \textquotesingle{}count\textquotesingle{} bytes long

Used by F\+S\+L\+\_\+\+H\+V\+\_\+\+I\+O\+C\+T\+L\+\_\+\+M\+E\+M\+C\+PY

\mbox{\hyperlink{classThe}{The}} \textquotesingle{}local\textquotesingle{} partition is the partition that calls this ioctl. \mbox{\hyperlink{classThe}{The}} \textquotesingle{}remote\textquotesingle{} partition is a different partition. \mbox{\hyperlink{classThe}{The}} data is copied from the \textquotesingle{}source\textquotesingle{} paritition\textquotesingle{} to the \textquotesingle{}target\textquotesingle{} partition.

\mbox{\hyperlink{classThe}{The}} buffer in the remote partition must be guest physically contiguous.

This ioctl does not support copying memory between two remote partitions or within the same partition, so either \textquotesingle{}source\textquotesingle{} or \textquotesingle{}target\textquotesingle{} (but not both) must be -\/1. In other words, either \begin{DoxyVerb} source == local and target == remote
\end{DoxyVerb}
