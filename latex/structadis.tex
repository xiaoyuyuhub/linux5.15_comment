This lock is used by all \char`\"{}adis\+\_\+\{functions\}\char`\"{} that have to read/write registers. These functions also have unlocked variants (see \char`\"{}\+\_\+\+\_\+adis\+\_\+\{functions\}\char`\"{}), which don\textquotesingle{}t hold this lock.
