\doxysubsection{Detailed Description}
\mbox{\hyperlink{classThe}{The}} C\+PU requests the B\+P\+MP to perform a particular service by sending it an I\+VC frame containing a single M\+RQ message. An M\+RQ message consists of a \mbox{\hyperlink{structmrq__request}{mrq\+\_\+request}} followed by a payload whose format depends on \mbox{\hyperlink{structmrq__request_ae1e703f5c6485ac5122f70a6a0590b97}{mrq\+\_\+request\+::mrq}}.

\mbox{\hyperlink{classThe}{The}} B\+P\+MP processes the data and replies with an I\+VC frame (on the same I\+VC channel) containing and M\+RQ response. An M\+RQ response consists of a \mbox{\hyperlink{structmrq__response}{mrq\+\_\+response}} followed by a payload whose format depends on the associated \mbox{\hyperlink{structmrq__request_ae1e703f5c6485ac5122f70a6a0590b97}{mrq\+\_\+request\+::mrq}}.

A well-\/defined subset of the M\+RQ messages that the C\+PU sends to the B\+P\+MP can lead to B\+P\+MP eventually sending an M\+RQ message to the C\+PU. For example, when the C\+PU uses an \mbox{\hyperlink{group__MRQ__Codes_ga1ae2e7acc9142340c84892200c4e53ec}{M\+R\+Q\+\_\+\+T\+H\+E\+R\+M\+AL}} message to set a thermal trip point, the B\+P\+MP may eventually send a single \mbox{\hyperlink{group__MRQ__Codes_ga1ae2e7acc9142340c84892200c4e53ec}{M\+R\+Q\+\_\+\+T\+H\+E\+R\+M\+AL}} message of its own to the C\+PU indicating that the trip point has been crossed.
