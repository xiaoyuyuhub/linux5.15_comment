\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structscmi__sensor__proto__ops}{scmi\+\_\+sensor\+\_\+proto\+\_\+ops}} -\/ represents the various operations provided by S\+C\+MI Sensor Protocol

@count\+\_\+get\+: get the count of sensors provided by S\+C\+MI @info\+\_\+get\+: get the information of the specified sensor @trip\+\_\+point\+\_\+config\+: selects and configures a trip-\/point of interest @reading\+\_\+get\+: gets the current value of the sensor @reading\+\_\+get\+\_\+timestamped\+: gets the current value and timestamp, when available, of the sensor. (as of v3.\+0 spec) Supports multi-\/axis sensors for sensors which supports it and if the @reading array size of @count entry equals the sensor num\+\_\+axis @config\+\_\+get\+: Get sensor current configuration @config\+\_\+set\+: Set sensor current configuration
