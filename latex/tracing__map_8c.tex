Creates and sets up a map to contain 2 $\ast$$\ast$ map\+\_\+bits number of elements (internally maintained as \textquotesingle{}max\+\_\+elts\textquotesingle{} in struct \mbox{\hyperlink{structtracing__map}{tracing\+\_\+map}}). Before using, map fields should be added to the map with \mbox{\hyperlink{tracing__map_8c_a080c3bc934c7fe4cce9abebfee8922bb}{tracing\+\_\+map\+\_\+add\+\_\+sum\+\_\+field()}} and \mbox{\hyperlink{tracing__map_8c_a2ce70b992c976ea46f27a5b6773f8d9d}{tracing\+\_\+map\+\_\+add\+\_\+key\+\_\+field()}}. \mbox{\hyperlink{tracing__map_8c_a4fcdd469dd754bfcd72f5e2a34908554}{tracing\+\_\+map\+\_\+init()}} should then be called to allocate the array of tracing\+\_\+map\+\_\+elts, in order to avoid allocating anything in the map insertion path. \mbox{\hyperlink{classThe}{The}} user-\/specified map size reflects the maximum number of elements that can be contained in the table requested by the user -\/ internally we double that in order to keep the table sparse and keep collisions manageable.

A \mbox{\hyperlink{structtracing__map}{tracing\+\_\+map}} is a special-\/purpose map designed to aggregate or \textquotesingle{}sum\textquotesingle{} one or more values associated with a specific object of type \mbox{\hyperlink{structtracing__map__elt}{tracing\+\_\+map\+\_\+elt}}, which is attached by the map to a given key.

\mbox{\hyperlink{tracing__map_8c_a916d3ca7165a35e7268721ffe96249ac}{tracing\+\_\+map\+\_\+create()}} sets up the map itself, and provides operations for inserting tracing\+\_\+map\+\_\+elts, but doesn\textquotesingle{}t allocate the tracing\+\_\+map\+\_\+elts themselves, or provide a means for describing the keys or sums associated with the tracing\+\_\+map\+\_\+elts. All tracing\+\_\+map\+\_\+elts for a given map have the same set of sums and keys, which are defined by the client using the functions \mbox{\hyperlink{tracing__map_8c_a2ce70b992c976ea46f27a5b6773f8d9d}{tracing\+\_\+map\+\_\+add\+\_\+key\+\_\+field()}} and \mbox{\hyperlink{tracing__map_8c_a080c3bc934c7fe4cce9abebfee8922bb}{tracing\+\_\+map\+\_\+add\+\_\+sum\+\_\+field()}}.
