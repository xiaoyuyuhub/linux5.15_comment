sort\+\_\+r -\/ sort an array of elements @base\+: pointer to data to sort @num\+: number of elements @size\+: size of each element @cmp\+\_\+func\+: pointer to comparison function @swap\+\_\+func\+: pointer to swap function or N\+U\+LL @priv\+: third argument passed to comparison function

This function does a heapsort on the given array. You may provide a swap\+\_\+func function if you need to do something more than a memory copy (e.\+g. fix up pointers or auxiliary data), but the built-\/in swap avoids a slow retpoline and so is significantly faster.
