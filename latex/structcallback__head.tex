\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structcallback__head}{callback\+\_\+head}} -\/ callback structure for use with R\+CU and task\+\_\+work @next\+: next update requests in a list @func\+: actual update function to call after the grace period.

\mbox{\hyperlink{classThe}{The}} struct is aligned to size of pointer. On most architectures it happens naturally due A\+BI requirements, but some architectures (like C\+R\+IS) have weird A\+BI and we need to ask it explicitly.

\mbox{\hyperlink{classThe}{The}} alignment is required to guarantee that bit 0 of @next will be clear under normal conditions -- as long as we use \mbox{\hyperlink{tiny_8c_a094a548179ef967658b67414a0c91d32}{call\+\_\+rcu()}} or \mbox{\hyperlink{srcutiny_8c_a5e78f1e39878d4f7ed37018fd66f8a50}{call\+\_\+srcu()}} to queue the callback.

This guarantee is important for few reasons\+:
\begin{DoxyItemize}
\item future call\+\_\+rcu\+\_\+lazy() will make use of lower bits in the pointer;
\item the structure shares storage space in struct page with @compound\+\_\+head, which encode \mbox{\hyperlink{page-flags_8h_a12f7cad6c9f968ccb9de080504517a8d}{Page\+Tail()}} in bit 0. \mbox{\hyperlink{classThe}{The}} guarantee is needed to avoid false-\/positive \mbox{\hyperlink{page-flags_8h_a12f7cad6c9f968ccb9de080504517a8d}{Page\+Tail()}}. 
\end{DoxyItemize}
