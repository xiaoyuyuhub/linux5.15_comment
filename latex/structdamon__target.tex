\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdamon__target}{damon\+\_\+target}} -\/ Represents a monitoring target. @id\+: Unique identifier for this target. @nr\+\_\+regions\+: Number of monitoring target regions of this target. @regions\+\_\+list\+: Head of the monitoring target regions of this target. @list\+: List head for siblings.

Each monitoring context could have multiple targets. For example, a context for virtual memory address spaces could have multiple target processes. \mbox{\hyperlink{classThe}{The}} @id of each target should be unique among the targets of the context. For example, in the virtual address monitoring context, it could be a pidfd or an address of an \mbox{\hyperlink{structmm__struct}{mm\+\_\+struct}}.
