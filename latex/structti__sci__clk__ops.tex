\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structti__sci__clk__ops}{ti\+\_\+sci\+\_\+clk\+\_\+ops}} -\/ Clock control operations @get\+\_\+clock\+: Request for activation of clock and manage by processor
\begin{DoxyItemize}
\item needs\+\_\+ssc\+: \textquotesingle{}true\textquotesingle{} if Spread Spectrum clock is desired.
\item can\+\_\+change\+\_\+freq\+: \textquotesingle{}true\textquotesingle{} if frequency change is desired.
\item enable\+\_\+input\+\_\+term\+: \textquotesingle{}true\textquotesingle{} if input termination is desired. @idle\+\_\+clock\+: Request for Idling a clock managed by processor @put\+\_\+clock\+: Release the clock to be auto managed by T\+I\+S\+CI @is\+\_\+auto\+: Is the clock being auto managed
\item req\+\_\+state\+: state indicating if the clock is auto managed @is\+\_\+on\+: Is the clock ON
\item req\+\_\+state\+: if the clock is requested to be forced ON
\item current\+\_\+state\+: if the clock is currently ON @is\+\_\+off\+: Is the clock O\+FF
\item req\+\_\+state\+: if the clock is requested to be forced O\+FF
\item current\+\_\+state\+: if the clock is currently Gated @set\+\_\+parent\+: Set the clock source of a specific device clock
\item parent\+\_\+id\+: Parent clock identifier to set. @get\+\_\+parent\+: Get the current clock source of a specific device clock
\item parent\+\_\+id\+: Parent clock identifier which is the parent. @get\+\_\+num\+\_\+parents\+: Get the number of parents of the current clock source
\item num\+\_\+parents\+: returns the number of parent clocks. @get\+\_\+best\+\_\+match\+\_\+freq\+: Find a best matching frequency for a frequency range.
\item match\+\_\+freq\+: Best matching frequency in Hz. @set\+\_\+freq\+: Set the Clock frequency @get\+\_\+freq\+: Get the Clock frequency
\item current\+\_\+freq\+: Frequency in Hz that the clock is at.
\end{DoxyItemize}

N\+O\+TE\+: for all these functions, the following parameters are generic in nature\+: -\/handle\+: Pointer to T\+I\+S\+CI handle as retrieved by $\ast$ti\+\_\+sci\+\_\+get\+\_\+handle -\/did\+: \mbox{\hyperlink{classDevice}{Device}} identifier this request is for -\/cid\+: Clock identifier for the device for this request. Each device has it\textquotesingle{}s own set of clock inputs. This indexes which clock input to modify. -\/min\+\_\+freq\+: \mbox{\hyperlink{classThe}{The}} minimum allowable frequency in Hz. This is the minimum allowable programmed frequency and does not account for clock tolerances and jitter. -\/target\+\_\+freq\+: \mbox{\hyperlink{classThe}{The}} target clock frequency in Hz. A frequency will be processed as close to this target frequency as possible. -\/max\+\_\+freq\+: \mbox{\hyperlink{classThe}{The}} maximum allowable frequency in Hz. This is the maximum allowable programmed frequency and does not account for clock tolerances and jitter.

Request for the clock -\/ N\+O\+TE\+: the client M\+U\+ST maintain integrity of usage count by balancing get\+\_\+clock with put\+\_\+clock. No refcounting is managed by driver for that purpose.
