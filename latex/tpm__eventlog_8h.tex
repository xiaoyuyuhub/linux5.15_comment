\mbox{\hyperlink{classThe}{The}} T\+P\+M2 event log format can contain multiple digests corresponding to separate P\+CR banks, and also \mbox{\hyperlink{protocolcontains-p}{contains}} a variable length of the data that was measured. This requires knowledge of how long each digest type is, and this information is contained within the first event in the log.

We calculate the length by examining the number of events, and then looking at each event in turn to determine how much space is used for events in total. Once we\textquotesingle{}ve done this we know the offset of the data length field, and can calculate the total size of the event.
