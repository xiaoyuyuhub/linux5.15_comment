\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structv4l2__subdev__tuner__ops}{v4l2\+\_\+subdev\+\_\+tuner\+\_\+ops}} -\/ Callbacks used when v4l device was opened in radio mode.

@standby\+: puts the tuner in standby mode. It will be woken up automatically the next time it is used.

@s\+\_\+radio\+: callback that switches the tuner to radio mode. drivers should explicitly call it when a tuner ops should operate on radio mode, before being able to handle it. Used on devices that have both A\+M/\+FM radio receiver and TV.

@s\+\_\+frequency\+: callback for \mbox{\hyperlink{uapi_2linux_2videodev2_8h_a41d9a450e5a2f4610f1a47b0a3ba898c}{V\+I\+D\+I\+O\+C\+\_\+\+S\+\_\+\+F\+R\+E\+Q\+U\+E\+N\+C\+Y()}} ioctl handler code.

@g\+\_\+frequency\+: callback for \mbox{\hyperlink{uapi_2linux_2videodev2_8h_aef00b42ea83790c7a91324f177a045a7}{V\+I\+D\+I\+O\+C\+\_\+\+G\+\_\+\+F\+R\+E\+Q\+U\+E\+N\+C\+Y()}} ioctl handler code. freq-\/$>$type must be filled in. Normally done by \mbox{\hyperlink{v4l2-ioctl_8h_a7e1fa58443a4eb8135b71abbf90c68ed}{video\+\_\+ioctl2()}} or the bridge driver.

@enum\+\_\+freq\+\_\+bands\+: callback for \mbox{\hyperlink{uapi_2linux_2videodev2_8h_a45abdb93932ec7c3729c2f9290634b2b}{V\+I\+D\+I\+O\+C\+\_\+\+E\+N\+U\+M\+\_\+\+F\+R\+E\+Q\+\_\+\+B\+A\+N\+D\+S()}} ioctl handler code.

@g\+\_\+tuner\+: callback for \mbox{\hyperlink{uapi_2linux_2videodev2_8h_a45d229596a3cc4761cf0340457c3369a}{V\+I\+D\+I\+O\+C\+\_\+\+G\+\_\+\+T\+U\+N\+E\+R()}} ioctl handler code.

@s\+\_\+tuner\+: callback for \mbox{\hyperlink{uapi_2linux_2videodev2_8h_ac44ea5a7701e74861b3413b9d5f28c9d}{V\+I\+D\+I\+O\+C\+\_\+\+S\+\_\+\+T\+U\+N\+E\+R()}} ioctl handler code. @vt-\/$>$type must be filled in. Normally done by video\+\_\+ioctl2 or the bridge driver.

@g\+\_\+modulator\+: callback for \mbox{\hyperlink{uapi_2linux_2videodev2_8h_a37be047959ac0633511003b4c556e2e1}{V\+I\+D\+I\+O\+C\+\_\+\+G\+\_\+\+M\+O\+D\+U\+L\+A\+T\+O\+R()}} ioctl handler code.

@s\+\_\+modulator\+: callback for \mbox{\hyperlink{uapi_2linux_2videodev2_8h_a75b4757681a3959595ebfd8714617ef5}{V\+I\+D\+I\+O\+C\+\_\+\+S\+\_\+\+M\+O\+D\+U\+L\+A\+T\+O\+R()}} ioctl handler code.

@s\+\_\+type\+\_\+addr\+: sets tuner type and its I2C addr.

@s\+\_\+config\+: sets tda9887 specific stuff, like port1, port2 and qss

.. note\+:\+:

On devices that have both A\+M/\+FM and TV, it is up to the driver to explicitly call s\+\_\+radio when the tuner should be switched to radio mode, before handling other \&struct \mbox{\hyperlink{structv4l2__subdev__tuner__ops}{v4l2\+\_\+subdev\+\_\+tuner\+\_\+ops}} that would require it. An example of such usage is\+:\+:
