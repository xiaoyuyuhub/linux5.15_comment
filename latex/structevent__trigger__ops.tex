\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structevent__trigger__ops}{event\+\_\+trigger\+\_\+ops}} -\/ callbacks for trace event triggers

\mbox{\hyperlink{classThe}{The}} methods in this structure provide per-\/event trigger hooks for various trigger operations.

All the methods below, except for @init() and @free(), must be implemented.

@func\+: \mbox{\hyperlink{classThe}{The}} trigger \textquotesingle{}probe\textquotesingle{} function called when the triggering event occurs. \mbox{\hyperlink{classThe}{The}} data passed into this callback is the data that was supplied to the \mbox{\hyperlink{structevent__command}{event\+\_\+command}} @reg() function that registered the trigger (see struct \mbox{\hyperlink{structevent__command}{event\+\_\+command}}) along with the trace record, rec.

@init\+: An optional initialization function called for the trigger when the trigger is registered (via the \mbox{\hyperlink{structevent__command}{event\+\_\+command}} \mbox{\hyperlink{calling_8h_a01b09d0d2ab1d928b97bc4d419a6f65e}{reg()}} function). This can be used to perform per-\/trigger initialization such as incrementing a per-\/trigger reference count, for instance. This is usually implemented by the generic utility function @event\+\_\+trigger\+\_\+init() (see trace\+\_\+event\+\_\+triggers.\+c).

@free\+: An optional de-\/initialization function called for the trigger when the trigger is unregistered (via the \mbox{\hyperlink{structevent__command}{event\+\_\+command}} @reg() function). This can be used to perform per-\/trigger de-\/initialization such as decrementing a per-\/trigger reference count and freeing corresponding trigger data, for instance. This is usually implemented by the generic utility function @event\+\_\+trigger\+\_\+free() (see trace\+\_\+event\+\_\+triggers.\+c).

@print\+: \mbox{\hyperlink{classThe}{The}} callback function invoked to have the trigger print itself. This is usually implemented by a wrapper function that calls the generic utility function @event\+\_\+trigger\+\_\+print() (see trace\+\_\+event\+\_\+triggers.\+c).
