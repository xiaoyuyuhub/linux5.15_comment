\mbox{\hyperlink{cordic_8h_a732e351d9cad4505a512a608df62be2c}{cordic\+\_\+calc\+\_\+iq()}} -\/ calculates the i/q coordinate for given angle.

@theta\+: angle in degrees for which i/q coordinate is to be calculated. @coord\+: function output parameter holding the i/q coordinate.

\mbox{\hyperlink{classThe}{The}} function calculates the i/q coordinate for a given angle using the C\+O\+R\+D\+IC algorithm. \mbox{\hyperlink{classThe}{The}} coordinate consists of a real (i) and an imaginary (q) part. \mbox{\hyperlink{classThe}{The}} real part is essentially the cosine of the angle and the imaginary part is the sine of the angle. \mbox{\hyperlink{classThe}{The}} returned values are scaled by 2$^\wedge$16 for precision. \mbox{\hyperlink{classThe}{The}} range for theta is for -\/180 degrees to +180 degrees. Passed values outside this range are converted before doing the actual calculation.
