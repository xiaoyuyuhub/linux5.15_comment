\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structfw__cdev__queue__iso}{fw\+\_\+cdev\+\_\+queue\+\_\+iso}} -\/ Queue isochronous packets for I/O @packets\+: Userspace pointer to an array of \&\mbox{\hyperlink{structfw__cdev__iso__packet}{fw\+\_\+cdev\+\_\+iso\+\_\+packet}} @data\+: Pointer into mmap()\textquotesingle{}ed payload buffer @size\+: Size of the @packets array, in bytes @handle\+: Isochronous context handle

Queue a number of isochronous packets for reception or transmission. This ioctl takes a pointer to an array of \&\mbox{\hyperlink{structfw__cdev__iso__packet}{fw\+\_\+cdev\+\_\+iso\+\_\+packet}} structs, which describe how to transmit from or receive into a contiguous region of a mmap()\textquotesingle{}ed payload buffer. As part of transmit packet descriptors, a series of headers can be supplied, which will be prepended to the payload during D\+MA.

\mbox{\hyperlink{classThe}{The}} kernel may or may not queue all packets, but will write back updated values of the @packets, @data and @size fields, so the ioctl can be resubmitted easily.

In case of a multichannel receive context, @data must be quadlet-\/aligned relative to the buffer start.
