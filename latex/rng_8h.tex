\mbox{\hyperlink{classThe}{The}} random number generator A\+PI is used with the ciphers of type C\+R\+Y\+P\+T\+O\+\_\+\+A\+L\+G\+\_\+\+T\+Y\+P\+E\+\_\+\+R\+NG (listed as type \char`\"{}rng\char`\"{} in /proc/crypto) \mbox{\hyperlink{rng_8h_a35c55b43b4e847627ce0186520cc4ca2}{crypto\+\_\+alloc\+\_\+rng()}} -- allocate R\+NG handle @alg\+\_\+name\+: is the cra\+\_\+name / name or cra\+\_\+driver\+\_\+name / driver name of the message digest cipher @type\+: specifies the type of the cipher @mask\+: specifies the mask for the cipher

Allocate a cipher handle for a random number generator. \mbox{\hyperlink{classThe}{The}} returned struct \mbox{\hyperlink{structcrypto__rng}{crypto\+\_\+rng}} is the cipher handle that is required for any subsequent A\+PI invocation for that random number generator.
