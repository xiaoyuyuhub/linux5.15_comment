\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__gem__object}{drm\+\_\+gem\+\_\+object}} -\/ G\+EM buffer object

This structure defines the generic parts for G\+EM buffer objects, which are mostly around handling mmap and userspace handles.

Buffer objects are often abbreviated to BO.
