\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structv4l2__file__operations}{v4l2\+\_\+file\+\_\+operations}} -\/ fs operations used by a V4\+L2 device

@owner\+: pointer to struct module @read\+: operations needed to implement the \mbox{\hyperlink{structv4l2__file__operations_a157aa3070a730cfe6b0c243b44eff444}{read()}} syscall @write\+: operations needed to implement the \mbox{\hyperlink{structv4l2__file__operations_a93c02e8b52874c67b5f7c258c71a3164}{write()}} syscall @poll\+: operations needed to implement the \mbox{\hyperlink{structv4l2__file__operations_ac2ec64646b57d32368a1ca6ee93b985d}{poll()}} syscall @unlocked\+\_\+ioctl\+: operations needed to implement the ioctl() syscall @compat\+\_\+ioctl32\+: operations needed to implement the ioctl() syscall for the special case where the Kernel uses 64 bits instructions, but the userspace uses 32 bits. @get\+\_\+unmapped\+\_\+area\+: called by the \mbox{\hyperlink{structv4l2__file__operations_a80f6f2d15977e5563a3ad99212c1a075}{mmap()}} syscall, used when \%!\+C\+O\+N\+F\+I\+G\+\_\+\+M\+MU @mmap\+: operations needed to implement the \mbox{\hyperlink{structv4l2__file__operations_a80f6f2d15977e5563a3ad99212c1a075}{mmap()}} syscall @open\+: operations needed to implement the \mbox{\hyperlink{structv4l2__file__operations_a61ac5c51e16cd935ee541358c7636f92}{open()}} syscall @release\+: operations needed to implement the \mbox{\hyperlink{structv4l2__file__operations_a4fe5fada41884261c7534427920ff545}{release()}} syscall

.. note\+:\+:

Those operations are used to implemente the fs struct \mbox{\hyperlink{structfile__operations}{file\+\_\+operations}} at the V4\+L2 drivers. \mbox{\hyperlink{classThe}{The}} V4\+L2 core overrides the fs ops with some extra logic needed by the subsystem.
