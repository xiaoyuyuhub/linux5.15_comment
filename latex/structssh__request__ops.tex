\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structssh__request__ops}{ssh\+\_\+request\+\_\+ops}} -\/ Callback operations for a S\+SH request. @release\+: Function called when the request\textquotesingle{}s reference count reaches zero. This callback must be relied upon to ensure that the request has left the transport systems (both, packet an request systems). @complete\+: Function called when the request is completed, either with success or failure. \mbox{\hyperlink{classThe}{The}} command data for the request response is provided via the \&struct \mbox{\hyperlink{structssh__command}{ssh\+\_\+command}} parameter ({\ttfamily cmd}), the command payload of the request response via the \&struct ssh\+\_\+span parameter ({\ttfamily data}).

If the request does not have any response or has not been completed with success, both {\ttfamily cmd} and {\ttfamily data} parameters will be N\+U\+LL. If the request response does not have any command payload, the {\ttfamily data} span will be an empty (zero-\/length) span.

In case of failure, the reason for the failure is indicated by the value of the provided status code argument ({\ttfamily status}). This value will be zero in case of success and a regular errno otherwise.

Note that a call to this callback does not guarantee that the request is not in use by the transport systems any more.
