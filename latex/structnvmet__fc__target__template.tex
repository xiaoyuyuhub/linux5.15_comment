\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structnvmet__fc__target__template}{nvmet\+\_\+fc\+\_\+target\+\_\+template}} -\/ structure containing static entrypoints and operational parameters for an L\+L\+DD that supports N\+V\+ME subsystem behavior. Passed by reference in port registrations. N\+V\+M\+E-\/\+FC transport remembers template reference and may access it during runtime operation.

Subsystem/\+Target Transport Entrypoints/\+Parameters\+:

@targetport\+\_\+delete\+: \mbox{\hyperlink{classThe}{The}} L\+L\+DD initiates deletion of a targetport via \mbox{\hyperlink{nvme-fc-driver_8h_a6f9be064297981f99b31a335db675501}{nvmet\+\_\+fc\+\_\+unregister\+\_\+targetport()}}. However, the teardown is asynchronous. This routine is called upon the completion of the teardown to inform the L\+L\+DD that the targetport has been deleted. Entrypoint is Mandatory.

@xmt\+\_\+ls\+\_\+rsp\+: Called to transmit the response to a F\+C-\/\+N\+V\+ME F\+C-\/4 LS service. \mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structnvmefc__ls__rsp}{nvmefc\+\_\+ls\+\_\+rsp}} structure is the same L\+L\+D\+D-\/supplied exchange structure specified in the \mbox{\hyperlink{nvme-fc-driver_8h_acfb18f4f882584bb674c5b0a83902332}{nvmet\+\_\+fc\+\_\+rcv\+\_\+ls\+\_\+req()}} call made when the LS request was received. \mbox{\hyperlink{classThe}{The}} structure will fully describe the buffers for the response payload and the dma address of the payload. \mbox{\hyperlink{classThe}{The}} L\+L\+DD is to transmit the response (or return a non-\/zero errno status), and upon completion of the transmit, call the \char`\"{}done\char`\"{} routine specified in the \mbox{\hyperlink{structnvmefc__ls__rsp}{nvmefc\+\_\+ls\+\_\+rsp}} structure (argument to done is the address of the \mbox{\hyperlink{structnvmefc__ls__rsp}{nvmefc\+\_\+ls\+\_\+rsp}} structure itself). Upon the completion of the \mbox{\hyperlink{preemptirq__delay__test_8c_abbff772932f6fec6c7cce983c6796257}{done()}} routine, the L\+L\+DD shall consider the LS handling complete and the \mbox{\hyperlink{structnvmefc__ls__rsp}{nvmefc\+\_\+ls\+\_\+rsp}} structure may be freed/released. \mbox{\hyperlink{classThe}{The}} transport will always call the \mbox{\hyperlink{structnvmet__fc__target__template_a59f73be1abc915e170fd2aae8341beec}{xmt\+\_\+ls\+\_\+rsp()}} routine for any LS received. Entrypoint is Mandatory.

@fcp\+\_\+op\+: Called to perform a data transfer or transmit a response. \mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structnvmefc__tgt__fcp__req}{nvmefc\+\_\+tgt\+\_\+fcp\+\_\+req}} structure is the same L\+L\+D\+D-\/supplied exchange structure specified in the \mbox{\hyperlink{nvme-fc-driver_8h_a3e0a6b901422268dac2c3b786087cf67}{nvmet\+\_\+fc\+\_\+rcv\+\_\+fcp\+\_\+req()}} call made when the F\+CP C\+MD IU was received. \mbox{\hyperlink{classThe}{The}} op field in the structure shall indicate the operation for the L\+L\+DD to perform relative to the io. N\+V\+M\+E\+T\+\_\+\+F\+C\+O\+P\+\_\+\+R\+E\+A\+D\+D\+A\+TA operation\+: the L\+L\+DD is to send the payload data (described by sglist) to the host in 1 or more FC sequences (preferrably 1). Note\+: the fc-\/nvme layer may call the R\+E\+A\+D\+D\+A\+TA operation multiple times for longer payloads. N\+V\+M\+E\+T\+\_\+\+F\+C\+O\+P\+\_\+\+W\+R\+I\+T\+E\+D\+A\+TA operation\+: the L\+L\+DD is to receive the payload data (described by sglist) from the host via 1 or more FC sequences (preferrably 1). \mbox{\hyperlink{classThe}{The}} L\+L\+DD is to generate the X\+F\+E\+R\+\_\+\+R\+DY I\+U(s) corresponding to the data being requested. Note\+: the F\+C-\/\+N\+V\+ME layer may call the W\+R\+I\+T\+E\+D\+A\+TA operation multiple times for longer payloads. N\+V\+M\+E\+T\+\_\+\+F\+C\+O\+P\+\_\+\+R\+E\+A\+D\+D\+A\+T\+A\+\_\+\+R\+SP operation\+: the L\+L\+DD is to send the payload data (described by sglist) to the host in 1 or more FC sequences (preferrably 1). If an error occurs during payload data transmission, the L\+L\+DD is to set the \mbox{\hyperlink{structnvmefc__tgt__fcp__req}{nvmefc\+\_\+tgt\+\_\+fcp\+\_\+req}} fcp\+\_\+error and transferred\+\_\+length field, then consider the operation complete. On error, the L\+L\+DD is to not transmit the F\+C\+P\+\_\+\+R\+SP iu. If all payload data is transferred successfully, the L\+L\+DD is to update the \mbox{\hyperlink{structnvmefc__tgt__fcp__req}{nvmefc\+\_\+tgt\+\_\+fcp\+\_\+req}} transferred\+\_\+length field and may subsequently transmit the F\+C\+P\+\_\+\+R\+SP iu payload (described by rspbuf, rspdma, rsplen). If F\+C\+P\+\_\+\+C\+O\+NF is supported, the L\+L\+DD is to await F\+C\+P\+\_\+\+C\+O\+NF reception to confirm the R\+SP reception by the host. \mbox{\hyperlink{classThe}{The}} L\+L\+DD may retramsit the F\+C\+P\+\_\+\+R\+SP iu if necessary per F\+C-\/\+N\+V\+ME. Upon transmission of the F\+C\+P\+\_\+\+R\+SP iu if F\+C\+P\+\_\+\+C\+O\+NF is not supported, or upon success/failure of F\+C\+P\+\_\+\+C\+O\+NF if it is supported, the L\+L\+DD is to set the \mbox{\hyperlink{structnvmefc__tgt__fcp__req}{nvmefc\+\_\+tgt\+\_\+fcp\+\_\+req}} fcp\+\_\+error field and consider the operation complete. N\+V\+M\+E\+T\+\_\+\+F\+C\+O\+P\+\_\+\+R\+SP\+: the L\+L\+DD is to transmit the F\+C\+P\+\_\+\+R\+SP iu payload (described by rspbuf, rspdma, rsplen). If F\+C\+P\+\_\+\+C\+O\+NF is supported, the L\+L\+DD is to await F\+C\+P\+\_\+\+C\+O\+NF reception to confirm the R\+SP reception by the host. \mbox{\hyperlink{classThe}{The}} L\+L\+DD may retramsit the F\+C\+P\+\_\+\+R\+SP iu if F\+C\+P\+\_\+\+C\+O\+NF is not received per F\+C-\/\+N\+V\+ME. Upon transmission of the F\+C\+P\+\_\+\+R\+SP iu if F\+C\+P\+\_\+\+C\+O\+NF is not supported, or upon success/failure of F\+C\+P\+\_\+\+C\+O\+NF if it is supported, the L\+L\+DD is to set the \mbox{\hyperlink{structnvmefc__tgt__fcp__req}{nvmefc\+\_\+tgt\+\_\+fcp\+\_\+req}} fcp\+\_\+error field and consider the operation complete. Upon completing the indicated operation, the L\+L\+DD is to set the status fields for the operation (tranferred\+\_\+length and fcp\+\_\+error status) in the request, then call the \char`\"{}done\char`\"{} routine indicated in the fcp request. After the operation completes, regardless of whether the F\+C\+P\+\_\+\+R\+SP iu was successfully transmit, the L\+L\+D\+D-\/supplied exchange structure must remain valid until the transport calls the \mbox{\hyperlink{structnvmet__fc__target__template_a2072b37d4001b29f3aa427c65e5b1ce9}{fcp\+\_\+req\+\_\+release()}} callback to return ownership of the exchange structure back to the L\+L\+DD so that it may be used for another fcp command. Note\+: when calling the done routine for R\+E\+A\+D\+D\+A\+TA or W\+R\+I\+T\+E\+D\+A\+TA operations, the fc-\/nvme layer may immediate convert, in the same thread and before returning to the L\+L\+DD, the fcp operation to the next operation for the fcp io and call the L\+L\+D\+Ds fcp\+\_\+op call again. If fields in the fcp request are to be accessed post the done call, the L\+L\+DD should save their values prior to calling the done routine, and inspect the save values after the done routine. Returns 0 on success, -\/$<$errno$>$ on failure (Ex\+: -\/E\+IO) Entrypoint is Mandatory.

@fcp\+\_\+abort\+: Called by the transport to abort an active command. \mbox{\hyperlink{classThe}{The}} command may be in-\/between operations (nothing active in L\+L\+DD) or may have an active W\+R\+I\+T\+E\+D\+A\+TA operation pending. \mbox{\hyperlink{classThe}{The}} L\+L\+DD is to initiate the A\+B\+TS process for the command and return from the callback. \mbox{\hyperlink{classThe}{The}} A\+B\+TS does not need to be complete on the command. \mbox{\hyperlink{classThe}{The}} fcp\+\_\+abort callback inherently cannot fail. After the \mbox{\hyperlink{structnvmet__fc__target__template_ad3740b81711c8ac091284938c97dc4e2}{fcp\+\_\+abort()}} callback completes, the transport will wait for any outstanding operation (if there was one) to complete, then will call the \mbox{\hyperlink{structnvmet__fc__target__template_a2072b37d4001b29f3aa427c65e5b1ce9}{fcp\+\_\+req\+\_\+release()}} callback to return the command\textquotesingle{}s exchange context back to the L\+L\+DD. Entrypoint is Mandatory.

@fcp\+\_\+req\+\_\+release\+: Called by the transport to return a \mbox{\hyperlink{structnvmefc__tgt__fcp__req}{nvmefc\+\_\+tgt\+\_\+fcp\+\_\+req}} to the L\+L\+DD after all operations on the fcp operation are complete. This may be due to the command completing or upon completion of abort cleanup. Entrypoint is Mandatory.

@defer\+\_\+rcv\+: Called by the transport to signal the L\+L\+LD that it has begun processing of a previously received N\+V\+ME C\+MD IU. \mbox{\hyperlink{classThe}{The}} L\+L\+DD is now free to re-\/use the rcv buffer associated with the \mbox{\hyperlink{structnvmefc__tgt__fcp__req}{nvmefc\+\_\+tgt\+\_\+fcp\+\_\+req}}. Entrypoint is Optional.

@discovery\+\_\+event\+: Called by the transport to generate an R\+S\+CN change notifications to N\+V\+ME initiators. \mbox{\hyperlink{classThe}{The}} R\+S\+CN notifications should cause the initiator to rescan the discovery controller on the targetport.

@ls\+\_\+req\+: Called to issue a F\+C-\/\+N\+V\+ME F\+C-\/4 LS service request. \mbox{\hyperlink{classThe}{The}} nvme\+\_\+fc\+\_\+ls\+\_\+req structure will fully describe the buffers for the request payload and where to place the response payload. \mbox{\hyperlink{classThe}{The}} targetport that is to issue the LS request is identified by the targetport argument. \mbox{\hyperlink{classThe}{The}} remote port that is to receive the LS request is identified by the hosthandle argument. \mbox{\hyperlink{classThe}{The}} nvmet-\/fc transport is only allowed to issue F\+C-\/\+N\+V\+ME LS\textquotesingle{}s on behalf of an association that was created prior by a Create Association LS. \mbox{\hyperlink{classThe}{The}} hosthandle will originate from the L\+L\+DD in the struct \mbox{\hyperlink{structnvmefc__ls__rsp}{nvmefc\+\_\+ls\+\_\+rsp}} structure for the Create Association LS that was delivered to the transport. \mbox{\hyperlink{classThe}{The}} transport will save the hosthandle as an attribute of the association. If the L\+L\+DD loses connectivity with the remote port, it must call the \mbox{\hyperlink{nvme-fc-driver_8h_a1b1a7d6e68273f02bba21455b902c8c3}{nvmet\+\_\+fc\+\_\+invalidate\+\_\+host()}} routine to remove any references to the remote port in the transport. \mbox{\hyperlink{classThe}{The}} L\+L\+DD is to allocate an exchange, issue the LS request, obtain the LS response, and call the \char`\"{}done\char`\"{} routine specified in the request structure (argument to done is the ls request structure itself). Entrypoint is Optional -\/ but highly recommended.

@ls\+\_\+abort\+: called to request the L\+L\+DD to abort the indicated ls request. \mbox{\hyperlink{classThe}{The}} call may return before the abort has completed. After aborting the request, the L\+L\+DD must still call the ls request done routine indicating an FC transport Aborted status. Entrypoint is Mandatory if the ls\+\_\+req entry point is specified.

@host\+\_\+release\+: called to inform the L\+L\+DD that the request to invalidate the host port indicated by the hosthandle has been fully completed. No associations exist with the host port and there will be no further references to hosthandle. Entrypoint is Mandatory if the lldd calls \mbox{\hyperlink{nvme-fc-driver_8h_a1b1a7d6e68273f02bba21455b902c8c3}{nvmet\+\_\+fc\+\_\+invalidate\+\_\+host()}}.

@max\+\_\+hw\+\_\+queues\+: indicates the maximum number of hw queues the L\+L\+DD supports for cpu affinitization. Value is Mandatory. Must be at least 1.

@max\+\_\+sgl\+\_\+segments\+: indicates the maximum number of sgl segments supported by the L\+L\+DD Value is Mandatory. Must be at least 1. Recommend at least 256.

@max\+\_\+dif\+\_\+sgl\+\_\+segments\+: indicates the maximum number of sgl segments supported by the L\+L\+DD for D\+IF operations. Value is Mandatory. Must be at least 1. Recommend at least 256.

@dma\+\_\+boundary\+: indicates the dma address boundary where dma mappings will be split across. Value is Mandatory. Typical value is 0x\+F\+F\+F\+F\+F\+F\+FF to split across 4Gig address boundarys

@target\+\_\+features\+: \mbox{\hyperlink{classThe}{The}} L\+L\+DD sets bits in this field to correspond to optional features that are supported by the L\+L\+DD. Refer to the N\+V\+M\+E\+T\+\_\+\+F\+C\+T\+G\+T\+F\+E\+A\+T\+\_\+xxx values. Value is Mandatory. Allowed to be zero.

@target\+\_\+priv\+\_\+sz\+: \mbox{\hyperlink{classThe}{The}} L\+L\+DD sets this field to the amount of additional memory that it would like fc nvme layer to allocate on the L\+L\+DD\textquotesingle{}s behalf whenever a targetport is allocated. \mbox{\hyperlink{classThe}{The}} additional memory area solely for the of the L\+L\+DD and its location is specified by the targetport-\/$>$private pointer. Value is Mandatory. Allowed to be zero.

@lsrqst\+\_\+priv\+\_\+sz\+: \mbox{\hyperlink{classThe}{The}} L\+L\+DD sets this field to the amount of additional memory that it would like nvmet-\/fc layer to allocate on the L\+L\+DD\textquotesingle{}s behalf whenever a ls request structure is allocated. \mbox{\hyperlink{classThe}{The}} additional memory area is solely for use by the L\+L\+DD and its location is specified by the ls\+\_\+request-\/$>$private pointer. Value is Mandatory. Allowed to be zero.
