\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structclk__notifier__data}{clk\+\_\+notifier\+\_\+data}} -\/ rate data to pass to the notifier callback @clk\+: struct clk $\ast$ being changed @old\+\_\+rate\+: previous rate of this clk @new\+\_\+rate\+: new rate of this clk

For a pre-\/notifier, old\+\_\+rate is the clk\textquotesingle{}s rate before this rate change, and new\+\_\+rate is what the rate will be in the future.
