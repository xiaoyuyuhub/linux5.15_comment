\doxysubsection{Detailed Description}
V\+F\+I\+O\+\_\+\+D\+E\+V\+I\+C\+E\+\_\+\+I\+O\+E\+V\+E\+N\+T\+FD -\/ \+\_\+\+I\+OW(V\+F\+I\+O\+\_\+\+T\+Y\+PE, V\+F\+I\+O\+\_\+\+B\+A\+SE + 16, struct \mbox{\hyperlink{structvfio__device__ioeventfd}{vfio\+\_\+device\+\_\+ioeventfd}})

Perform a write to the device at the specified device fd offset, with the specified data and width when the provided eventfd is triggered. vfio bus drivers may not support this for all regions, for all widths, or at all. vfio-\/pci currently only enables support for B\+AR regions, excluding the M\+S\+I-\/X vector table.

Return\+: 0 on success, -\/errno on failure.
