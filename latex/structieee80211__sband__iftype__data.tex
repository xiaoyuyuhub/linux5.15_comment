struct \mbox{\hyperlink{structieee80211__sband__iftype__data}{ieee80211\+\_\+sband\+\_\+iftype\+\_\+data}} -\/ sband data per interface type

This structure encapsulates sband data that is relevant for the interface types defined in @types\+\_\+mask. Each type in the @types\+\_\+mask must be unique across all instances of iftype\+\_\+data.
