\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdelayed__free}{delayed\+\_\+free}} -\/ data structures used for delayed freeing

A data structure for delayed freeing of data structures that may be accessed by R\+CU readers at the time these were freed.

@rcu\+\_\+head\+: Used to schedule an R\+CU callback for freeing data structures. @index\+: Index of @pf to which freed data structures are added. @scheduled\+: Whether or not an R\+CU callback has been scheduled. @pf\+: Array with information about data structures about to be freed.
