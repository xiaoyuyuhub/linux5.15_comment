struct \mbox{\hyperlink{structs3c__fb__platdata}{s3c\+\_\+fb\+\_\+platdata}} -\/ S3C driver platform specific information @setup\+\_\+gpio\+: Setup the external G\+P\+IO pins to the right state to transfer the data from the display system to the connected display device. @vidcon0\+: \mbox{\hyperlink{classThe}{The}} base vidcon0 values to control the panel data format. @vidcon1\+: \mbox{\hyperlink{classThe}{The}} base vidcon1 values to control the panel data output. @vtiming\+: Video timing when connected to a R\+GB type panel. @win\+: \mbox{\hyperlink{classThe}{The}} setup data for each hardware window, or N\+U\+LL for unused. @display\+\_\+mode\+: \mbox{\hyperlink{classThe}{The}} L\+CD output display mode.
