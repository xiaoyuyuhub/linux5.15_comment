\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structmipi__dsi__host__ops}{mipi\+\_\+dsi\+\_\+host\+\_\+ops}} -\/ D\+SI bus operations @attach\+: attach D\+SI device to D\+SI host @detach\+: detach D\+SI device from D\+SI host @transfer\+: transmit a D\+SI packet

D\+SI packets transmitted by .\mbox{\hyperlink{structmipi__dsi__host__ops_a1676b53e79436683de1be06a3ed5fc6c}{transfer()}} are passed in as \mbox{\hyperlink{structmipi__dsi__msg}{mipi\+\_\+dsi\+\_\+msg}} structures. This structure \mbox{\hyperlink{protocolcontains-p}{contains}} information about the type of packet being transmitted as well as the transmit and receive buffers. When an error is encountered during transmission, this function will return a negative error code. On success it shall return the number of bytes transmitted for write packets or the number of bytes received for read packets.

Note that typically D\+SI packet transmission is atomic, so the .\mbox{\hyperlink{structmipi__dsi__host__ops_a1676b53e79436683de1be06a3ed5fc6c}{transfer()}} function will seldomly return anything other than the number of bytes contained in the transmit buffer on success.

Also note that those callbacks can be called no matter the state the host is in. Drivers that need the underlying device to be powered to perform these operations will first need to make sure it\textquotesingle{}s been properly enabled.
