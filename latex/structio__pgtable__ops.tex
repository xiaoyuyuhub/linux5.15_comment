\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structio__pgtable__ops}{io\+\_\+pgtable\+\_\+ops}} -\/ Page table manipulation A\+PI for I\+O\+M\+MU drivers.

@map\+: Map a physically contiguous memory region. @map\+\_\+pages\+: Map a physically contiguous range of pages of the same size. @unmap\+: Unmap a physically contiguous memory region. @unmap\+\_\+pages\+: Unmap a range of virtually contiguous pages of the same size. @iova\+\_\+to\+\_\+phys\+: Translate iova to physical address.

These functions map directly onto the \mbox{\hyperlink{structiommu__ops}{iommu\+\_\+ops}} member functions with the same names.
