struct \mbox{\hyperlink{structnand__nvddr__timings}{nand\+\_\+nvddr\+\_\+timings}} -\/ N\+V-\/\+D\+DR N\+A\+ND chip timings

This struct defines the timing requirements of a N\+V-\/\+D\+DR N\+A\+ND data interface. These information can be found in every N\+A\+ND datasheets and the timings meaning are described in the O\+N\+FI specifications\+: \href{https://media-www.micron.com/-/media/client/onfi/specs/onfi_4_1_gold.pdf}{\texttt{ https\+://media-\/www.\+micron.\+com/-\//media/client/onfi/specs/onfi\+\_\+4\+\_\+1\+\_\+gold.\+pdf}} (chapter 4.\+18.\+2 N\+V-\/\+D\+DR)

All these timings are expressed in picoseconds.
