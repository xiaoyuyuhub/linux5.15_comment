@platform\+\_\+data\+: platform\+\_\+data to assign for matching nodes

This lookup table allows the caller of \mbox{\hyperlink{of__platform_8h_a2e1c692707e2ce8bd588915bf2f09e77}{of\+\_\+platform\+\_\+populate()}} to override the names of devices when creating devices from the device tree. \mbox{\hyperlink{classThe}{The}} table should be terminated with an empty entry. It also allows the platform\+\_\+data pointer to be set.

\mbox{\hyperlink{classThe}{The}} reason for this functionality is that some Linux infrastructure uses the device name to look up a specific device, but the Linux-\/specific names are not encoded into the device tree, so the kernel needs to provide specific values.

Note\+: Using an auxdata lookup table should be considered a last resort when converting a platform to use the DT.
