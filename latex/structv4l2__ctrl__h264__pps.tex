\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structv4l2__ctrl__h264__pps}{v4l2\+\_\+ctrl\+\_\+h264\+\_\+pps}} -\/ H264 picture parameter set

Except where noted, all the members on this picture parameter set structure match the picture parameter set syntax as specified by the H264 specification.

In particular, V4\+L2\+\_\+\+H264\+\_\+\+P\+P\+S\+\_\+\+F\+L\+A\+G\+\_\+\+S\+C\+A\+L\+I\+N\+G\+\_\+\+M\+A\+T\+R\+I\+X\+\_\+\+P\+R\+E\+S\+E\+NT flag has a specific meaning. This flag should be set if a non-\/flat scaling matrix applies to the picture. In this case, applications are expected to use V4\+L2\+\_\+\+C\+I\+D\+\_\+\+S\+T\+A\+T\+E\+L\+E\+S\+S\+\_\+\+H264\+\_\+\+S\+C\+A\+L\+I\+N\+G\+\_\+\+M\+A\+T\+R\+IX, to pass the values of the non-\/flat matrices.
