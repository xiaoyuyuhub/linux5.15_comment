\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdmx__section__filter}{dmx\+\_\+section\+\_\+filter}} -\/ Structure that describes a section filter

@filter\+\_\+value\+: Contains up to 16 bytes (128 bits) of the TS section header that will be matched by the section filter @filter\+\_\+mask\+: Contains a 16 bytes (128 bits) filter mask with the bits specified by @filter\+\_\+value that will be used on the filter match logic. @filter\+\_\+mode\+: Contains a 16 bytes (128 bits) filter mode. @parent\+: Back-\/pointer to struct \mbox{\hyperlink{structdmx__section__feed}{dmx\+\_\+section\+\_\+feed}}. @priv\+: Pointer to private data of the A\+PI client.

\mbox{\hyperlink{classThe}{The}} @filter\+\_\+mask controls which bits of @filter\+\_\+value are compared with the section headers/payload. On a binary value of 1 in filter\+\_\+mask, the corresponding bits are compared. \mbox{\hyperlink{classThe}{The}} filter only accepts sections that are equal to filter\+\_\+value in all the tested bit positions.
