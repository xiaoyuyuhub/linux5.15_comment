Helper macro for mtd blktrans drivers which do not do anything special in module init/exit. This eliminates a lot of boilerplate. Each module may only use this macro once, and calling it replaces \mbox{\hyperlink{include_2linux_2module_8h_a3a0f5631ca99139bac78725694baadaf}{module\+\_\+init()}} and \mbox{\hyperlink{include_2linux_2module_8h_aef89bfe0ab2bd2093c2ee9bc969e0a62}{module\+\_\+exit()}}
