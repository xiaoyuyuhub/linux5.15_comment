Grab the eseq value, and see whether it matches the value that \begin{DoxySince}{Since}
points to. If it does, then just return 0.
\end{DoxySince}
If it doesn\textquotesingle{}t, then the value has changed. Set the \char`\"{}seen\char`\"{} flag, and try to swap it into place as the new eseq value. Then, set that value as the new \char`\"{}since\char`\"{} value, and return whatever the error portion is set to.
