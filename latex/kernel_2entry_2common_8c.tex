enter\+\_\+from\+\_\+user\+\_\+mode -\/ Establish state when coming from user mode

Syscall/interrupt entry disables interrupts, but user mode is traced as interrupts enabled. Also with N\+O\+\_\+\+H\+Z\+\_\+\+F\+U\+LL R\+CU might be idle.

1) Tell lockdep that interrupts are disabled 2) Invoke context tracking if enabled to reactivate R\+CU 3) Trace interrupts off state

Invoked from architecture specific syscall entry code with interrupts disabled. \mbox{\hyperlink{classThe}{The}} calling code has to be non-\/instrumentable. When the function returns all state is correct and interrupts are still disabled. \mbox{\hyperlink{classThe}{The}} subsequent functions can be instrumented.

This is invoked when there is architecture specific functionality to be done between establishing state and enabling interrupts. \mbox{\hyperlink{classThe}{The}} caller must enable interrupts before invoking \mbox{\hyperlink{include_2linux_2entry-common_8h_ace38acc2ca4c6eea00dd9fe9583b8dc6}{syscall\+\_\+enter\+\_\+from\+\_\+user\+\_\+mode\+\_\+work()}}. Invokes\+:
\begin{DoxyItemize}
\item lockdep irqflag state tracking as low level A\+SM entry disabled interrupts.
\item Context tracking if the exception hit user mode.
\item \mbox{\hyperlink{classThe}{The}} hardirq tracer to keep the state consistent as low level A\+SM entry disabled interrupts.

As a precondition, this requires that the entry came from user mode, idle, or a kernel context in which R\+CU is watching.

For kernel mode entries R\+CU handling is done conditional. If R\+CU is watching then the only R\+CU requirement is to check whether the tick has to be restarted. If R\+CU is not watching then \mbox{\hyperlink{tree_8c_a8cebd94ac3da6cb4d6b467e2eb8b0751}{rcu\+\_\+irq\+\_\+enter()}} has to be invoked on entry and \mbox{\hyperlink{tree_8c_a5d2774cea1c93603269f5d4df9adec0f}{rcu\+\_\+irq\+\_\+exit()}} on exit.

Avoiding the rcu\+\_\+irq\+\_\+enter/exit() calls is an optimization but also solves the problem of kernel mode pagefaults which can schedule, which is not possible after invoking \mbox{\hyperlink{tree_8c_a8cebd94ac3da6cb4d6b467e2eb8b0751}{rcu\+\_\+irq\+\_\+enter()}} without undoing it.
