@handle\+: Fence object handle for fence associated with a command submission. @mask\+: Fence flags relevant for this fence object. @seqno\+: Fence sequence number in fifo. A fence object with a lower seqno will signal the E\+X\+EC flag before a fence object with a higher seqno. This can be used by user-\/space to avoid kernel calls to determine whether a fence has signaled the E\+X\+EC flag. Note that @seqno will wrap at 32-\/bit. @passed\+\_\+seqno\+: \mbox{\hyperlink{classThe}{The}} highest seqno number processed by the hardware so far. Use the fence\+\_\+seq member. error == 0\+: All is OK, \mbox{\hyperlink{classThe}{The}} host may not be synchronized. Use the fence\+\_\+seq member.
