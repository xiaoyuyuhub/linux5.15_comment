\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structwatchdog__device}{watchdog\+\_\+device}} -\/ \mbox{\hyperlink{classThe}{The}} structure that defines a watchdog device

@id\+: \mbox{\hyperlink{classThe}{The}} watchdog\textquotesingle{}s ID. (Allocated by watchdog\+\_\+register\+\_\+device) @parent\+: \mbox{\hyperlink{classThe}{The}} parent bus device @groups\+: List of sysfs attribute groups to create when creating the watchdog device. @info\+: Pointer to a \mbox{\hyperlink{structwatchdog__info}{watchdog\+\_\+info}} structure. @ops\+: Pointer to the list of watchdog operations. @gov\+: Pointer to watchdog pretimeout governor. @bootstatus\+: Status of the watchdog device at boot. @timeout\+: \mbox{\hyperlink{classThe}{The}} watchdog devices timeout value (in seconds). @pretimeout\+: \mbox{\hyperlink{classThe}{The}} watchdog devices pre\+\_\+timeout value. @min\+\_\+timeout\+:\mbox{\hyperlink{classThe}{The}} watchdog devices minimum timeout value (in seconds). @max\+\_\+timeout\+:\mbox{\hyperlink{classThe}{The}} watchdog devices maximum timeout value (in seconds) as configurable from user space. Only relevant if max\+\_\+hw\+\_\+heartbeat\+\_\+ms is not provided. @min\+\_\+hw\+\_\+heartbeat\+\_\+ms\+: Hardware limit for minimum time between heartbeats, in milli-\/seconds. @max\+\_\+hw\+\_\+heartbeat\+\_\+ms\+: Hardware limit for maximum timeout, in milli-\/seconds. Replaces max\+\_\+timeout if specified. @reboot\+\_\+nb\+: \mbox{\hyperlink{classThe}{The}} notifier block to stop watchdog on reboot. @restart\+\_\+nb\+: \mbox{\hyperlink{classThe}{The}} notifier block to register a restart function. @driver\+\_\+data\+:Pointer to the drivers private data. @wd\+\_\+data\+: Pointer to watchdog core internal data. @status\+: Field that \mbox{\hyperlink{protocolcontains-p}{contains}} the devices internal status bits. @deferred\+: Entry in wtd\+\_\+deferred\+\_\+reg\+\_\+list which is used to register early initialized watchdogs.

\mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structwatchdog__device}{watchdog\+\_\+device}} structure \mbox{\hyperlink{protocolcontains-p}{contains}} all information about a watchdog timer device.

\mbox{\hyperlink{classThe}{The}} driver-\/data field may not be accessed directly. It must be accessed via the watchdog\+\_\+set\+\_\+drvdata and watchdog\+\_\+get\+\_\+drvdata helpers.
