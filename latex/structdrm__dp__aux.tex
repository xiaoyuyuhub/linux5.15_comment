\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__dp__aux}{drm\+\_\+dp\+\_\+aux}} -\/ Display\+Port A\+UX channel

An A\+UX channel can also be used to transport I2C messages to a sink. A typical application of that is to access an E\+D\+ID that\textquotesingle{}s present in the sink device. \mbox{\hyperlink{classThe}{The}} @transfer() function can also be used to execute such transactions. \mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{drm__dp__helper_8h_a14a4ce6e8f4db5f8ea341f8c84b20955}{drm\+\_\+dp\+\_\+aux\+\_\+register()}} function registers an I2C adapter that can be passed to \mbox{\hyperlink{drm__edid_8h_aab8bcb2b6342e1be50d65b47a7555787}{drm\+\_\+probe\+\_\+ddc()}}. Upon removal, drivers should call \mbox{\hyperlink{drm__dp__helper_8h_a38efe63b7162d85147f0b1897c84667c}{drm\+\_\+dp\+\_\+aux\+\_\+unregister()}} to remove the I2C adapter. \mbox{\hyperlink{classThe}{The}} I2C adapter uses long transfers by default; if a partial response is received, the adapter will drop down to the size given by the partial response for this transaction only.

@transfer\+: transfers a message representing a single A\+UX transaction.

This is a hardware-\/specific implementation of how transactions are executed that the drivers must provide.

A pointer to a \&\mbox{\hyperlink{structdrm__dp__aux__msg}{drm\+\_\+dp\+\_\+aux\+\_\+msg}} structure describing the transaction is passed into this function. Upon success, the implementation should return the number of payload bytes that were transferred, or a negative error-\/code on failure.

Helpers will propagate these errors, with the exception of the \%-\/E\+B\+U\+SY error, which causes a transaction to be retried. On a short, helpers will return \%-\/E\+P\+R\+O\+TO to make it simpler to check for failure.

\mbox{\hyperlink{classThe}{The}} @transfer() function must only modify the reply field of the \&\mbox{\hyperlink{structdrm__dp__aux__msg}{drm\+\_\+dp\+\_\+aux\+\_\+msg}} structure. \mbox{\hyperlink{classThe}{The}} retry logic and i2c helpers assume this is the case.

Also note that this callback can be called no matter the state @dev is in. Drivers that need that device to be powered to perform this operation will first need to make sure it\textquotesingle{}s been properly enabled.
