\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structspmi__driver}{spmi\+\_\+driver}} -\/ S\+P\+MI slave device driver @driver\+: S\+P\+MI device drivers should initialize name and owner field of this structure. @probe\+: binds this driver to a S\+P\+MI device. @remove\+: unbinds this driver from the S\+P\+MI device.

If PM runtime support is desired for a slave, a device driver can call \mbox{\hyperlink{pm__runtime_8h_ad130f03ee44be5a87dbf186df2c5d8cb}{pm\+\_\+runtime\+\_\+put()}} from their \mbox{\hyperlink{structspmi__driver_a18f8593b3c170b8c9870866d740ad407}{probe()}} routine (and a balancing \mbox{\hyperlink{pm__runtime_8h_a5d4ed635d10a0fceb3e41d0c84ab0f1a}{pm\+\_\+runtime\+\_\+get()}} in \mbox{\hyperlink{structspmi__driver_ad37ad3cae2993e9810ca55be3bcfd21c}{remove()}}). PM runtime support for a slave is implemented by issuing a S\+L\+E\+EP command to the slave on runtime\+\_\+suspend(), transitioning the slave into the S\+L\+E\+EP state. On runtime\+\_\+resume(), a W\+A\+K\+E\+UP command is sent to the slave to bring it back to A\+C\+T\+I\+VE.
