\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structv4l2__ctrl__ref}{v4l2\+\_\+ctrl\+\_\+ref}} -\/ \mbox{\hyperlink{classThe}{The}} control reference.

@node\+: List node for the sorted list. @next\+: Single-\/link list node for the hash. @ctrl\+: \mbox{\hyperlink{classThe}{The}} actual control information. @helper\+: Pointer to helper struct. Used internally in {\ttfamily prepare\+\_\+ext\+\_\+ctrls} function at {\ttfamily v4l2-\/ctrl.\+c}. @from\+\_\+other\+\_\+dev\+: If true, then @ctrl was defined in another device than the \&struct \mbox{\hyperlink{structv4l2__ctrl__handler}{v4l2\+\_\+ctrl\+\_\+handler}}. @req\+\_\+done\+: Internal flag\+: if the control handler containing this control reference is bound to a media request, then this is set when the control has been applied. This prevents applying controls from a cluster with multiple controls twice (when the first control of a cluster is applied, they all are). @valid\+\_\+p\+\_\+req\+: If set, then p\+\_\+req \mbox{\hyperlink{protocolcontains-p}{contains}} the control value for the request. @p\+\_\+req\+: If the control handler containing this control reference is bound to a media request, then this points to the value of the control that must be applied when the request is executed, or to the value of the control at the time that the request was completed. If @valid\+\_\+p\+\_\+req is false, then this control was never set for this request and the control will not be updated when this request is applied.

Each control handler has a list of these refs. \mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structlist__head}{list\+\_\+head}} is used to keep a sorted-\/by-\/control-\/\+ID list of all controls, while the next pointer is used to link the control in the hash\textquotesingle{}s bucket.
