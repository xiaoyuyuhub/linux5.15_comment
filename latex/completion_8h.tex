complete\+\_\+all\+: -\/ signals all threads waiting on this completion @x\+: holds the state of this particular completion

This will wake up all threads waiting on this particular completion event.

If this function wakes up a task, it executes a full memory barrier before accessing the task state.

Since \mbox{\hyperlink{completion_8c_a9b745b70f04b8165945b2a7f75375206}{complete\+\_\+all()}} sets the completion of @x permanently to done to allow multiple waiters to finish, a call to \mbox{\hyperlink{completion_8h_a0f1a3bff79c77224c5edcbe13b5e7635}{reinit\+\_\+completion()}} must be used on @x if @x is to be used again. \mbox{\hyperlink{classThe}{The}} code must make sure that all waiters have woken and finished before reinitializing @x. Also note that the function \mbox{\hyperlink{completion_8c_a09f3920ec9913a8549f850a761ede663}{completion\+\_\+done()}} can not be used to know if there are still waiters after \mbox{\hyperlink{completion_8c_a9b745b70f04b8165945b2a7f75375206}{complete\+\_\+all()}} has been called.
