These functions compress data in successive blocks of any size, using previous blocks as dictionary. One key assumption is that previous blocks (up to 64 KB) remain read-\/accessible while compressing next blocks. There is an exception for ring buffers, which can be smaller than 64 KB. Ring buffers scenario is automatically detected and handled by \mbox{\hyperlink{lz4_8h_acec65ca1e147d00a28f5bbeb1502dbf8}{L\+Z4\+\_\+compress\+\_\+\+H\+C\+\_\+continue()}}. Before starting compression, state must be properly initialized, using \mbox{\hyperlink{lz4_8h_a07c757112b623c6937f2110e5be855dd}{L\+Z4\+\_\+reset\+Stream\+H\+C()}}. A first \char`\"{}fictional block\char`\"{} can then be designated as initial dictionary, using \mbox{\hyperlink{lz4_8h_a6ec9bbd2a0ac66b868d9fa6bf5fcdfdb}{L\+Z4\+\_\+load\+Dict\+H\+C()}} (Optional). Then, use \mbox{\hyperlink{lz4_8h_acec65ca1e147d00a28f5bbeb1502dbf8}{L\+Z4\+\_\+compress\+\_\+\+H\+C\+\_\+continue()}} to compress each successive block. Previous memory blocks (including initial dictionary when present) must remain accessible and unmodified during compression. \textquotesingle{}dst\textquotesingle{} buffer should be sized to handle worst case scenarios, using \mbox{\hyperlink{lz4_8h_a5620f56fbec7c7028a4199467c9cf1f2}{L\+Z4\+\_\+compress\+Bound()}}, to ensure operation success. If, for any reason, previous data blocks can\textquotesingle{}t be preserved unmodified in memory during next compression block, you must save it to a safer memory space, using \mbox{\hyperlink{lz4_8h_a4bd3f7a7601492b9bf21d5a441394fff}{L\+Z4\+\_\+save\+Dict\+H\+C()}}.
