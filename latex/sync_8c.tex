This function is used by updaters who need readers to make use of a slowpath during the update. After this function returns, all subsequent calls to \mbox{\hyperlink{rcu__sync_8h_a4c65217bb3ef94cb7a301f219f52547f}{rcu\+\_\+sync\+\_\+is\+\_\+idle()}} will return false, which tells readers to stay off their fastpaths. A later call to \mbox{\hyperlink{sync_8c_a648625017a03c3a546b9ef0ba310c9a9}{rcu\+\_\+sync\+\_\+exit()}} re-\/enables reader slowpaths.

When called in isolation, \mbox{\hyperlink{sync_8c_afb3bf9da62b25629bf76aa540d1cbdb1}{rcu\+\_\+sync\+\_\+enter()}} must wait for a grace period, however, closely spaced calls to \mbox{\hyperlink{sync_8c_afb3bf9da62b25629bf76aa540d1cbdb1}{rcu\+\_\+sync\+\_\+enter()}} can optimize away the grace-\/period wait via a state machine implemented by \mbox{\hyperlink{sync_8c_afb3bf9da62b25629bf76aa540d1cbdb1}{rcu\+\_\+sync\+\_\+enter()}}, \mbox{\hyperlink{sync_8c_a648625017a03c3a546b9ef0ba310c9a9}{rcu\+\_\+sync\+\_\+exit()}}, and \mbox{\hyperlink{sync_8c_a0f8b04b71866ba0c71660767f9a66640}{rcu\+\_\+sync\+\_\+func()}}. This function is passed to \mbox{\hyperlink{tiny_8c_a094a548179ef967658b67414a0c91d32}{call\+\_\+rcu()}} function by \mbox{\hyperlink{sync_8c_afb3bf9da62b25629bf76aa540d1cbdb1}{rcu\+\_\+sync\+\_\+enter()}} and \mbox{\hyperlink{sync_8c_a648625017a03c3a546b9ef0ba310c9a9}{rcu\+\_\+sync\+\_\+exit()}}, so that it is invoked after a grace period following the that invocation of enter/exit.

If it is called by \mbox{\hyperlink{sync_8c_afb3bf9da62b25629bf76aa540d1cbdb1}{rcu\+\_\+sync\+\_\+enter()}} it signals that all the readers were switched onto slow path.

If it is called by \mbox{\hyperlink{sync_8c_a648625017a03c3a546b9ef0ba310c9a9}{rcu\+\_\+sync\+\_\+exit()}} it takes action based on events that have taken place in the meantime, so that closely spaced \mbox{\hyperlink{sync_8c_afb3bf9da62b25629bf76aa540d1cbdb1}{rcu\+\_\+sync\+\_\+enter()}} and \mbox{\hyperlink{sync_8c_a648625017a03c3a546b9ef0ba310c9a9}{rcu\+\_\+sync\+\_\+exit()}} pairs need not wait for a grace period.

If another \mbox{\hyperlink{sync_8c_afb3bf9da62b25629bf76aa540d1cbdb1}{rcu\+\_\+sync\+\_\+enter()}} is invoked before the grace period ended, reset state to allow the next \mbox{\hyperlink{sync_8c_a648625017a03c3a546b9ef0ba310c9a9}{rcu\+\_\+sync\+\_\+exit()}} to let the readers back onto their fastpaths (after a grace period). If both another \mbox{\hyperlink{sync_8c_afb3bf9da62b25629bf76aa540d1cbdb1}{rcu\+\_\+sync\+\_\+enter()}} and its matching \mbox{\hyperlink{sync_8c_a648625017a03c3a546b9ef0ba310c9a9}{rcu\+\_\+sync\+\_\+exit()}} are invoked before the grace period ended, re-\/invoke \mbox{\hyperlink{tiny_8c_a094a548179ef967658b67414a0c91d32}{call\+\_\+rcu()}} on behalf of that \mbox{\hyperlink{sync_8c_a648625017a03c3a546b9ef0ba310c9a9}{rcu\+\_\+sync\+\_\+exit()}}.
