\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structposix__clock}{posix\+\_\+clock}} -\/ represents a dynamic posix clock

@ops\+: Functional interface to the clock @cdev\+: Character device instance for this clock @dev\+: Pointer to the clock\textquotesingle{}s device. @rwsem\+: Protects the \textquotesingle{}zombie\textquotesingle{} field from concurrent access. @zombie\+: If \textquotesingle{}zombie\textquotesingle{} is true, then the hardware has disappeared.

Drivers should embed their struct \mbox{\hyperlink{structposix__clock}{posix\+\_\+clock}} within a private structure, obtaining a reference to it during callbacks using \mbox{\hyperlink{linux_2kernel_8h_af8c317a42292b61c93aae91e59118a46}{container\+\_\+of()}}.

Drivers should supply an initialized but not exposed struct device to \mbox{\hyperlink{posix-clock_8c_a029788ad17b20b088c7f514c9f6b892a}{posix\+\_\+clock\+\_\+register()}}. It is used to manage lifetime of the driver\textquotesingle{}s private structure. It\textquotesingle{}s \textquotesingle{}release\textquotesingle{} field should be set to a release function for this private structure.
