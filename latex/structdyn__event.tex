\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdyn__event}{dyn\+\_\+event}} -\/ Dynamic event list header

\mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structdyn__event}{dyn\+\_\+event}} structure encapsulates a list and a pointer to the operators for making a global list of dynamic events. User must includes this in each event structure, so that those events can be added/removed via dynamic\+\_\+events interface.
