\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structnvme__fc__port__template}{nvme\+\_\+fc\+\_\+port\+\_\+template}} -\/ structure containing static entrypoints and operational parameters for an L\+L\+DD that supports N\+V\+ME host behavior. Passed by reference in port registrations. N\+V\+M\+E-\/\+FC transport remembers template reference and may access it during runtime operation.

Host/\+Initiator Transport Entrypoints/\+Parameters\+:

@localport\+\_\+delete\+: \mbox{\hyperlink{classThe}{The}} L\+L\+DD initiates deletion of a localport via nvme\+\_\+fc\+\_\+deregister\+\_\+localport(). However, the teardown is asynchronous. This routine is called upon the completion of the teardown to inform the L\+L\+DD that the localport has been deleted. Entrypoint is Mandatory.

@remoteport\+\_\+delete\+: \mbox{\hyperlink{classThe}{The}} L\+L\+DD initiates deletion of a remoteport via nvme\+\_\+fc\+\_\+deregister\+\_\+remoteport(). However, the teardown is asynchronous. This routine is called upon the completion of the teardown to inform the L\+L\+DD that the remoteport has been deleted. Entrypoint is Mandatory.

@create\+\_\+queue\+: Upon creating a host$<$-\/$>$controller association, queues are created such that they can be affinitized to cpus/cores. This callback into the L\+L\+DD to notify that a controller queue is being created. \mbox{\hyperlink{classThe}{The}} L\+L\+DD may choose to allocate an associated hw queue or map it onto a shared hw queue. Upon return from the call, the L\+L\+DD specifies a handle that will be given back to it for any command that is posted to the controller queue. \mbox{\hyperlink{classThe}{The}} handle can be used by the L\+L\+DD to map quickly to the proper hw queue for command execution. \mbox{\hyperlink{classThe}{The}} mask of cpu\textquotesingle{}s that will map to this queue at the block-\/level is also passed in. \mbox{\hyperlink{classThe}{The}} L\+L\+DD should use the queue id and/or cpu masks to ensure proper affinitization of the controller queue to the hw queue. Entrypoint is Optional.

@delete\+\_\+queue\+: This is the inverse of the crete\+\_\+queue. During host$<$-\/$>$controller association teardown, this routine is called when a controller queue is being terminated. Any association with a hw queue should be termined. If there is a unique hw queue, the hw queue should be torn down. Entrypoint is Optional.

@poll\+\_\+queue\+: Called to poll for the completion of an io on a blk queue. Entrypoint is Optional.

@ls\+\_\+req\+: Called to issue a F\+C-\/\+N\+V\+ME F\+C-\/4 LS service request. \mbox{\hyperlink{classThe}{The}} nvme\+\_\+fc\+\_\+ls\+\_\+req structure will fully describe the buffers for the request payload and where to place the response payload. \mbox{\hyperlink{classThe}{The}} L\+L\+DD is to allocate an exchange, issue the LS request, obtain the LS response, and call the \char`\"{}done\char`\"{} routine specified in the request structure (argument to done is the ls request structure itself). Entrypoint is Mandatory.

@fcp\+\_\+io\+: called to issue a F\+C-\/\+N\+V\+ME I/O request. \mbox{\hyperlink{classThe}{The}} I/O may be for an admin queue or an i/o queue. \mbox{\hyperlink{classThe}{The}} nvmefc\+\_\+fcp\+\_\+req structure will fully describe the io\+: the buffer containing the F\+C-\/\+N\+V\+ME C\+MD IU (which \mbox{\hyperlink{protocolcontains-p}{contains}} the S\+QE), the sg list for the payload if applicable, and the buffer to place the F\+C-\/\+N\+V\+ME R\+SP IU into. \mbox{\hyperlink{classThe}{The}} L\+L\+DD will complete the i/o, indicating the amount of data transferred or any transport error, and call the \char`\"{}done\char`\"{} routine specified in the request structure (argument to done is the fcp request structure itself). Entrypoint is Mandatory.

@ls\+\_\+abort\+: called to request the L\+L\+DD to abort the indicated ls request. \mbox{\hyperlink{classThe}{The}} call may return before the abort has completed. After aborting the request, the L\+L\+DD must still call the ls request done routine indicating an FC transport Aborted status. Entrypoint is Mandatory.

@fcp\+\_\+abort\+: called to request the L\+L\+DD to abort the indicated fcp request. \mbox{\hyperlink{classThe}{The}} call may return before the abort has completed. After aborting the request, the L\+L\+DD must still call the fcp request done routine indicating an FC transport Aborted status. Entrypoint is Mandatory.

@xmt\+\_\+ls\+\_\+rsp\+: Called to transmit the response to a F\+C-\/\+N\+V\+ME F\+C-\/4 LS service. \mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structnvmefc__ls__rsp}{nvmefc\+\_\+ls\+\_\+rsp}} structure is the same L\+L\+D\+D-\/supplied exchange structure specified in the \mbox{\hyperlink{nvme-fc-driver_8h_a62f8272f14ad8a94934d26e88c2fb331}{nvme\+\_\+fc\+\_\+rcv\+\_\+ls\+\_\+req()}} call made when the LS request was received. \mbox{\hyperlink{classThe}{The}} structure will fully describe the buffers for the response payload and the dma address of the payload. \mbox{\hyperlink{classThe}{The}} L\+L\+DD is to transmit the response (or return a non-\/zero errno status), and upon completion of the transmit, call the \char`\"{}done\char`\"{} routine specified in the \mbox{\hyperlink{structnvmefc__ls__rsp}{nvmefc\+\_\+ls\+\_\+rsp}} structure (argument to done is the address of the \mbox{\hyperlink{structnvmefc__ls__rsp}{nvmefc\+\_\+ls\+\_\+rsp}} structure itself). Upon the completion of the done routine, the L\+L\+DD shall consider the LS handling complete and the \mbox{\hyperlink{structnvmefc__ls__rsp}{nvmefc\+\_\+ls\+\_\+rsp}} structure may be freed/released. Entrypoint is mandatory if the L\+L\+DD calls the \mbox{\hyperlink{nvme-fc-driver_8h_a62f8272f14ad8a94934d26e88c2fb331}{nvme\+\_\+fc\+\_\+rcv\+\_\+ls\+\_\+req()}} entrypoint.

@max\+\_\+hw\+\_\+queues\+: indicates the maximum number of hw queues the L\+L\+DD supports for cpu affinitization. Value is Mandatory. Must be at least 1.

@max\+\_\+sgl\+\_\+segments\+: indicates the maximum number of sgl segments supported by the L\+L\+DD Value is Mandatory. Must be at least 1. Recommend at least 256.

@max\+\_\+dif\+\_\+sgl\+\_\+segments\+: indicates the maximum number of sgl segments supported by the L\+L\+DD for D\+IF operations. Value is Mandatory. Must be at least 1. Recommend at least 256.

@dma\+\_\+boundary\+: indicates the dma address boundary where dma mappings will be split across. Value is Mandatory. Typical value is 0x\+F\+F\+F\+F\+F\+F\+FF to split across 4Gig address boundarys

@local\+\_\+priv\+\_\+sz\+: \mbox{\hyperlink{classThe}{The}} L\+L\+DD sets this field to the amount of additional memory that it would like fc nvme layer to allocate on the L\+L\+DD\textquotesingle{}s behalf whenever a localport is allocated. \mbox{\hyperlink{classThe}{The}} additional memory area solely for the of the L\+L\+DD and its location is specified by the localport-\/$>$private pointer. Value is Mandatory. Allowed to be zero.

@remote\+\_\+priv\+\_\+sz\+: \mbox{\hyperlink{classThe}{The}} L\+L\+DD sets this field to the amount of additional memory that it would like fc nvme layer to allocate on the L\+L\+DD\textquotesingle{}s behalf whenever a remoteport is allocated. \mbox{\hyperlink{classThe}{The}} additional memory area solely for the of the L\+L\+DD and its location is specified by the remoteport-\/$>$private pointer. Value is Mandatory. Allowed to be zero.

@lsrqst\+\_\+priv\+\_\+sz\+: \mbox{\hyperlink{classThe}{The}} L\+L\+DD sets this field to the amount of additional memory that it would like fc nvme layer to allocate on the L\+L\+DD\textquotesingle{}s behalf whenever a ls request structure is allocated. \mbox{\hyperlink{classThe}{The}} additional memory area is solely for use by the L\+L\+DD and its location is specified by the ls\+\_\+request-\/$>$private pointer. Value is Mandatory. Allowed to be zero.

@fcprqst\+\_\+priv\+\_\+sz\+: \mbox{\hyperlink{classThe}{The}} L\+L\+DD sets this field to the amount of additional memory that it would like fc nvme layer to allocate on the L\+L\+DD\textquotesingle{}s behalf whenever a fcp request structure is allocated. \mbox{\hyperlink{classThe}{The}} additional memory area solely for the of the L\+L\+DD and its location is specified by the fcp\+\_\+request-\/$>$private pointer. Value is Mandatory. Allowed to be zero.
