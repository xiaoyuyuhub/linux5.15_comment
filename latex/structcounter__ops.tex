\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structcounter__ops}{counter\+\_\+ops}} -\/ Callbacks from driver @signal\+\_\+read\+: optional read callback for Signal attribute. \mbox{\hyperlink{classThe}{The}} read level of the respective Signal should be passed back via the level parameter. @count\+\_\+read\+: optional read callback for Count attribute. \mbox{\hyperlink{classThe}{The}} read value of the respective Count should be passed back via the val parameter. @count\+\_\+write\+: optional write callback for Count attribute. \mbox{\hyperlink{classThe}{The}} write value for the respective Count is passed in via the val parameter. @function\+\_\+get\+: function to get the current count function mode. Returns 0 on success and negative error code on error. \mbox{\hyperlink{classThe}{The}} index of the respective Count\textquotesingle{}s returned function mode should be passed back via the function parameter. @function\+\_\+set\+: function to set the count function mode. function is the index of the requested function mode from the respective Count\textquotesingle{}s functions\+\_\+list array. @action\+\_\+get\+: function to get the current action mode. Returns 0 on success and negative error code on error. \mbox{\hyperlink{classThe}{The}} index of the respective Synapse\textquotesingle{}s returned action mode should be passed back via the action parameter. @action\+\_\+set\+: function to set the action mode. action is the index of the requested action mode from the respective Synapse\textquotesingle{}s actions\+\_\+list array.
