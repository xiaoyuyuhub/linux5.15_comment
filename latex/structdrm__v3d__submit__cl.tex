\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__v3d__submit__cl}{drm\+\_\+v3d\+\_\+submit\+\_\+cl}} -\/ ioctl argument for submitting commands to the 3D engine.

This asks the kernel to have the G\+PU execute an optional binner command list, and a render command list.

\mbox{\hyperlink{classThe}{The}} L1T, slice, L2C, L2T, and G\+CA caches will be flushed before each CL executes. \mbox{\hyperlink{classThe}{The}} V\+CD cache should be flushed (if necessary) by the submitted C\+Ls. \mbox{\hyperlink{classThe}{The}} T\+LB writes are guaranteed to have been flushed by the time the render done I\+RQ happens, which is the trigger for out\+\_\+sync. Any dirtying of cachelines by the job (only possible using T\+MU writes) must be flushed by the caller using the D\+R\+M\+\_\+\+V3\+D\+\_\+\+S\+U\+B\+M\+I\+T\+\_\+\+C\+L\+\_\+\+F\+L\+U\+S\+H\+\_\+\+C\+A\+C\+H\+E\+\_\+\+F\+L\+AG flag.
