conversion is done as follows\+:


\begin{DoxyItemize}
\item negative values mean \textquotesingle{}infinite timeout\textquotesingle{} (M\+A\+X\+\_\+\+J\+I\+F\+F\+Y\+\_\+\+O\+F\+F\+S\+ET)

\item all other values are converted to jiffies by either multiplying the input value by a factor or dividing it with a factor and handling any 32-\/bit overflows. for the details see \mbox{\hyperlink{kernel_2time_2time_8c_a7f61126c819b1c1df0c21bc34f4bb549}{\+\_\+\+\_\+msecs\+\_\+to\+\_\+jiffies()}}
