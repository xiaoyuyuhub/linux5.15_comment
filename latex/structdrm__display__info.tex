\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__display__info}{drm\+\_\+display\+\_\+info}} -\/ runtime data about the connected sink

Describes a given display (e.\+g. C\+RT or flat panel) and its limitations. For fixed display sinks like built-\/in panels there\textquotesingle{}s not much difference between this and \&struct \mbox{\hyperlink{structdrm__connector}{drm\+\_\+connector}}. But for sinks with a real cable this structure is meant to describe all the things at the other end of the cable.

For sinks which provide an E\+D\+ID this can be filled out by calling \mbox{\hyperlink{drm__edid_8h_ad27cbab837eded8539aaebc12fc4524f}{drm\+\_\+add\+\_\+edid\+\_\+modes()}}.
