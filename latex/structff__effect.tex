\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structff__effect}{ff\+\_\+effect}} -\/ defines force feedback effect @type\+: type of the effect (F\+F\+\_\+\+C\+O\+N\+S\+T\+A\+NT, F\+F\+\_\+\+P\+E\+R\+I\+O\+D\+IC, F\+F\+\_\+\+R\+A\+MP, F\+F\+\_\+\+S\+P\+R\+I\+NG, F\+F\+\_\+\+F\+R\+I\+C\+T\+I\+ON, F\+F\+\_\+\+D\+A\+M\+P\+ER, F\+F\+\_\+\+R\+U\+M\+B\+LE, F\+F\+\_\+\+I\+N\+E\+R\+T\+IA, or F\+F\+\_\+\+C\+U\+S\+T\+OM) @id\+: an unique id assigned to an effect @direction\+: direction of the effect @trigger\+: trigger conditions (struct \mbox{\hyperlink{structff__trigger}{ff\+\_\+trigger}}) @replay\+: scheduling of the effect (struct \mbox{\hyperlink{structff__replay}{ff\+\_\+replay}}) @u\+: effect-\/specific structure (one of \mbox{\hyperlink{structff__constant__effect}{ff\+\_\+constant\+\_\+effect}}, \mbox{\hyperlink{structff__ramp__effect}{ff\+\_\+ramp\+\_\+effect}}, \mbox{\hyperlink{structff__periodic__effect}{ff\+\_\+periodic\+\_\+effect}}, \mbox{\hyperlink{structff__condition__effect}{ff\+\_\+condition\+\_\+effect}}, \mbox{\hyperlink{structff__rumble__effect}{ff\+\_\+rumble\+\_\+effect}}) further defining effect parameters

This structure is sent through ioctl from the application to the driver. To create a new effect application should set its @id to -\/1; the kernel will return assigned @id which can later be used to update or delete this effect.

Direction of the effect is encoded as follows\+: 0 deg -\/$>$ 0x0000 (down) 90 deg -\/$>$ 0x4000 (left) 180 deg -\/$>$ 0x8000 (up) 270 deg -\/$>$ 0x\+C000 (right)
