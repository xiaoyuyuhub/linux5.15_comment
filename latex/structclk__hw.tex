\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structclk__hw}{clk\+\_\+hw}} -\/ handle for traversing from a struct clk to its corresponding hardware-\/specific structure. struct \mbox{\hyperlink{structclk__hw}{clk\+\_\+hw}} should be declared within struct clk\+\_\+foo and then referenced by the struct clk instance that uses struct clk\+\_\+foo\textquotesingle{}s \mbox{\hyperlink{structclk__ops}{clk\+\_\+ops}}

@core\+: pointer to the struct clk\+\_\+core instance that points back to this struct \mbox{\hyperlink{structclk__hw}{clk\+\_\+hw}} instance

@clk\+: pointer to the per-\/user struct clk instance that can be used to call into the clk A\+PI

@init\+: pointer to struct \mbox{\hyperlink{structclk__init__data}{clk\+\_\+init\+\_\+data}} that \mbox{\hyperlink{protocolcontains-p}{contains}} the init data shared with the common clock framework.
