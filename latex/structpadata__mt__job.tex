\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structpadata__mt__job}{padata\+\_\+mt\+\_\+job}} -\/ represents one multithreaded job

@thread\+\_\+fn\+: Called for each chunk of work that a padata thread does. @fn\+\_\+arg\+: \mbox{\hyperlink{classThe}{The}} thread function argument. @start\+: \mbox{\hyperlink{classThe}{The}} start of the job (units are job-\/specific). @size\+: size of this node\textquotesingle{}s work (units are job-\/specific). @align\+: Ranges passed to the thread function fall on this boundary, with the possible exceptions of the beginning and end of the job. @min\+\_\+chunk\+: \mbox{\hyperlink{classThe}{The}} minimum chunk size in job-\/specific units. This allows the client to communicate the minimum amount of work that\textquotesingle{}s appropriate for one worker thread to do at once. @max\+\_\+threads\+: Max threads to use for the job, actual number may be less depending on task size and minimum chunk size.
