@restore\+:

Called on drm\+\_\+lastclose(). \mbox{\hyperlink{classThe}{The}} first client instance in the list that returns zero gets the privilege to restore and no more clients are called. This callback is not called after @unregister has been called.

Note that the core does not guarantee exclusion against concurrent \mbox{\hyperlink{drm__file_8h_a7e92bfba351039ad336bdc8a48e31dae}{drm\+\_\+open()}}. Clients need to ensure this themselves, for example by using drm\+\_\+master\+\_\+internal\+\_\+acquire() and drm\+\_\+master\+\_\+internal\+\_\+release().
