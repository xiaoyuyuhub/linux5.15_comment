\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structrmi__gpio__data}{rmi\+\_\+gpio\+\_\+data}} -\/ overrides defaults for a single F30/\+F3A G\+P\+I\+Os/\+L\+ED chip. @buttonpad -\/ the touchpad is a buttonpad, so enable only the first actual button that is found. @trackstick\+\_\+buttons -\/ Set when the function 30 or 3a is handling the physical buttons of the trackstick (as a P\+S/2 passthrough device). @disable -\/ the touchpad incorrectly reports F30/\+F3A and it should be ignored. This is a special case which is due to misconfigured firmware.
