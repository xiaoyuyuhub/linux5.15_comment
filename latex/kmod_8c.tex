\+\_\+\+\_\+request\+\_\+module -\/ try to load a kernel module @wait\+: wait (or not) for the operation to complete @fmt\+: printf style format string for the name of the module ...\+: arguments as specified in the format string

Load a module using the user mode module loader. \mbox{\hyperlink{classThe}{The}} function returns zero on success or a negative errno code or positive exit code from \char`\"{}modprobe\char`\"{} on failure. Note that a successful module load does not mean the module did not then unload and exit on an error of its own. Callers must check that the service they requested is now available not blindly invoke it.
