\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structwatchdog__ops}{watchdog\+\_\+ops}} -\/ \mbox{\hyperlink{classThe}{The}} watchdog-\/devices operations

@owner\+: \mbox{\hyperlink{classThe}{The}} module owner. @start\+: \mbox{\hyperlink{classThe}{The}} routine for starting the watchdog device. @stop\+: \mbox{\hyperlink{classThe}{The}} routine for stopping the watchdog device. @ping\+: \mbox{\hyperlink{classThe}{The}} routine that sends a keepalive ping to the watchdog device. @status\+: \mbox{\hyperlink{classThe}{The}} routine that shows the status of the watchdog device. @set\+\_\+timeout\+:\mbox{\hyperlink{classThe}{The}} routine for setting the watchdog devices timeout value (in seconds). @set\+\_\+pretimeout\+:\mbox{\hyperlink{classThe}{The}} routine for setting the watchdog devices pretimeout. @get\+\_\+timeleft\+:\mbox{\hyperlink{classThe}{The}} routine that gets the time left before a reset (in seconds). @restart\+: \mbox{\hyperlink{classThe}{The}} routine for restarting the machine. @ioctl\+: \mbox{\hyperlink{classThe}{The}} routines that handles extra ioctl calls.

\mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structwatchdog__ops}{watchdog\+\_\+ops}} structure \mbox{\hyperlink{protocolcontains-p}{contains}} a list of low-\/level operations that control a watchdog device. It also \mbox{\hyperlink{protocolcontains-p}{contains}} the module that owns these operations. \mbox{\hyperlink{classThe}{The}} start function is mandatory, all other functions are optional.
