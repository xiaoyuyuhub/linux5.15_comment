\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__dp__mst__branch}{drm\+\_\+dp\+\_\+mst\+\_\+branch}} -\/ M\+ST branch device. @rad\+: Relative Address to talk to this branch device. @lct\+: Link count total to talk to this branch device. @num\+\_\+ports\+: number of ports on the branch. @port\+\_\+parent\+: pointer to the port parent, N\+U\+LL if toplevel. @mgr\+: topology manager for this branch device. @link\+\_\+address\+\_\+sent\+: if a link address message has been sent to this device yet. @guid\+: guid for DP 1.\+2 branch device. port under this branch can be identified by port \#.
