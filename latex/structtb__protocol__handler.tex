\doxysubsection{Detailed Description}
\mbox{\hyperlink{structtb__protocol__handler}{tb\+\_\+protocol\+\_\+handler}} -\/ Protocol specific handler @uuid\+: X\+Domain messages with this U\+U\+ID are dispatched to this handler @callback\+: Callback called with the X\+Domain message. Returning \%1 here tells the X\+Domain core that the message was handled by this handler and should not be forwared to other handlers. @data\+: Data passed with the callback @list\+: Handlers are linked using this

Thunderbolt services can hook into incoming X\+Domain requests by registering \mbox{\hyperlink{protocolprotocol-p}{protocol}} handler. Only limitation is that the X\+Domain discovery \mbox{\hyperlink{protocolprotocol-p}{protocol}} U\+U\+ID cannot be registered since it is handled by the core X\+Domain code.

\mbox{\hyperlink{classThe}{The}} @callback must check that the message is really directed to the service the driver implements.
