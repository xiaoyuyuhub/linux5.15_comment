\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structnand__sdr__timings}{nand\+\_\+sdr\+\_\+timings}} -\/ S\+DR N\+A\+ND chip timings

This struct defines the timing requirements of a S\+DR N\+A\+ND chip. These information can be found in every N\+A\+ND datasheets and the timings meaning are described in the O\+N\+FI specifications\+: \href{https://media-www.micron.com/-/media/client/onfi/specs/onfi_3_1_spec.pdf}{\texttt{ https\+://media-\/www.\+micron.\+com/-\//media/client/onfi/specs/onfi\+\_\+3\+\_\+1\+\_\+spec.\+pdf}} (chapter 4.\+15 Timing Parameters)

All these timings are expressed in picoseconds.
