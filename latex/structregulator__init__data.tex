\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structregulator__init__data}{regulator\+\_\+init\+\_\+data}} -\/ regulator platform initialisation data.

Initialisation constraints, our supply and consumers supplies.

@supply\+\_\+regulator\+: Parent regulator. Specified using the regulator name as it appears in the name field in sysfs, which can be explicitly set using the constraints field \textquotesingle{}name\textquotesingle{}.

@constraints\+: Constraints. These must be specified for the regulator to be usable. @num\+\_\+consumer\+\_\+supplies\+: Number of consumer device supplies. @consumer\+\_\+supplies\+: Consumer device supply configuration.

@regulator\+\_\+init\+: Callback invoked when the regulator has been registered. @driver\+\_\+data\+: Data passed to regulator\+\_\+init.
