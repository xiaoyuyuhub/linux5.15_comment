\doxysubsection{Detailed Description}
struct hrtimer -\/ the basic hrtimer structure @node\+: timerqueue node, which also manages node.\+expires, the absolute expiry time in the hrtimers internal representation. \mbox{\hyperlink{classThe}{The}} time is related to the clock on which the timer is based. Is setup by adding slack to the \+\_\+softexpires value. For non range timers identical to \+\_\+softexpires. @\+\_\+softexpires\+: the absolute earliest expiry time of the hrtimer. \mbox{\hyperlink{classThe}{The}} time which was given as expiry time when the timer was armed. @function\+: timer expiry callback function @base\+: pointer to the timer base (per cpu and per clock) @state\+: state information (See bit values above) @is\+\_\+rel\+: Set if the timer was armed relative @is\+\_\+soft\+: Set if hrtimer will be expired in soft interrupt context. @is\+\_\+hard\+: Set if hrtimer will be expired in hard interrupt context even on RT.

\mbox{\hyperlink{classThe}{The}} hrtimer structure must be initialized by \mbox{\hyperlink{hrtimer_8c_a6e49770c43416cb8835cbc6201fb0d87}{hrtimer\+\_\+init()}}
