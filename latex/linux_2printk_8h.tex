printk -\/ print a kernel message @fmt\+: format string

This is \mbox{\hyperlink{linux_2printk_8h_ac002b290a55c356b2b46a7be61a791d4}{printk()}}. It can be called from any context. We want it to work.

If printk indexing is enabled, \+\_\+printk() is called from printk\+\_\+index\+\_\+wrap. Otherwise, printk is simply \#defined to \+\_\+printk.

We try to grab the console\+\_\+lock. If we succeed, it\textquotesingle{}s easy -\/ we log the output and call the console drivers. If we fail to get the semaphore, we place the output into the log buffer and return. \mbox{\hyperlink{classThe}{The}} current holder of the console\+\_\+sem will notice the new output in \mbox{\hyperlink{printk_8c_aacf12f77f6ae697454569a0be00bd20b}{console\+\_\+unlock()}}; and will send it to the consoles before releasing the lock.

One effect of this deferred printing is that code which calls \mbox{\hyperlink{linux_2printk_8h_ac002b290a55c356b2b46a7be61a791d4}{printk()}} and then changes console\+\_\+loglevel may break. This is because console\+\_\+loglevel is inspected when the actual printing occurs.
