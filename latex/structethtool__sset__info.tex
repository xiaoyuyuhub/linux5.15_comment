struct \mbox{\hyperlink{structethtool__sset__info}{ethtool\+\_\+sset\+\_\+info}} -\/ string set information @cmd\+: Command number = E\+T\+H\+T\+O\+O\+L\+\_\+\+G\+S\+S\+E\+T\+\_\+\+I\+N\+FO @reserved\+: Reserved for future use; see the note on reserved space. @sset\+\_\+mask\+: On entry, a bitmask of string sets to query, with bits numbered according to \&enum ethtool\+\_\+stringset. On return, this \mbox{\hyperlink{protocolcontains-p}{contains}} the size of each string set that was queried and supported, in order of ID.
