\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdmx__section__feed}{dmx\+\_\+section\+\_\+feed}} -\/ Structure that \mbox{\hyperlink{protocolcontains-p}{contains}} a section feed filter

@is\+\_\+filtering\+: Set to non-\/zero when filtering in progress @parent\+: pointer to struct \mbox{\hyperlink{structdmx__demux}{dmx\+\_\+demux}} @priv\+: pointer to private data of the A\+PI client @check\+\_\+crc\+: If non-\/zero, check the C\+RC values of filtered sections. @set\+: sets the section filter @allocate\+\_\+filter\+: This function is used to allocate a section filter on the demux. It should only be called when no filtering is in progress on this section feed. If a filter cannot be allocated, the function fails with -\/E\+N\+O\+S\+PC. @release\+\_\+filter\+: This function releases all the resources of a previously allocated section filter. \mbox{\hyperlink{classThe}{The}} function should not be called while filtering is in progress on this section feed. After calling this function, the caller should not try to dereference the filter pointer. @start\+\_\+filtering\+: starts section filtering @stop\+\_\+filtering\+: stops section filtering

A TS feed is typically mapped to a hardware P\+ID filter on the demux chip. Using this A\+PI, the client can set the filtering properties to start/stop filtering TS packets on a particular TS feed.
