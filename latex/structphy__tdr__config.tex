\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structphy__tdr__config}{phy\+\_\+tdr\+\_\+config}} -\/ Configuration of a T\+DR raw test

@first\+: Distance for first data collection point @last\+: Distance for last data collection point @step\+: Step between data collection points @pair\+: Bitmap of cable pairs to collect data for
