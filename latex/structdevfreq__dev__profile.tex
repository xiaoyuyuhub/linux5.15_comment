\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdevfreq__dev__profile}{devfreq\+\_\+dev\+\_\+profile}} -\/ Devfreq\textquotesingle{}s user device profile @initial\+\_\+freq\+: \mbox{\hyperlink{classThe}{The}} operating frequency when \mbox{\hyperlink{linux_2devfreq_8h_ac1140c2a5003ce4f8c92c8ddff13434b}{devfreq\+\_\+add\+\_\+device()}} is called. @polling\+\_\+ms\+: \mbox{\hyperlink{classThe}{The}} polling interval in ms. 0 disables polling. @timer\+: Timer type is either deferrable or delayed timer. @target\+: \mbox{\hyperlink{classThe}{The}} device should set its operating frequency at freq or lowest-\/upper-\/than-\/freq value. If freq is higher than any operable frequency, set maximum. Before returning, target function should set freq at the current frequency. \mbox{\hyperlink{classThe}{The}} \char`\"{}flags\char`\"{} parameter\textquotesingle{}s possible values are explained above with \char`\"{}\+D\+E\+V\+F\+R\+E\+Q\+\_\+\+F\+L\+A\+G\+\_\+$\ast$\char`\"{} macros. @get\+\_\+dev\+\_\+status\+: \mbox{\hyperlink{classThe}{The}} device should provide the current performance status to devfreq. Governors are recommended not to use this directly. Instead, governors are recommended to use \mbox{\hyperlink{linux_2devfreq_8h_a0a6d8a1ed70d36139281fed378ccfef3}{devfreq\+\_\+update\+\_\+stats()}} along with \mbox{\hyperlink{structdevfreq_a30fbbf1622ac58bc588acf1e2ec5b45a}{devfreq.\+last\+\_\+status}}. @get\+\_\+cur\+\_\+freq\+: \mbox{\hyperlink{classThe}{The}} device should provide the current frequency at which it is operating. @exit\+: An optional callback that is called when devfreq is removing the devfreq object due to error or from \mbox{\hyperlink{linux_2devfreq_8h_ae51e04f04ca87569512d8e2f81b99208}{devfreq\+\_\+remove\+\_\+device()}} call. If the user has registered devfreq-\/$>$nb at a notifier-\/head, this is the time to unregister it. @freq\+\_\+table\+: Optional list of frequencies to support statistics and freq\+\_\+table must be generated in ascending order. @max\+\_\+state\+: \mbox{\hyperlink{classThe}{The}} size of freq\+\_\+table.
