mtrr\+\_\+trim\+\_\+uncached\+\_\+memory -\/ trim R\+AM not covered by M\+T\+R\+Rs @end\+\_\+pfn\+: ending page frame number

Some buggy B\+I\+O\+Ses don\textquotesingle{}t setup the M\+T\+R\+Rs properly for systems with certain memory configurations. This routine checks that the highest M\+T\+RR matches the end of memory, to make sure the M\+T\+R\+Rs having a write back type cover all of the memory the kernel is intending to use. If not, it\textquotesingle{}ll trim any memory off the end by adjusting end\+\_\+pfn, removing it from the kernel\textquotesingle{}s allocation pools, warning the user with an obnoxious message.
