\doxysubsection{Detailed Description}
Configuration for the W\+M831x D\+C-\/\+DC Buck\+Wise convertors. This should be passed as driver\+\_\+data in the \mbox{\hyperlink{structregulator__init__data}{regulator\+\_\+init\+\_\+data}}.

Currently all the configuration is for the fast D\+VS switching support of the devices. This allows M\+F\+Ps on the device to be configured as an input to switch between two output voltages, allowing voltage transitions without the expense of an access over I2C or S\+PI buses.
