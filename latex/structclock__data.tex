\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structclock__data}{clock\+\_\+data}} -\/ all data needed for \mbox{\hyperlink{tsc_8c_aabe9553f0e7e14e3a42e686fd7ae3eed}{sched\+\_\+clock()}} (including registration of a new clock source)

@seq\+: Sequence counter for protecting updates. \mbox{\hyperlink{classThe}{The}} lowest bit is the index for @read\+\_\+data. @read\+\_\+data\+: Data required to read from sched\+\_\+clock. @wrap\+\_\+kt\+: Duration for which clock can run before wrapping. @rate\+: Tick rate of the registered clock. @actual\+\_\+read\+\_\+sched\+\_\+clock\+: Registered hardware level clock read function.

\mbox{\hyperlink{classThe}{The}} ordering of this structure has been chosen to optimize cache performance. In particular \textquotesingle{}seq\textquotesingle{} and \textquotesingle{}read\+\_\+data\mbox{[}0\mbox{]}\textquotesingle{} (combined) should fit into a single 64-\/byte cache line.
