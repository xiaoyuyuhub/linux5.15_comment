If @false is returned, it is the caller\textquotesingle{}s responsibility to invoke this function later on until it does return @true. Alternatively, the caller can explicitly wait for a grace period, for example, by passing @oldstate to \mbox{\hyperlink{tree_8c_a29db2a365de14ef720fd3557734b6ec7}{cond\+\_\+synchronize\+\_\+rcu()}} or by directly invoking \mbox{\hyperlink{tree_8c_a2a82b0ecedfdd3957789e90bdfd47756}{synchronize\+\_\+rcu()}}.
