numa\+\_\+emulation -\/ Emulate N\+U\+MA nodes @numa\+\_\+meminfo\+: N\+U\+MA configuration to massage @numa\+\_\+dist\+\_\+cnt\+: \mbox{\hyperlink{classThe}{The}} size of the physical N\+U\+MA distance table

Emulate N\+U\+MA nodes according to the numa=fake kernel parameter. @numa\+\_\+meminfo \mbox{\hyperlink{protocolcontains-p}{contains}} the physical memory configuration and is modified to reflect the emulated configuration on success. @numa\+\_\+dist\+\_\+cnt is used to determine the size of the physical distance table.

On success, the following modifications are made.


\begin{DoxyItemize}
\item @numa\+\_\+meminfo is updated to reflect the emulated nodes.
\item \+\_\+\+\_\+apicid\+\_\+to\+\_\+node\mbox{[}\mbox{]} is updated such that A\+P\+IC I\+Ds are mapped to the emulated nodes.
\item N\+U\+MA distance table is rebuilt to represent distances between emulated nodes. \mbox{\hyperlink{classThe}{The}} distances are determined considering how emulated nodes are mapped to physical nodes and match the actual distances.
\item emu\+\_\+nid\+\_\+to\+\_\+phys\mbox{[}\mbox{]} reflects how emulated nodes are mapped to physical nodes. This is used by \mbox{\hyperlink{numa__emulation_8c_afc2cb0a4995888119152907471a1e439}{numa\+\_\+add\+\_\+cpu()}} and \mbox{\hyperlink{numa__emulation_8c_a79536692ae975a916f5a9e4ca09ca478}{numa\+\_\+remove\+\_\+cpu()}}.
\end{DoxyItemize}
