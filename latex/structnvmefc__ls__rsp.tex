\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structnvmefc__ls__rsp}{nvmefc\+\_\+ls\+\_\+rsp}} -\/ Structure passed from the transport to the L\+L\+DD to request the transmit the N\+V\+M\+E-\/\+FC LS response to a N\+V\+M\+E-\/\+FC LS request. \mbox{\hyperlink{classThe}{The}} structure originates in the L\+L\+DD and is given to the transport via the xxx\+\_\+rcv\+\_\+ls\+\_\+req() transport routine. As such, the structure represents the FC exchange context for the N\+V\+M\+E-\/\+FC LS request that was received and which the response is to be sent for. Used by the L\+L\+DD to pass the nvmet-\/fc transport (controller) received LS\textquotesingle{}s such as Create Association, Create Connection and Disconnect Association. Used by the L\+L\+DD to pass the nvme-\/fc transport (host) received LS\textquotesingle{}s such as Disconnect Association or Disconnect Connection.

\mbox{\hyperlink{classThe}{The}} structure is allocated by the L\+L\+DD whenever a LS Request is received from the FC link. \mbox{\hyperlink{classThe}{The}} address of the structure is passed to the nvmet-\/fc or nvme-\/fc layer via the xxx\+\_\+rcv\+\_\+ls\+\_\+req() transport routines.

\mbox{\hyperlink{classThe}{The}} address of the structure is to be passed back to the L\+L\+DD when the response is to be transmit. \mbox{\hyperlink{classThe}{The}} L\+L\+DD will use the address to map back to the L\+L\+DD exchange structure which maintains information such the remote N\+\_\+\+Port that sent the LS as well as any FC exchange context. Upon completion of the LS response transmit, the L\+L\+DD will pass the address of the structure back to the transport LS rsp \mbox{\hyperlink{structnvmefc__ls__rsp_ad02c7bf5ba2b21eebb017c2473743406}{done()}} routine, allowing the transport release dma resources. Upon completion of the \mbox{\hyperlink{structnvmefc__ls__rsp_ad02c7bf5ba2b21eebb017c2473743406}{done()}} routine, no further access to the structure will be made by the transport and the L\+L\+DD can de-\/allocate the structure.

Field initialization\+: At the time of the xxx\+\_\+rcv\+\_\+ls\+\_\+req() call, there is no content that is valid in the structure.

When the structure is used for the L\+L\+D\+D-\/$>$xmt\+\_\+ls\+\_\+rsp() call, the transport layer will fully set the fields in order to specify the response payload buffer and its length as well as the done routine to be called upon completion of the transmit. \mbox{\hyperlink{classThe}{The}} transport layer will also set a private pointer for its own use in the done routine.

Values set by the transport layer prior to calling the L\+L\+DD xmt\+\_\+ls\+\_\+rsp entrypoint\+: @rspbuf\+: pointer to the LS response buffer @rspdma\+: P\+CI D\+MA address of the LS response buffer @rsplen\+: Length, in bytes, of the LS response buffer @done\+: \mbox{\hyperlink{classThe}{The}} callback routine the L\+L\+DD is to invoke upon completion of transmitting the LS response. req argument is the pointer to the original ls request. @nvme\+\_\+fc\+\_\+private\+: pointer to an internal transport-\/specific structure used as part of the transport \mbox{\hyperlink{structnvmefc__ls__rsp_ad02c7bf5ba2b21eebb017c2473743406}{done()}} processing. \mbox{\hyperlink{classThe}{The}} L\+L\+DD is not to access this pointer.
