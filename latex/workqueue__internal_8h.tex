Determine the last function a worker executed. This is called from the scheduler to get a worker\textquotesingle{}s last known identity.

C\+O\+N\+T\+E\+XT\+: raw\+\_\+spin\+\_\+lock\+\_\+irq(rq-\/$>$lock)

This function is called during \mbox{\hyperlink{kernel_2sched_2core_8c_a7366dbeb1fb6baba9c376a2310e2d966}{schedule()}} when a kworker is going to sleep. It\textquotesingle{}s used by psi to identify aggregation workers during dequeuing, to allow periodic aggregation to shut-\/off when that worker is the last task in the system or cgroup to go to sleep.

As this function doesn\textquotesingle{}t involve any workqueue-\/related locking, it only returns stable values when called from inside the scheduler\textquotesingle{}s queuing and dequeuing paths, when @task, which must be a kworker, is guaranteed to not be processing any works.
