struct \mbox{\hyperlink{structloop__config}{loop\+\_\+config}} -\/ Complete configuration for a loop device. @fd\+: fd of the file to be used as a backing file for the loop device. @block\+\_\+size\+: block size to use; ignored if 0. @info\+: struct \mbox{\hyperlink{structloop__info64}{loop\+\_\+info64}} to configure the loop device with.
