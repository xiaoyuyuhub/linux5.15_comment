vdso\+\_\+update\+\_\+begin -\/ Start of a V\+D\+SO update section

Allows architecture code to safely update the architecture specific V\+D\+SO data. Disables interrupts, acquires timekeeper lock to serialize against concurrent updates from timekeeping and invalidates the V\+D\+SO data sequence counter to prevent concurrent readers from accessing inconsistent data.
