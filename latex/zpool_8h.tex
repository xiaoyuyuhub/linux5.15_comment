This checks if the @type pool driver is available. This will try to load the requested module, if needed, but there is no guarantee the module will still be loaded and available immediately after calling. If this returns true, the caller should assume the pool is available, but must be prepared to handle the @zpool\+\_\+create\+\_\+pool() returning failure.
