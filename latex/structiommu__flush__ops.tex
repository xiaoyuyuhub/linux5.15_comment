\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structiommu__flush__ops}{iommu\+\_\+flush\+\_\+ops}} -\/ I\+O\+M\+MU callbacks for T\+LB and page table management.

@tlb\+\_\+flush\+\_\+all\+: Synchronously invalidate the entire T\+LB context. @tlb\+\_\+flush\+\_\+walk\+: Synchronously invalidate all intermediate T\+LB state (sometimes referred to as the \char`\"{}walk cache\char`\"{}) for a virtual address range. @tlb\+\_\+add\+\_\+page\+: Optional callback to queue up leaf T\+LB invalidation for a single page. I\+O\+M\+M\+Us that cannot batch T\+LB invalidation operations efficiently will typically issue them here, but others may decide to update the \mbox{\hyperlink{structiommu__iotlb__gather}{iommu\+\_\+iotlb\+\_\+gather}} structure and defer the invalidation until \mbox{\hyperlink{include_2linux_2iommu_8h_adbc0efe892a6038c072be4ebd46cb909}{iommu\+\_\+iotlb\+\_\+sync()}} instead.

Note that these can all be called in atomic context and must therefore not block.
