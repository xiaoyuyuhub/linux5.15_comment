\doxysubsection{Detailed Description}
Replacement weights and ids for a given straw2 bucket, for placement purposes.

When \mbox{\hyperlink{mapper_8h_a84bea04c5a8297f2e8ae6743bef91070}{crush\+\_\+do\+\_\+rule()}} chooses the Nth item from a straw2 bucket, the replacement weights found at {\bfseries{weight\+\_\+set\mbox{[}N\mbox{]}}} are used instead of the weights from {\bfseries{item\+\_\+weights}}. If {\bfseries{N}} is greater than {\bfseries{weight\+\_\+set\+\_\+size}}, the weights found at {\bfseries{weight\+\_\+set\+\_\+size-\/1}} are used instead. For instance if {\bfseries{weight\+\_\+set}} is\+:

\mbox{[} \mbox{[} 0x10000, 0x20000 \mbox{]}, // position 0 \mbox{[} 0x20000, 0x40000 \mbox{]} \mbox{]} // position 1

choosing the 0th item will use position 0 weights \mbox{[} 0x10000, 0x20000 \mbox{]} choosing the 1th item will use position 1 weights \mbox{[} 0x20000, 0x40000 \mbox{]} choosing the 2th item will use position 1 weights \mbox{[} 0x20000, 0x40000 \mbox{]} etc.
