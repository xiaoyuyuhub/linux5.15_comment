\doxysubsection{Detailed Description}
D\+OC\+: D\+P\+A\+A2 FD -\/ Frame Descriptor A\+P\+Is for D\+P\+A\+A2

Frame Descriptors (F\+Ds) are used to describe frame data in the D\+P\+A\+A2. Frames can be enqueued and dequeued to Frame Queues (F\+Qs) which are consumed by the various D\+P\+AA accelerators (W\+R\+I\+OP, S\+EC, P\+ME, D\+CE)

There are three types of frames\+: single, scatter gather, and frame lists.

\mbox{\hyperlink{classThe}{The}} set of A\+P\+Is in this file must be used to create, manipulate and query Frame Descriptors. struct \mbox{\hyperlink{structdpaa2__fd}{dpaa2\+\_\+fd}} -\/ Struct describing F\+Ds @words\+: for easier/faster copying the whole FD structure @addr\+: address in the FD @len\+: length in the FD @bpid\+: buffer pool ID @format\+\_\+offset\+: format, offset, and short-\/length fields @frc\+: frame context @ctrl\+: control bits...including dd, sc, va, err, etc @flc\+: flow context address

This structure represents the basic Frame Descriptor used in the system.
