packing -\/ Convert numbers (currently u64) between a packed and an unpacked format. Unpacked means laid out in memory in the C\+PU\textquotesingle{}s native understanding of integers, while packed means anything else that requires translation.

@pbuf\+: Pointer to a buffer holding the packed value. @uval\+: Pointer to an u64 holding the unpacked value. @startbit\+: \mbox{\hyperlink{classThe}{The}} index (in logical notation, compensated for quirks) where the packed value starts within pbuf. Must be larger than, or equal to, endbit. @endbit\+: \mbox{\hyperlink{classThe}{The}} index (in logical notation, compensated for quirks) where the packed value ends within pbuf. Must be smaller than, or equal to, startbit. @pbuflen\+: \mbox{\hyperlink{classThe}{The}} length in bytes of the packed buffer pointed to by @pbuf. @op\+: If P\+A\+CK, then uval will be treated as const pointer and copied (packed) into pbuf, between startbit and endbit. If U\+N\+P\+A\+CK, then pbuf will be treated as const pointer and the logical value between startbit and endbit will be copied (unpacked) to uval. @quirks\+: A bit mask of Q\+U\+I\+R\+K\+\_\+\+L\+I\+T\+T\+L\+E\+\_\+\+E\+N\+D\+I\+AN, Q\+U\+I\+R\+K\+\_\+\+L\+S\+W32\+\_\+\+I\+S\+\_\+\+F\+I\+R\+ST and Q\+U\+I\+R\+K\+\_\+\+M\+S\+B\+\_\+\+O\+N\+\_\+\+T\+H\+E\+\_\+\+R\+I\+G\+HT.

Return\+: 0 on success, E\+I\+N\+V\+AL or E\+R\+A\+N\+GE if called incorrectly. Assuming correct usage, return code may be discarded. If op is P\+A\+CK, pbuf is modified. If op is U\+N\+P\+A\+CK, uval is modified. Here is the call graph for this function\+:
