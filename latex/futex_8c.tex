Set the futex exit state of the task lockless. \mbox{\hyperlink{classThe}{The}} futex waiter code observes that state when a task is exiting and loops until the task has actually finished the futex cleanup. \mbox{\hyperlink{classThe}{The}} worst case for this is that the waiter runs through the wait loop until the state becomes visible.
