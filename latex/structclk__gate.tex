struct \mbox{\hyperlink{structclk__gate}{clk\+\_\+gate}} -\/ gating clock

Clock which can gate its output. Implements .enable \& .disable

Flags\+: C\+L\+K\+\_\+\+G\+A\+T\+E\+\_\+\+S\+E\+T\+\_\+\+T\+O\+\_\+\+D\+I\+S\+A\+B\+LE -\/ by default this clock sets the bit at bit\+\_\+idx to enable the clock.
