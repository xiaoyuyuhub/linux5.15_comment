There\textquotesingle{}s no reason to use this function for the usual reference counting. To re-\/use an expired ref, use \mbox{\hyperlink{percpu-refcount_8c_ae57d23ea6dae360ed5c4f4778dd37c49}{percpu\+\_\+ref\+\_\+reinit()}}.

Switch \mbox{\hyperlink{to}{get.}} percpu mode. This function may be invoked concurrently with all the get/put operations and can safely be mixed with kill and reinit operations. This function reverses the sticky atomic state set by P\+E\+R\+C\+P\+U\+\_\+\+R\+E\+F\+\_\+\+I\+N\+I\+T\+\_\+\+A\+T\+O\+M\+IC or \mbox{\hyperlink{percpu-refcount_8c_aa7dbabe0bf1ce928e3fdd309ac8c3354}{percpu\+\_\+ref\+\_\+switch\+\_\+to\+\_\+atomic()}}. If \mbox{\hyperlink{is}{mapped at}} dying or dead, the actual switching takes place on the following \mbox{\hyperlink{percpu-refcount_8c_ae57d23ea6dae360ed5c4f4778dd37c49}{percpu\+\_\+ref\+\_\+reinit()}}.

This function may block if \mbox{\hyperlink{is}{mapped at}} in the process of switching to atomic mode.
