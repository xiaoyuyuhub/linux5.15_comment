\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structmm__walk__ops}{mm\+\_\+walk\+\_\+ops}} -\/ callbacks for walk\+\_\+page\+\_\+range @pgd\+\_\+entry\+: if set, called for each non-\/empty P\+GD (top-\/level) entry @p4d\+\_\+entry\+: if set, called for each non-\/empty P4D entry @pud\+\_\+entry\+: if set, called for each non-\/empty P\+UD entry @pmd\+\_\+entry\+: if set, called for each non-\/empty P\+MD entry this handler is required to be able to handle pmd\+\_\+trans\+\_\+huge() pmds. They may simply choose to \mbox{\hyperlink{huge__mm_8h_ac0dae4413336925070ad226600fa39e8}{split\+\_\+huge\+\_\+page()}} instead of handling it explicitly. @pte\+\_\+entry\+: if set, called for each non-\/empty P\+TE (lowest-\/level) entry @pte\+\_\+hole\+: if set, called for each hole at all levels, depth is -\/1 if not known, 0\+:P\+GD, 1\+:P4D, 2\+:P\+UD, 3\+:P\+MD 4\+:P\+TE. Any folded depths (where P\+T\+R\+S\+\_\+\+P\+E\+R\+\_\+P?D is equal to 1) are skipped. @hugetlb\+\_\+entry\+: if set, called for each hugetlb entry @test\+\_\+walk\+: caller specific callback function to determine whether we walk over the current vma or not. Returning 0 means \char`\"{}do page table walk over the current vma\char`\"{}, returning a negative value means \char`\"{}abort current page table walk
        right now\char`\"{} and returning 1 means \char`\"{}skip the current vma\char`\"{} @pre\+\_\+vma\+: if set, called before starting walk on a non-\/null vma. @post\+\_\+vma\+: if set, called after a walk on a non-\/null vma, provided that @pre\+\_\+vma and the vma walk succeeded.
