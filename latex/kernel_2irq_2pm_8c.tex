suspend\+\_\+device\+\_\+irqs -\/ disable all currently enabled interrupt lines

During system-\/wide suspend or hibernation device drivers need to be prevented from receiving interrupts and this function is provided for this purpose.

So we disable all interrupts and mark them I\+R\+Q\+S\+\_\+\+S\+U\+S\+P\+E\+N\+D\+ED except for those which are unused, those which are marked as not suspendable via an interrupt request with the flag I\+R\+Q\+F\+\_\+\+N\+O\+\_\+\+S\+U\+S\+P\+E\+ND set and those which are marked as active wakeup sources.
