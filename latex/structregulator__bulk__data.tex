struct \mbox{\hyperlink{structregulator__bulk__data}{regulator\+\_\+bulk\+\_\+data}} -\/ Data used for bulk regulator operations.

@supply\+: \mbox{\hyperlink{classThe}{The}} name of the supply. Initialised by the user before using the bulk regulator A\+P\+Is. @consumer\+: \mbox{\hyperlink{classThe}{The}} regulator consumer for the supply. This will be managed by the bulk A\+PI.
