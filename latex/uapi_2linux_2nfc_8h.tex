@\+N\+F\+C\+\_\+\+C\+M\+D\+\_\+\+L\+L\+C\+\_\+\+G\+E\+T\+\_\+\+P\+A\+R\+A\+MS\+: request L\+TO, RW, and M\+I\+UX parameters for a device @\+N\+F\+C\+\_\+\+C\+M\+D\+\_\+\+L\+L\+C\+\_\+\+S\+E\+T\+\_\+\+P\+A\+R\+A\+MS\+: set one or more of L\+TO, RW, and M\+I\+UX parameters for a device.
