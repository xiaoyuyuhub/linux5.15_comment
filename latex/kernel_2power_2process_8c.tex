freeze\+\_\+kernel\+\_\+threads -\/ Make freezable kernel threads go to the refrigerator.

On success, returns 0. On failure, -\/errno and only the kernel threads are thawed, so as to give a chance to the caller to do additional cleanups (if any) before thawing the userspace tasks.
