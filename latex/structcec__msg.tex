\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structcec__msg}{cec\+\_\+msg}} -\/ C\+EC message structure. @tx\+\_\+ts\+: Timestamp in nanoseconds using C\+L\+O\+C\+K\+\_\+\+M\+O\+N\+O\+T\+O\+N\+IC. Set by the driver when the message transmission has finished. @rx\+\_\+ts\+: Timestamp in nanoseconds using C\+L\+O\+C\+K\+\_\+\+M\+O\+N\+O\+T\+O\+N\+IC. Set by the driver when the message was received. @len\+: Length in bytes of the message. @timeout\+: \mbox{\hyperlink{classThe}{The}} timeout (in ms) that is used to timeout C\+E\+C\+\_\+\+R\+E\+C\+E\+I\+VE. If 0, then it will use a 1 second timeout instead of waiting forever as is done with C\+E\+C\+\_\+\+R\+E\+C\+E\+I\+VE. @sequence\+: \mbox{\hyperlink{classThe}{The}} framework assigns a sequence number to messages that are sent. If non-\/zero, then wait for a reply with this opcode. Set to C\+E\+C\+\_\+\+M\+S\+G\+\_\+\+F\+E\+A\+T\+U\+R\+E\+\_\+\+A\+B\+O\+RT if you want to wait for a possible A\+B\+O\+RT reply. If there was an error when sending the msg or Feature\+Abort was returned, then reply is set to 0. If reply is non-\/zero upon return, then len/msg are set to the received message. If reply is zero upon return and status has the C\+E\+C\+\_\+\+T\+X\+\_\+\+S\+T\+A\+T\+U\+S\+\_\+\+F\+E\+A\+T\+U\+R\+E\+\_\+\+A\+B\+O\+RT bit set, then len/msg are set to the received feature abort message. If reply is zero upon return and status has the C\+E\+C\+\_\+\+T\+X\+\_\+\+S\+T\+A\+T\+U\+S\+\_\+\+M\+A\+X\+\_\+\+R\+E\+T\+R\+I\+ES bit set, then no reply was seen at all. If reply is non-\/zero for C\+E\+C\+\_\+\+T\+R\+A\+N\+S\+M\+IT and the message is a broadcast, then -\/E\+I\+N\+V\+AL is returned. if reply is non-\/zero, then timeout is set to 1000 (the required maximum response time). @rx\+\_\+status\+: \mbox{\hyperlink{classThe}{The}} message receive status bits. Set by the driver. @tx\+\_\+status\+: \mbox{\hyperlink{classThe}{The}} message transmit status bits. Set by the driver. @tx\+\_\+arb\+\_\+lost\+\_\+cnt\+: \mbox{\hyperlink{classThe}{The}} number of \textquotesingle{}Arbitration Lost\textquotesingle{} events.
