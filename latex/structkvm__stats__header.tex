\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structkvm__stats__header}{kvm\+\_\+stats\+\_\+header}} -\/ Header of per vm/vcpu binary statistics data. @flags\+: Some extra information for header, always 0 for now. @name\+\_\+size\+: \mbox{\hyperlink{classThe}{The}} size in bytes of the memory which \mbox{\hyperlink{protocolcontains-p}{contains}} statistics name string including trailing \textquotesingle{}\textbackslash{}0\textquotesingle{}. \mbox{\hyperlink{classThe}{The}} memory is allocated at the send of statistics descriptor. @num\+\_\+desc\+: \mbox{\hyperlink{classThe}{The}} number of statistics the vm or vcpu has. @id\+\_\+offset\+: \mbox{\hyperlink{classThe}{The}} offset of the vm/vcpu stats\textquotesingle{} id string in the file pointed by vm/vcpu stats fd. @desc\+\_\+offset\+: \mbox{\hyperlink{classThe}{The}} offset of the vm/vcpu stats\textquotesingle{} descriptor block in the file pointd by vm/vcpu stats fd. @data\+\_\+offset\+: \mbox{\hyperlink{classThe}{The}} offset of the vm/vcpu stats\textquotesingle{} data block in the file pointed by vm/vcpu stats fd.

This is the header userspace needs to read from stats fd before any other readings. It is used by userspace to discover all the information about the vm/vcpu\textquotesingle{}s binary statistics. Userspace reads this header from the start of the vm/vcpu\textquotesingle{}s stats fd.
