\mbox{\hyperlink{vmpressure_8c_a07ee52d679163ccf993f8acee6a51d12}{vmpressure()}} -\/ Account memory pressure through scanned/reclaimed ratio @gfp\+: reclaimer\textquotesingle{}s gfp mask @memcg\+: cgroup memory controller handle @tree\+: legacy subtree mode @scanned\+: number of pages scanned @reclaimed\+: number of pages reclaimed

This function should be called from the vmscan reclaim path to account \char`\"{}instantaneous\char`\"{} memory pressure (scanned/reclaimed ratio). \mbox{\hyperlink{classThe}{The}} raw pressure index is then further refined and averaged over time.

If @tree is set, vmpressure is in traditional userspace reporting mode\+: @memcg is considered the pressure root and userspace is notified of the entire subtree\textquotesingle{}s reclaim efficiency.

If @tree is not set, reclaim efficiency is recorded for @memcg, and only in-\/kernel users are notified.
