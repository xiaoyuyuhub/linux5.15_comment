\doxysubsection{Detailed Description}

This should normally match the name in its bus driver structure (e.\+g. \mbox{\hyperlink{structpci__driver_a05cc3c788ae87a07ae4d92ce603ce211}{pci\+\_\+driver\+::name}}).
