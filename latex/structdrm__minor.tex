\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__minor}{drm\+\_\+minor}} -\/ D\+RM device minor structure

This structure represents a D\+RM minor number for device nodes in /dev. Entirely opaque to drivers and should never be inspected directly by drivers. Drivers instead should only interact with \&struct \mbox{\hyperlink{structdrm__file}{drm\+\_\+file}} and of course \&struct \mbox{\hyperlink{structdrm__device}{drm\+\_\+device}}, which is also where driver-\/private data and resources can be attached to.
