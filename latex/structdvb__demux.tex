\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdvb__demux}{dvb\+\_\+demux}} -\/ represents a digital TV demux @dmx\+: embedded \&struct \mbox{\hyperlink{structdmx__demux}{dmx\+\_\+demux}} with demux capabilities and callbacks. @priv\+: private data that can optionally be used by a D\+VB driver. @filternum\+: maximum amount of D\+VB filters. @feednum\+: maximum amount of D\+VB feeds. @start\+\_\+feed\+: callback routine to be called in order to start a D\+VB feed. @stop\+\_\+feed\+: callback routine to be called in order to stop a D\+VB feed. @write\+\_\+to\+\_\+decoder\+: callback routine to be called if the feed is TS and it is routed to an A/V decoder, when a new TS packet is received. Used only on av7110-\/av.\+c. @check\+\_\+crc32\+: callback routine to check C\+RC. If not initialized, \mbox{\hyperlink{structdvb__demux}{dvb\+\_\+demux}} will use an internal one. @memcopy\+: callback routine to memcopy received data. If not initialized, \mbox{\hyperlink{structdvb__demux}{dvb\+\_\+demux}} will default to \mbox{\hyperlink{arch_2x86_2boot_2string_8h_a1ba7bbe013c04b850f2a33dfe5ba7102}{memcpy()}}. @users\+: counter for the number of demux opened file descriptors. Currently, it is limited to 10 users. @filter\+: pointer to \&struct \mbox{\hyperlink{structdvb__demux__filter}{dvb\+\_\+demux\+\_\+filter}}. @feed\+: pointer to \&struct \mbox{\hyperlink{structdvb__demux__feed}{dvb\+\_\+demux\+\_\+feed}}. @frontend\+\_\+list\+: \&struct \mbox{\hyperlink{structlist__head}{list\+\_\+head}} with frontends used by the demux. @pesfilter\+: array of \&struct \mbox{\hyperlink{structdvb__demux__feed}{dvb\+\_\+demux\+\_\+feed}} with the P\+ES types that will be filtered. @pids\+: list of filtered program I\+Ds. @feed\+\_\+list\+: \&struct \mbox{\hyperlink{structlist__head}{list\+\_\+head}} with feeds. @tsbuf\+: temporary buffer used internally to store TS packets. @tsbufp\+: temporary buffer index used internally. @mutex\+: pointer to \&struct mutex used to protect feed set logic. @lock\+: pointer to \&spinlock\+\_\+t, used to protect buffer handling. @cnt\+\_\+storage\+: buffer used for T\+S/\+T\+EI continuity check. @speed\+\_\+last\+\_\+time\+: \&ktime\+\_\+t used for TS speed check. @speed\+\_\+pkts\+\_\+cnt\+: packets count used for TS speed check.
