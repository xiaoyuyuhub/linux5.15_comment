Otherwise N\+U\+LL. \mbox{\hyperlink{classThe}{The}} match table \mbox{\hyperlink{protocolcontains-p}{contains}} vendor (X86\+\_\+\+V\+E\+N\+D\+O\+R\+\_\+$\ast$), family, model and feature bits or respective wildcard entries.

A typical table entry would be to match a specific C\+PU
