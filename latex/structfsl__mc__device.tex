\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structfsl__mc__device}{fsl\+\_\+mc\+\_\+device}} -\/ MC object device object @dev\+: Linux driver model device object @dma\+\_\+mask\+: Default D\+MA mask @flags\+: MC object device flags @icid\+: Isolation context ID for the device @mc\+\_\+handle\+: MC handle for the corresponding MC object opened @mc\+\_\+io\+: Pointer to MC IO object assigned to this device or N\+U\+LL if none. @obj\+\_\+desc\+: MC description of the D\+P\+AA device @regions\+: pointer to array of M\+M\+IO region entries @irqs\+: pointer to array of pointers to interrupts allocated to this device @resource\+: generic resource associated with this MC object device, if any. @driver\+\_\+override\+: driver name to force a match

Generic device object for MC object devices that are \char`\"{}attached\char`\"{} to a MC bus.

N\+O\+T\+ES\+:
\begin{DoxyItemize}
\item For a non-\/\+D\+P\+RC object its icid is the same as its parent D\+P\+RC\textquotesingle{}s icid.
\item \mbox{\hyperlink{classThe}{The}} S\+M\+MU notifier callback gets invoked after \mbox{\hyperlink{include_2linux_2device_8h_a3a3f81b6670d4a85de769cf063a1d71c}{device\+\_\+add()}} has been called for an MC object device, but before the device-\/specific probe callback gets called.
\item D\+P\+\_\+\+O\+B\+J\+\_\+\+D\+P\+RC objects are the only MC objects that have built-\/in MC portals. For all other MC objects, their device drivers are responsible for allocating MC portals for them by calling \mbox{\hyperlink{linux_2fsl_2mc_8h_a358b247828d2e946134252ccc322d693}{fsl\+\_\+mc\+\_\+portal\+\_\+allocate()}}.
\item Some types of MC objects (e.\+g., D\+P\+\_\+\+O\+B\+J\+\_\+\+D\+P\+BP, D\+P\+\_\+\+O\+B\+J\+\_\+\+D\+P\+C\+ON) are treated as resources that can be allocated/deallocated from the corresponding resource pool in the object\textquotesingle{}s parent D\+P\+RC, using the \mbox{\hyperlink{linux_2fsl_2mc_8h_a5a386fa6cd3db4dc0d42a5a25a3f87a8}{fsl\+\_\+mc\+\_\+object\+\_\+allocate()}}/fsl\+\_\+mc\+\_\+object\+\_\+free() functions. These MC objects are known as \char`\"{}allocatable\char`\"{} objects. For them, the corresponding \mbox{\hyperlink{structfsl__mc__device}{fsl\+\_\+mc\+\_\+device}}\textquotesingle{}s \textquotesingle{}resource\textquotesingle{} points to the associated resource object. For MC objects that are not allocatable (e.\+g., D\+P\+\_\+\+O\+B\+J\+\_\+\+D\+P\+RC, D\+P\+\_\+\+O\+B\+J\+\_\+\+D\+P\+NI), \textquotesingle{}resource\textquotesingle{} is N\+U\+LL. 
\end{DoxyItemize}
