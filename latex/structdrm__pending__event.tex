\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__pending__event}{drm\+\_\+pending\+\_\+event}} -\/ Event queued up for userspace to read

This represents a D\+RM event. Drivers can use this as a generic completion mechanism, which supports kernel-\/internal \&struct completion, \&struct \mbox{\hyperlink{structdma__fence}{dma\+\_\+fence}} and also the D\+R\+M-\/specific \&struct \mbox{\hyperlink{structdrm__event}{drm\+\_\+event}} delivery mechanism.
