\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structcxl__mem__query__commands}{cxl\+\_\+mem\+\_\+query\+\_\+commands}} -\/ Query supported commands. @n\+\_\+commands\+: In/out parameter. When @n\+\_\+commands is $>$ 0, the driver will return \mbox{\hyperlink{minmax_8h_abb702d8b501669a23aa0ab3b281b9384}{min(num\+\_\+support\+\_\+commands, n\+\_\+commands)}}. Allow userspace to query the available commands supported by both the driver, and the hardware. Commands that aren\textquotesingle{}t supported by either the driver, or the hardware are not returned in the query.
