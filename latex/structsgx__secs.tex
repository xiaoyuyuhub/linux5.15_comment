S\+GX Enclave Control Structure (S\+E\+CS) is a special enclave page that is not visible in the address space. In fact, this structure defines the address range and other global attributes for the enclave and it is the first E\+PC page created for any enclave. It is moved from a temporary buffer to an E\+PC by the means of E\+N\+C\+LS\mbox{[}E\+C\+R\+E\+A\+TE\mbox{]} function.
