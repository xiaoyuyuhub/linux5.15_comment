\mbox{\hyperlink{z3fold_8c_a48908cc86221eebae65da5a110fad272}{z3fold\+\_\+reclaim\+\_\+page()}} -\/ evicts allocations from a pool page and frees it @pool\+: pool from which a page will attempt to be evicted @retries\+: number of pages on the L\+RU list for which eviction will be attempted before failing

z3fold reclaim is different from normal system reclaim in that it is done from the bottom, up. This is because only the bottom layer, z3fold, has information on how the allocations are organized within each z3fold page. This has the potential to create interesting locking situations between z3fold and the user, however.

To avoid these, this is how \mbox{\hyperlink{z3fold_8c_a48908cc86221eebae65da5a110fad272}{z3fold\+\_\+reclaim\+\_\+page()}} should be called\+:

\mbox{\hyperlink{classThe}{The}} user detects a page should be reclaimed and calls \mbox{\hyperlink{z3fold_8c_a48908cc86221eebae65da5a110fad272}{z3fold\+\_\+reclaim\+\_\+page()}}. \mbox{\hyperlink{z3fold_8c_a48908cc86221eebae65da5a110fad272}{z3fold\+\_\+reclaim\+\_\+page()}} will remove a z3fold page from the pool L\+RU list and call the user-\/defined eviction handler with the pool and handle as arguments.

If the handle can not be evicted, the eviction handler should return non-\/zero. \mbox{\hyperlink{z3fold_8c_a48908cc86221eebae65da5a110fad272}{z3fold\+\_\+reclaim\+\_\+page()}} will add the z3fold page back to the appropriate list and try the next z3fold page on the L\+RU up to a user defined number of retries.

If the handle is successfully evicted, the eviction handler should return 0 {\itshape and} should have called \mbox{\hyperlink{z3fold_8c_ac2f8250f71cfe596b4a38d8b0ca14b0c}{z3fold\+\_\+free()}} on the handle. \mbox{\hyperlink{z3fold_8c_ac2f8250f71cfe596b4a38d8b0ca14b0c}{z3fold\+\_\+free()}} \mbox{\hyperlink{protocolcontains-p}{contains}} logic to delay freeing the page if the page is under reclaim, as indicated by the setting of the P\+G\+\_\+reclaim flag on the underlying page.

If all buddies in the z3fold page are successfully evicted, then the z3fold page can be freed.

Returns\+: 0 if page is successfully freed, otherwise -\/E\+I\+N\+V\+AL if there are no pages to evict or an eviction handler is not registered, -\/E\+A\+G\+A\+IN if the retry limit was hit. Here is the call graph for this function\+:
