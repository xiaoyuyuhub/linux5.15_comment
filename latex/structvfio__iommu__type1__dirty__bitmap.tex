\doxysubsection{Detailed Description}
V\+F\+I\+O\+\_\+\+I\+O\+M\+M\+U\+\_\+\+D\+I\+R\+T\+Y\+\_\+\+P\+A\+G\+ES -\/ \+\_\+\+I\+O\+WR(V\+F\+I\+O\+\_\+\+T\+Y\+PE, V\+F\+I\+O\+\_\+\+B\+A\+SE + 17, struct \mbox{\hyperlink{structvfio__iommu__type1__dirty__bitmap}{vfio\+\_\+iommu\+\_\+type1\+\_\+dirty\+\_\+bitmap}}) I\+O\+C\+TL is used for dirty pages logging. Caller should set flag depending on which operation to perform, details as below\+:

Calling the I\+O\+C\+TL with V\+F\+I\+O\+\_\+\+I\+O\+M\+M\+U\+\_\+\+D\+I\+R\+T\+Y\+\_\+\+P\+A\+G\+E\+S\+\_\+\+F\+L\+A\+G\+\_\+\+S\+T\+A\+RT flag set, instructs the I\+O\+M\+MU driver to log pages that are dirtied or potentially dirtied by the device; designed to be used when a migration is in progress. Dirty pages are logged until logging is disabled by user application by calling the I\+O\+C\+TL with V\+F\+I\+O\+\_\+\+I\+O\+M\+M\+U\+\_\+\+D\+I\+R\+T\+Y\+\_\+\+P\+A\+G\+E\+S\+\_\+\+F\+L\+A\+G\+\_\+\+S\+T\+OP flag.

Calling the I\+O\+C\+TL with V\+F\+I\+O\+\_\+\+I\+O\+M\+M\+U\+\_\+\+D\+I\+R\+T\+Y\+\_\+\+P\+A\+G\+E\+S\+\_\+\+F\+L\+A\+G\+\_\+\+S\+T\+OP flag set, instructs the I\+O\+M\+MU driver to stop logging dirtied pages.

Calling the I\+O\+C\+TL with V\+F\+I\+O\+\_\+\+I\+O\+M\+M\+U\+\_\+\+D\+I\+R\+T\+Y\+\_\+\+P\+A\+G\+E\+S\+\_\+\+F\+L\+A\+G\+\_\+\+G\+E\+T\+\_\+\+B\+I\+T\+M\+AP flag set returns the dirty pages bitmap for I\+O\+M\+MU container for a given I\+O\+VA range. \mbox{\hyperlink{classThe}{The}} user must specify the I\+O\+VA range and the pgsize through the structure \mbox{\hyperlink{structvfio__iommu__type1__dirty__bitmap__get}{vfio\+\_\+iommu\+\_\+type1\+\_\+dirty\+\_\+bitmap\+\_\+get}} in the data\mbox{[}\mbox{]} portion. This interface supports getting a bitmap of the smallest supported pgsize only and can be modified in future to get a bitmap of any specified supported pgsize. \mbox{\hyperlink{classThe}{The}} user must provide a zeroed memory area for the bitmap memory and specify its size in bitmap.\+size. One bit is used to represent one page consecutively starting from iova offset. \mbox{\hyperlink{classThe}{The}} user should provide page size in bitmap.\+pgsize field. A bit set in the bitmap indicates that the page at that offset from iova is dirty. \mbox{\hyperlink{classThe}{The}} caller must set argsz to a value including the size of structure \mbox{\hyperlink{structvfio__iommu__type1__dirty__bitmap__get}{vfio\+\_\+iommu\+\_\+type1\+\_\+dirty\+\_\+bitmap\+\_\+get}}, but excluding the size of the actual bitmap. If dirty pages logging is not enabled, an error will be returned.

Only one of the flags \+\_\+\+S\+T\+A\+RT, \+\_\+\+S\+T\+OP and \+\_\+\+G\+ET may be specified at a time.
