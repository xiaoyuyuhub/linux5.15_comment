Context\+: User context only. This function may sleep if pagefaults are enabled.

Get the size of a N\+U\+L-\/terminated string in user space.

Returns the size of the string I\+N\+C\+L\+U\+D\+I\+NG the terminating N\+UL. If the string is too long, returns a number larger than @count. User has to check the return value against \char`\"{}$>$ count\char`\"{}. On exception (or invalid count), returns 0.

N\+O\+T\+E! You should basically never use this function. There is almost never any valid case for using the length of a user space string, since the string can be changed at any time by other threads.
