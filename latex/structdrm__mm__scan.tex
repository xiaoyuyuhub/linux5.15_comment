\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__mm__scan}{drm\+\_\+mm\+\_\+scan}} -\/ D\+RM allocator eviction roaster data

This structure tracks data needed for the eviction roaster set up using \mbox{\hyperlink{drm__mm_8h_a1e682e1d3a188e77b6207362a121675e}{drm\+\_\+mm\+\_\+scan\+\_\+init()}}, and used with \mbox{\hyperlink{drm__mm_8h_a7c5d1bcc427f7f4cb2a077cfed24b685}{drm\+\_\+mm\+\_\+scan\+\_\+add\+\_\+block()}} and \mbox{\hyperlink{drm__mm_8h_a6eb69e1e31ba696a9c17f3c9cf3c6669}{drm\+\_\+mm\+\_\+scan\+\_\+remove\+\_\+block()}}. \mbox{\hyperlink{classThe}{The}} structure is entirely opaque and should only be accessed through the provided functions and macros. It is meant to be allocated temporarily by the driver on the stack.
