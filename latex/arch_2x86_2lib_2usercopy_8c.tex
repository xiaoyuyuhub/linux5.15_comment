Returns\+: \mbox{\hyperlink{classThe}{The}} number of not copied bytes. 0 is success, i.\+e. all bytes copied

Contrary to other \mbox{\hyperlink{include_2linux_2uaccess_8h_a42356f201e9b422225189445b2f8c40f}{copy\+\_\+from\+\_\+user()}} variants this function can be called from N\+MI context. Despite the name it is not restricted to be called from N\+MI context. It is safe to be called from any other context as well. It disables pagefaults across the copy which means a fault will abort the copy.
