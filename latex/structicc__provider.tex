\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structicc__provider}{icc\+\_\+provider}} -\/ interconnect provider (controller) entity that might provide multiple interconnect controls

@provider\+\_\+list\+: list of the registered interconnect providers @nodes\+: internal list of the interconnect provider nodes @set\+: pointer to device specific set operation function @aggregate\+: pointer to device specific aggregate operation function @pre\+\_\+aggregate\+: pointer to device specific function that is called before the aggregation begins (optional) @get\+\_\+bw\+: pointer to device specific function to get current bandwidth @xlate\+: provider-\/specific callback for mapping nodes from phandle arguments @xlate\+\_\+extended\+: vendor-\/specific callback for mapping node data from phandle arguments @dev\+: the device this interconnect provider belongs to @users\+: count of active users @inter\+\_\+set\+: whether inter-\/provider pairs will be configured with @set @data\+: pointer to private data
