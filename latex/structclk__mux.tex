\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structclk__mux}{clk\+\_\+mux}} -\/ multiplexer clock

@hw\+: handle between common and hardware-\/specific interfaces @reg\+: register controlling multiplexer @table\+: array of register values corresponding to the parent index @shift\+: shift to multiplexer bit field @mask\+: mask of mutliplexer bit field @flags\+: hardware-\/specific flags @lock\+: register lock

Clock with multiple selectable parents. Implements .get\+\_\+parent, .set\+\_\+parent and .recalc\+\_\+rate

Flags\+: C\+L\+K\+\_\+\+M\+U\+X\+\_\+\+I\+N\+D\+E\+X\+\_\+\+O\+NE -\/ register index starts at 1, not 0 C\+L\+K\+\_\+\+M\+U\+X\+\_\+\+I\+N\+D\+E\+X\+\_\+\+B\+IT -\/ register index is a single bit (power of two) C\+L\+K\+\_\+\+M\+U\+X\+\_\+\+H\+I\+W\+O\+R\+D\+\_\+\+M\+A\+SK -\/ \mbox{\hyperlink{classThe}{The}} mux settings are only in lower 16-\/bit of this register, and mask of mux bits are in higher 16-\/bit of this register. While setting the mux bits, higher 16-\/bit should also be updated to indicate changing mux bits. C\+L\+K\+\_\+\+M\+U\+X\+\_\+\+R\+E\+A\+D\+\_\+\+O\+N\+LY -\/ \mbox{\hyperlink{classThe}{The}} mux registers can\textquotesingle{}t be written, only read in the .get\+\_\+parent clk\+\_\+op. C\+L\+K\+\_\+\+M\+U\+X\+\_\+\+R\+O\+U\+N\+D\+\_\+\+C\+L\+O\+S\+E\+ST -\/ Use the parent rate that is closest to the desired frequency. C\+L\+K\+\_\+\+M\+U\+X\+\_\+\+B\+I\+G\+\_\+\+E\+N\+D\+I\+AN -\/ By default little endian register accesses are used for the mux register. Setting this flag makes the register accesses big endian.
