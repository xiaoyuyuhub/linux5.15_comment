\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structregulator__coupler}{regulator\+\_\+coupler}} -\/ customized regulator\textquotesingle{}s coupler

Regulator\textquotesingle{}s coupler allows to customize coupling algorithm.

@list\+: couplers list entry @attach\+\_\+regulator\+: Callback invoked on creation of a coupled regulator, couples are unresolved at this point. \mbox{\hyperlink{classThe}{The}} callee should check that it could handle the regulator and return 0 on success, -\/errno on failure and 1 if given regulator is not suitable for this coupler (case of having multiple regulators in a system). Callback shall be implemented. @detach\+\_\+regulator\+: Callback invoked on destruction of a coupled regulator. This callback is optional and could be N\+U\+LL. @balance\+\_\+voltage\+: Callback invoked when voltage of a coupled regulator is changing. Called with all of the coupled rdev\textquotesingle{}s being held under \char`\"{}consumer lock\char`\"{}. \mbox{\hyperlink{classThe}{The}} callee should perform voltage balancing, changing voltage of the coupled regulators as needed. It\textquotesingle{}s up to the coupler to verify the voltage before changing it in hardware, i.\+e. coupler should check consumer\textquotesingle{}s min/max and etc. This callback is optional and could be N\+U\+LL, in which case a generic voltage balancer will be used.
