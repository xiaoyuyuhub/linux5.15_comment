\doxysubsection{Detailed Description}
struct tveeprom -\/ Contains the fields parsed from Hauppauge eeproms

@has\+\_\+radio\+: 1 if the device has radio; 0 otherwise.

@has\+\_\+ir\+: If has\+\_\+ir == 0, then it is unknown what the IR capabilities are. Otherwise\+: bit 0) 1 (= IR capabilities are known); bit 1) IR receiver present; bit 2) IR transmitter (blaster) present.

@has\+\_\+\+M\+A\+C\+\_\+address\+: 0\+: no M\+AC, 1\+: M\+AC present, 2\+: unknown. @tuner\+\_\+type\+: type of the tuner (T\+U\+N\+E\+R\+\_\+$\ast$, as defined at \mbox{\hyperlink{tuner_8h}{include/media/tuner.\+h}}).

@tuner\+\_\+formats\+: Supported analog TV standards (V4\+L2\+\_\+\+S\+T\+D\+\_\+$\ast$). @tuner\+\_\+hauppauge\+\_\+model\+: Hauppauge\textquotesingle{}s code for the device model number. @tuner2\+\_\+type\+: type of the second tuner (T\+U\+N\+E\+R\+\_\+$\ast$, as defined at \mbox{\hyperlink{tuner_8h}{include/media/tuner.\+h}}).

@tuner2\+\_\+formats\+: Tuner 2 supported analog TV standards (V4\+L2\+\_\+\+S\+T\+D\+\_\+$\ast$).

@tuner2\+\_\+hauppauge\+\_\+model\+: tuner 2 Hauppauge\textquotesingle{}s code for the device model number.

@audio\+\_\+processor\+: analog audio decoder, as defined by enum tveeprom\+\_\+audio\+\_\+processor.

@decoder\+\_\+processor\+: Hauppauge\textquotesingle{}s code for the decoder chipset. Unused by the drivers, as they probe the decoder based on the P\+CI or U\+SB ID.

@model\+: Hauppauge\textquotesingle{}s model number

@revision\+: Card revision number

@serial\+\_\+number\+: Card\textquotesingle{}s serial number

@rev\+\_\+str\+: Card revision converted to number

@\+M\+A\+C\+\_\+address\+: M\+AC address for the network interface
