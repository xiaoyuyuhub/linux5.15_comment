\doxysubsection{Detailed Description}
struct rmi\+\_\+2d\+\_\+sensor\+\_\+data -\/ overrides defaults for a 2D sensor. @axis\+\_\+align -\/ provides axis alignment overrides (see above). @sensor\+\_\+type -\/ Forces the driver to treat the sensor as an indirect pointing device (touchpad) rather than a direct pointing device (touchscreen). This is useful when F11\+\_\+2\+D\+\_\+\+Q\+U\+E\+R\+Y14 register is not available. @disable\+\_\+report\+\_\+mask -\/ Force data to not be reported even if it is supported by the firware. @topbuttonpad -\/ Used with the \char`\"{}5 buttons touchpads\char`\"{} found on the Lenovo 40 series @kernel\+\_\+tracking -\/ most moderns R\+MI f11 firmwares implement Multifinger \mbox{\hyperlink{protocolType-p}{Type}} B \mbox{\hyperlink{protocolprotocol-p}{protocol}}. However, there are some corner cases where the user triggers some jumps by tapping with two fingers on the touchpad. Use this setting and dmax to filter out these jumps. Also, when using an old sensor using MF \mbox{\hyperlink{protocolType-p}{Type}} A behavior, set to true to report an actual MT \mbox{\hyperlink{protocolprotocol-p}{protocol}} B. @dmax -\/ the maximum distance (in sensor units) the kernel tracking allows two distincts fingers to be considered the same.
