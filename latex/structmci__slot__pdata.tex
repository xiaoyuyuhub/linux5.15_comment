\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structmci__slot__pdata}{mci\+\_\+slot\+\_\+pdata}} -\/ board-\/specific per-\/slot configuration @bus\+\_\+width\+: Number of data lines wired up the slot @detect\+\_\+pin\+: G\+P\+IO pin wired to the card detect switch @wp\+\_\+pin\+: G\+P\+IO pin wired to the write protect sensor @detect\+\_\+is\+\_\+active\+\_\+high\+: \mbox{\hyperlink{classThe}{The}} state of the detect pin when it is active @non\+\_\+removable\+: \mbox{\hyperlink{classThe}{The}} slot is not removable, only detect once

If a given slot is not present on the board, @bus\+\_\+width should be set to 0. \mbox{\hyperlink{classThe}{The}} other fields are ignored in this case.

Any pins that aren\textquotesingle{}t available should be set to a negative value.

Note that support for multiple slots is experimental -- some cards might get upset if we don\textquotesingle{}t get the clock management exactly right. But in most cases, it should work just fine.
