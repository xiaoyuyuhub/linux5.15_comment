Try to acquire the semaphore atomically. Returns 0 if the semaphore has been acquired successfully or 1 if it cannot be acquired.

N\+O\+TE\+: This return value is inverted from both spin\+\_\+trylock and mutex\+\_\+trylock! Be careful about this when converting code.
