\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structradix__tree__iter}{radix\+\_\+tree\+\_\+iter}} -\/ radix tree iterator state

@index\+: index of current slot @next\+\_\+index\+: one beyond the last index for this chunk @tags\+: bit-\/mask for tag-\/iterating @node\+: node that \mbox{\hyperlink{protocolcontains-p}{contains}} current slot

This radix tree iterator works in terms of \char`\"{}chunks\char`\"{} of slots. A chunk is a subinterval of slots contained within one radix tree leaf node. It is described by a pointer to its first slot and a struct \mbox{\hyperlink{structradix__tree__iter}{radix\+\_\+tree\+\_\+iter}} which holds the chunk\textquotesingle{}s position in the tree and its size. For tagged iteration \mbox{\hyperlink{structradix__tree__iter}{radix\+\_\+tree\+\_\+iter}} also holds the slots\textquotesingle{} bit-\/mask for one chosen radix tree tag.
