strncpy\+\_\+from\+\_\+user\+: -\/ Copy a N\+UL terminated string from userspace. @dst\+: Destination address, in kernel space. This buffer must be at least @count bytes long. @src\+: Source address, in user space. @count\+: Maximum number of bytes to copy, including the trailing N\+UL.

Copies a N\+U\+L-\/terminated string from userspace to kernel space.

On success, returns the length of the string (not including the trailing N\+UL).

If access to userspace fails, returns -\/E\+F\+A\+U\+LT (some data may have been copied).
