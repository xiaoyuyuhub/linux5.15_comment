\doxysubsection{Detailed Description}
D\+R\+M\+\_\+\+V\+M\+W\+\_\+\+C\+O\+N\+T\+R\+O\+L\+\_\+\+S\+T\+R\+E\+AM -\/ Control overlays, aka streams.

This I\+O\+C\+TL controls the overlay units of the svga device. \mbox{\hyperlink{classThe}{The}} S\+V\+GA overlay units does not work like regular hardware units in that they do not automaticaly read back the contents of the given dma buffer. But instead only read back for each call to this ioctl, and at any point between this call being made and a following call that either changes the buffer or disables the stream. struct \mbox{\hyperlink{structdrm__vmw__rect}{drm\+\_\+vmw\+\_\+rect}}

Defines a rectangle. Used in the overlay ioctl to define source and destination rectangle.
