\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structclone__args}{clone\+\_\+args}} -\/ arguments for the clone3 syscall @flags\+: Flags for the new process as listed above. All flags are valid except for C\+S\+I\+G\+N\+AL and C\+L\+O\+N\+E\+\_\+\+D\+E\+T\+A\+C\+H\+ED. @pidfd\+: If C\+L\+O\+N\+E\+\_\+\+P\+I\+D\+FD is set, a pidfd will be returned in this argument. @child\+\_\+tid\+: If C\+L\+O\+N\+E\+\_\+\+C\+H\+I\+L\+D\+\_\+\+S\+E\+T\+T\+ID is set, the T\+ID of the child process will be returned in the child\textquotesingle{}s memory. @parent\+\_\+tid\+: If C\+L\+O\+N\+E\+\_\+\+P\+A\+R\+E\+N\+T\+\_\+\+S\+E\+T\+T\+ID is set, the T\+ID of the child process will be returned in the parent\textquotesingle{}s memory. @exit\+\_\+signal\+: \mbox{\hyperlink{classThe}{The}} exit\+\_\+signal the parent process will be sent when the child exits. @stack\+: Specify the location of the stack for the child process. Note, @stack is expected to point to the lowest address. \mbox{\hyperlink{classThe}{The}} stack direction will be determined by the kernel and set up appropriately based on @stack\+\_\+size. @stack\+\_\+size\+: \mbox{\hyperlink{classThe}{The}} size of the stack for the child process. @tls\+: If C\+L\+O\+N\+E\+\_\+\+S\+E\+T\+T\+LS is set, the tls descriptor is set to tls. @set\+\_\+tid\+: Pointer to an array of type $\ast$pid\+\_\+t. \mbox{\hyperlink{classThe}{The}} size of the array is defined using @set\+\_\+tid\+\_\+size. This array is used to select P\+I\+Ds/\+T\+I\+Ds for newly created processes. \mbox{\hyperlink{classThe}{The}} first element in this defines the P\+ID in the most nested P\+ID namespace. Each additional element in the array defines the P\+ID in the parent P\+ID namespace of the original P\+ID namespace. If the array has less entries than the number of currently nested P\+ID namespaces only the P\+I\+Ds in the corresponding namespaces are set. @set\+\_\+tid\+\_\+size\+: This defines the size of the array referenced in @set\+\_\+tid. This cannot be larger than the kernel\textquotesingle{}s limit of nested P\+ID namespaces. @cgroup\+: If C\+L\+O\+N\+E\+\_\+\+I\+N\+T\+O\+\_\+\+C\+G\+R\+O\+UP is specified set this to a file descriptor for the cgroup.

\mbox{\hyperlink{classThe}{The}} structure is versioned by size and thus extensible. New struct members must go at the end of the struct and must be properly 64bit aligned.
