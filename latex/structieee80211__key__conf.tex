\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structieee80211__key__conf}{ieee80211\+\_\+key\+\_\+conf}} -\/ key information

This key information is given by mac80211 to the driver by the set\+\_\+key() callback in \&struct \mbox{\hyperlink{structieee80211__ops}{ieee80211\+\_\+ops}}.

@hw\+\_\+key\+\_\+idx\+: To be set by the driver, this is the key index the driver wants to be given when a frame is transmitted and needs to be encrypted in hardware. @cipher\+: \mbox{\hyperlink{classThe}{The}} key\textquotesingle{}s cipher suite selector. @tx\+\_\+pn\+: PN used for TX keys, may be used by the driver as well if it needs to do software PN assignment by itself (e.\+g. due to T\+SO) @flags\+: key flags, see \&enum ieee80211\+\_\+key\+\_\+flags. @keyidx\+: the key index (0-\/3) @keylen\+: key material length @key\+: key material. For A\+L\+G\+\_\+\+T\+K\+IP the key is encoded as a 256-\/bit (32 byte) data block\+:
\begin{DoxyItemize}
\item Temporal Encryption Key (128 bits)
\item Temporal Authenticator Tx M\+IC Key (64 bits)
\item Temporal Authenticator Rx M\+IC Key (64 bits) @icv\+\_\+len\+: \mbox{\hyperlink{classThe}{The}} I\+CV length for this key type @iv\+\_\+len\+: \mbox{\hyperlink{classThe}{The}} IV length for this key type
