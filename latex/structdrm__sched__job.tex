\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__sched__job}{drm\+\_\+sched\+\_\+job}} -\/ A job to be run by an entity.

@queue\+\_\+node\+: used to append this struct to the queue of jobs in an entity. @list\+: a job participates in a \char`\"{}pending\char`\"{} and \char`\"{}done\char`\"{} lists. @sched\+: the scheduler instance on which this job is scheduled. @s\+\_\+fence\+: \mbox{\hyperlink{protocolcontains-p}{contains}} the fences for the scheduling of job. @finish\+\_\+cb\+: the callback for the finished fence. @id\+: a unique id assigned to each job scheduled on the scheduler. @karma\+: increment on every hang caused by this job. If this exceeds the hang limit of the scheduler then the job is marked guilty and will not be scheduled further. @s\+\_\+priority\+: the priority of the job. @entity\+: the entity to which this job belongs. @cb\+: the callback for the parent fence in s\+\_\+fence.

A job is created by the driver using \mbox{\hyperlink{gpu__scheduler_8h_a19aa48e2c45635968ed40d0e46e166a4}{drm\+\_\+sched\+\_\+job\+\_\+init()}}, and should call \mbox{\hyperlink{gpu__scheduler_8h_a39079de5d679906712f191a17feccc8b}{drm\+\_\+sched\+\_\+entity\+\_\+push\+\_\+job()}} once it wants the scheduler to schedule the job.
