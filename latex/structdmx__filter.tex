\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdmx__filter}{dmx\+\_\+filter}} -\/ Specifies a section header filter.

@filter\+: bit array with bits to be matched at the section header. @mask\+: bits that are valid at the filter bit array. @mode\+: mode of match\+: if bit is zero, it will match if equal (positive match); if bit is one, it will match if the bit is negated.

Note\+: All arrays in this struct have a size of D\+M\+X\+\_\+\+F\+I\+L\+T\+E\+R\+\_\+\+S\+I\+ZE (16 bytes).
