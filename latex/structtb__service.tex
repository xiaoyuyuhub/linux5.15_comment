\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structtb__service}{tb\+\_\+service}} -\/ Thunderbolt service @dev\+: X\+Domain device @id\+: ID of the service (shown in sysfs) @key\+: Protocol key from the properties directory @prtcid\+: Protocol ID from the properties directory @prtcvers\+: Protocol version from the properties directory @prtcrevs\+: Protocol software revision from the properties directory @prtcstns\+: Protocol settings mask from the properties directory @debugfs\+\_\+dir\+: Pointer to the service debugfs directory. Always created when debugfs is enabled. Can be used by service drivers to add their own entries under the service.

Each domain exposes set of services it supports as collection of properties. For each service there will be one corresponding \&struct \mbox{\hyperlink{structtb__service}{tb\+\_\+service}}. Service drivers are bound to these.
