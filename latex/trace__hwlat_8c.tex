\doxysubsection{Detailed Description}
hwlat\+\_\+mode\+\_\+write -\/ Write function for \char`\"{}mode\char`\"{} entry @filp\+: \mbox{\hyperlink{classThe}{The}} active open file structure @ubuf\+: \mbox{\hyperlink{classThe}{The}} user buffer that \mbox{\hyperlink{protocolcontains-p}{contains}} the value to write @cnt\+: \mbox{\hyperlink{classThe}{The}} maximum number of bytes to write to \char`\"{}file\char`\"{} @ppos\+: \mbox{\hyperlink{classThe}{The}} current position in

This function provides a write implementation for the \char`\"{}mode\char`\"{} interface to the hardware latency detector. hwlatd has different operation modes. \mbox{\hyperlink{classThe}{The}} \char`\"{}none\char`\"{} sets the allowed cpumask for a single hwlatd thread at the startup and lets the scheduler handle the migration. \mbox{\hyperlink{classThe}{The}} default mode is the \char`\"{}round-\/robin\char`\"{} one, in which a single hwlatd thread runs, migrating among the allowed C\+P\+Us in a round-\/robin fashion. \mbox{\hyperlink{classThe}{The}} \char`\"{}per-\/cpu\char`\"{} mode creates one hwlatd thread per allowed C\+PU.
