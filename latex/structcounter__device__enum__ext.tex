\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structcounter__device__enum__ext}{counter\+\_\+device\+\_\+enum\+\_\+ext}} -\/ Counter enum extension attribute @items\+: Array of strings @num\+\_\+items\+: Number of items specified in @items @set\+: Set callback function; may be N\+U\+LL @get\+: Get callback function; may be N\+U\+LL

\mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structcounter__device__enum__ext}{counter\+\_\+device\+\_\+enum\+\_\+ext}} structure can be used to implement enum style Counter extension attributes. Enum style attributes are those which have a set of strings that map to unsigned integer values. \mbox{\hyperlink{classThe}{The}} Generic Counter enum extension helper code takes care of mapping between value and string, as well as generating a \char`\"{}\+\_\+available\char`\"{} file which \mbox{\hyperlink{protocolcontains-p}{contains}} a list of all available items. \mbox{\hyperlink{classThe}{The}} get callback is used to query the currently active item; the index of the item within the respective items array is returned via the \textquotesingle{}item\textquotesingle{} parameter. \mbox{\hyperlink{classThe}{The}} set callback is called when the attribute is updated; the \textquotesingle{}item\textquotesingle{} parameter \mbox{\hyperlink{protocolcontains-p}{contains}} the index of the newly activated item within the respective items array.
