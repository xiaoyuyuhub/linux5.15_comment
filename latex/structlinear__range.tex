\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structlinear__range}{linear\+\_\+range}} -\/ table of selector -\/ value pairs

Define a lookup-\/table for range of values. Intended to help when looking for a register value matching certaing physical measure (like voltage). Usable when increment of one in register always results a constant increment of the physical measure (like voltage).
