\doxysubsection{Detailed Description}
\mbox{\hyperlink{structlatch__tree__ops}{latch\+\_\+tree\+\_\+ops}} -\/ operators to define the tree order @less\+: used for insertion; provides the (partial) order between two elements. @comp\+: used for lookups; provides the order between the search key and an element.

\mbox{\hyperlink{classThe}{The}} operators are related like\+:

comp(a-\/$>$key,b) $<$ 0 \+:= less(a,b) comp(a-\/$>$key,b) $>$ 0 \+:= less(b,a) comp(a-\/$>$key,b) == 0 \+:= !less(a,b) \&\& !less(b,a)

If these operators define a partial order on the elements we make no guarantee on which of the elements matching the key is found. See \mbox{\hyperlink{rbtree__latch_8h_a60205e20b25a51fe6ca7298f551b5b6d}{latch\+\_\+tree\+\_\+find()}}.
