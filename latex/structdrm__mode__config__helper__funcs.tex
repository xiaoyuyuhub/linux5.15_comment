@atomic\+\_\+commit\+\_\+tail\+:

This hook is used by the default atomic\+\_\+commit() hook implemented in \mbox{\hyperlink{drm__atomic__helper_8h_a59377499957de2a8da3d7713e1a6bb7d}{drm\+\_\+atomic\+\_\+helper\+\_\+commit()}} together with the nonblocking commit helpers (see \mbox{\hyperlink{drm__atomic__helper_8h_ac29fa8a314989c69b0cc498bad396cb9}{drm\+\_\+atomic\+\_\+helper\+\_\+setup\+\_\+commit()}} for a starting point) to implement blocking and nonblocking commits easily. It is not used by the atomic helpers

This function is called when the new atomic state has already been swapped into the various state pointers. \mbox{\hyperlink{classThe}{The}} passed in state therefore \mbox{\hyperlink{protocolcontains-p}{contains}} copies of the old/previous state. This hook should commit the new state into hardware. Note that the helpers have already waited for preceeding atomic commits and fences, but drivers can add more waiting calls at the start of their implementation, e.\+g. to wait for driver-\/internal request for implicit syncing, before starting to commit the update to the hardware.

After the atomic update is committed to the hardware this hook needs to call \mbox{\hyperlink{drm__atomic__helper_8h_aff6121f0c5805f5f02d520160ad0b303}{drm\+\_\+atomic\+\_\+helper\+\_\+commit\+\_\+hw\+\_\+done()}}. Then wait for the upate to be executed by the hardware, for example using \mbox{\hyperlink{drm__atomic__helper_8h_a06852e3c22d610f9bd941157ca3417b3}{drm\+\_\+atomic\+\_\+helper\+\_\+wait\+\_\+for\+\_\+vblanks()}} or \mbox{\hyperlink{drm__atomic__helper_8h_a6a85d00d7595219db0c459aa7b36fe02}{drm\+\_\+atomic\+\_\+helper\+\_\+wait\+\_\+for\+\_\+flip\+\_\+done()}}, and then clean up the old framebuffers using \mbox{\hyperlink{drm__atomic__helper_8h_a54f3f0f7a8a6ba045e01aec3c4a68866}{drm\+\_\+atomic\+\_\+helper\+\_\+cleanup\+\_\+planes()}}.

When disabling a C\+R\+TC this hook {\itshape must} stall for the commit to complete. Vblank waits don\textquotesingle{}t work on disabled C\+R\+TC, hence the core can\textquotesingle{}t take care of this. And it also can\textquotesingle{}t rely on the vblank event, since that can be signalled already when the screen shows black, which can happen much earlier than the last hardware access needed to shut off the display pipeline completely.

This hook is optional, the default implementation is \mbox{\hyperlink{drm__atomic__helper_8h_ad1dc87ecb141d712e0205b1c899e24f7}{drm\+\_\+atomic\+\_\+helper\+\_\+commit\+\_\+tail()}}.
