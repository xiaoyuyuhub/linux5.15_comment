For E\+T\+H\+T\+O\+O\+L\+\_\+\+G\+R\+X\+C\+L\+S\+R\+L\+C\+NT, @rule\+\_\+cnt is set to the number of defined rules on return. For E\+T\+H\+T\+O\+O\+L\+\_\+\+S\+R\+X\+C\+L\+S\+R\+L\+I\+NS, @fs specifies the rule to add or update. @fs.@location either specifies the location to use or is a special location value with R\+X\+\_\+\+C\+L\+S\+\_\+\+L\+O\+C\+\_\+\+S\+P\+E\+C\+I\+AL flag set.
