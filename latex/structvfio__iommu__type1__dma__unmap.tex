\doxysubsection{Detailed Description}
V\+F\+I\+O\+\_\+\+I\+O\+M\+M\+U\+\_\+\+U\+N\+M\+A\+P\+\_\+\+D\+MA -\/ \+\_\+\+I\+O\+WR(V\+F\+I\+O\+\_\+\+T\+Y\+PE, V\+F\+I\+O\+\_\+\+B\+A\+SE + 14, struct vfio\+\_\+dma\+\_\+unmap)

Unmap IO virtual addresses using the provided struct vfio\+\_\+dma\+\_\+unmap. Caller sets argsz. \mbox{\hyperlink{classThe}{The}} actual unmapped size is returned in the size field. No guarantee is made to the user that arbitrary unmaps of iova or size different from those used in the original mapping call will succeed.

V\+F\+I\+O\+\_\+\+D\+M\+A\+\_\+\+U\+N\+M\+A\+P\+\_\+\+F\+L\+A\+G\+\_\+\+G\+E\+T\+\_\+\+D\+I\+R\+T\+Y\+\_\+\+B\+I\+T\+M\+AP should be set to get the dirty bitmap before unmapping IO virtual addresses. When this flag is set, the user must provide a struct \mbox{\hyperlink{structvfio__bitmap}{vfio\+\_\+bitmap}} in data\mbox{[}\mbox{]}. User must provide zero-\/allocated memory via \mbox{\hyperlink{structvfio__bitmap_a451f6de544ee09d9a5cc93c9663c8407}{vfio\+\_\+bitmap.\+data}} and its size in the \mbox{\hyperlink{structvfio__bitmap_ab31bcacc2c0603914b34b9d94cae7146}{vfio\+\_\+bitmap.\+size}} field. A bit in the bitmap represents one page, of user provided page size in \mbox{\hyperlink{structvfio__bitmap_a719cd2d8883913513de04b1b8bcc37d7}{vfio\+\_\+bitmap.\+pgsize}} field, consecutively starting from iova offset. Bit set indicates that the page at that offset from iova is dirty. A Bitmap of the pages in the range of unmapped size is returned in the user-\/provided \mbox{\hyperlink{structvfio__bitmap_a451f6de544ee09d9a5cc93c9663c8407}{vfio\+\_\+bitmap.\+data}}.

If flags \& V\+F\+I\+O\+\_\+\+D\+M\+A\+\_\+\+U\+N\+M\+A\+P\+\_\+\+F\+L\+A\+G\+\_\+\+A\+LL, unmap all addresses. iova and size must be 0. This cannot be combined with the get-\/dirty-\/bitmap flag.

If flags \& V\+F\+I\+O\+\_\+\+D\+M\+A\+\_\+\+U\+N\+M\+A\+P\+\_\+\+F\+L\+A\+G\+\_\+\+V\+A\+D\+DR, do not unmap, but invalidate host virtual addresses in the iova range. Tasks that attempt to translate an iova\textquotesingle{}s vaddr will block. D\+MA to already-\/mapped pages continues. This cannot be combined with the get-\/dirty-\/bitmap flag.
