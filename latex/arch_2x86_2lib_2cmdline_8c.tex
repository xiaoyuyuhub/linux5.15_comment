Find a boolean option (like quiet,noapic,nosmp....)

@cmdline\+: the cmdline string @option\+: option string to look for

Returns the position of that @option (starts counting with 1) or 0 on not found. @option will only be found if it is found as an entire word in @cmdline. For instance, if @option=\char`\"{}car\char`\"{} then a cmdline which \mbox{\hyperlink{protocolcontains-p}{contains}} \char`\"{}cart\char`\"{} will not match.
