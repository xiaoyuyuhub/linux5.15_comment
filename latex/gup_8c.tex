\char`\"{}gup-\/pinned page\char`\"{} refers to a page that has had one of the \mbox{\hyperlink{gup_8c_aae0075c7e51f84b52b0631623dd6269f}{get\+\_\+user\+\_\+pages()}} variants called on that page.

For each page in the @pages array, make that page (or its head page, if a compound page) dirty, if @make\+\_\+dirty is true, and if the page was previously listed as clean. In any case, releases all pages using \mbox{\hyperlink{gup_8c_a660b424e7f87f459ffb8828df2a1bc75}{unpin\+\_\+user\+\_\+page()}}, possibly via \mbox{\hyperlink{gup_8c_aabe9d244a6ae69755cba02ebafaa66a1}{unpin\+\_\+user\+\_\+pages()}}, for the non-\/dirty case.

Please see the \mbox{\hyperlink{gup_8c_a660b424e7f87f459ffb8828df2a1bc75}{unpin\+\_\+user\+\_\+page()}} documentation for details.
