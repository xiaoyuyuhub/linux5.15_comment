\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structfw__rsc__vdev}{fw\+\_\+rsc\+\_\+vdev}} -\/ virtio device header @id\+: virtio device id (as in \mbox{\hyperlink{virtio__ids_8h}{virtio\+\_\+ids.\+h}}) @notifyid\+: a unique rproc-\/wide notify index for this vdev. This notify index is used when kicking a remote processor, to let it know that the status/features of this vdev have changes. @dfeatures\+: specifies the virtio device features supported by the firmware @gfeatures\+: a place holder used by the host to write back the negotiated features that are supported by both sides. @config\+\_\+len\+: the size of the virtio config space of this vdev. \mbox{\hyperlink{classThe}{The}} config space lies in the resource table immediate after this vdev header. @status\+: a place holder where the host will indicate its virtio progress. @num\+\_\+of\+\_\+vrings\+: indicates how many vrings are described in this vdev header @reserved\+: reserved (must be zero) @vring\+: an array of @num\+\_\+of\+\_\+vrings entries of \textquotesingle{}struct \mbox{\hyperlink{structfw__rsc__vdev__vring}{fw\+\_\+rsc\+\_\+vdev\+\_\+vring}}\textquotesingle{}.

This resource is a virtio device header\+: it provides information about the vdev, and is then used by the host and its peer remote processors to negotiate and share certain virtio properties.

By providing this resource entry, the firmware essentially asks remoteproc to statically allocate a vdev upon registration of the rproc (dynamic vdev allocation is not yet supported).

Note\+:
\begin{DoxyEnumerate}
\item unlike virtualization systems, the term \textquotesingle{}host\textquotesingle{} here means the Linux side which is running remoteproc to control the remote processors. We use the name \textquotesingle{}gfeatures\textquotesingle{} to comply with virtio\textquotesingle{}s terms, though there isn\textquotesingle{}t really any virtualized guest OS here\+: it\textquotesingle{}s the host which is responsible for negotiating the final features. Yeah, it\textquotesingle{}s a bit confusing.
\item immediately following this structure is the virtio config space for this vdev (which is specific to the vdev; for more info, read the virtio spec). \mbox{\hyperlink{classThe}{The}} size of the config space is specified by @config\+\_\+len. 
\end{DoxyEnumerate}
