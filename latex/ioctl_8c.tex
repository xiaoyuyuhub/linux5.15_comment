\mbox{\hyperlink{ioctl_8c_a74921a3067157ce28ae7160e38b5e9fa}{sgx\+\_\+ioc\+\_\+enclave\+\_\+add\+\_\+pages()}} -\/ \mbox{\hyperlink{classThe}{The}} handler for S\+G\+X\+\_\+\+I\+O\+C\+\_\+\+E\+N\+C\+L\+A\+V\+E\+\_\+\+A\+D\+D\+\_\+\+P\+A\+G\+ES @encl\+: an enclave pointer \begin{DoxyItemize}
\item \+: a user pointer to a struct \mbox{\hyperlink{structsgx__enclave__add__pages}{sgx\+\_\+enclave\+\_\+add\+\_\+pages}} instance\end{DoxyItemize}
Add one or more pages to an uninitialized enclave, and optionally extend the measurement with the contents of the page. \mbox{\hyperlink{classThe}{The}} S\+E\+C\+I\+N\+FO and measurement mask are applied to all pages.

A S\+E\+C\+I\+N\+FO for a T\+CS is required to always contain zero permissions because C\+PU silently zeros them. Allowing anything else would cause a mismatch in the measurement.

mmap()\textquotesingle{}s protection bits are capped by the page permissions. For each page address, the maximum protection bits are computed with the following heuristics\+:


\begin{DoxyEnumerate}
\item A regular page\+: P\+R\+O\+T\+\_\+R, P\+R\+O\+T\+\_\+W and P\+R\+O\+T\+\_\+X match the S\+E\+C\+I\+N\+FO permissions.
\item A T\+CS page\+: P\+R\+O\+T\+\_\+R $\vert$ P\+R\+O\+T\+\_\+W.
\end{DoxyEnumerate}

mmap() is not allowed to surpass the minimum of the maximum protection bits within the given address range.

\mbox{\hyperlink{classThe}{The}} function deinitializes kernel data structures for enclave and returns -\/E\+IO in any of the following conditions\+:


\begin{DoxyItemize}
\item Enclave Page Cache (E\+PC), the physical memory holding enclaves, has been invalidated. This will cause E\+A\+DD and E\+E\+X\+T\+E\+ND to fail.
\item If the source address is corrupted somehow when executing E\+A\+DD.
\end{DoxyItemize}

Return\+:
\begin{DoxyItemize}
\item 0\+: Success.
\item -\/E\+A\+C\+C\+ES\+: \mbox{\hyperlink{classThe}{The}} source page is located in a noexec partition.
\item -\/E\+N\+O\+M\+EM\+: Out of E\+PC pages.
\item -\/E\+I\+N\+TR\+: \mbox{\hyperlink{classThe}{The}} call was interrupted before data was processed.
\item -\/E\+IO\+: Either E\+A\+DD or E\+E\+X\+T\+E\+ND failed because invalid source address or power cycle.
\item -\/errno\+: P\+O\+S\+IX error.
