\doxysubsection{Detailed Description}
struct timecounter -\/ layer above a struct cyclecounter which counts nanoseconds Contains the state needed by \mbox{\hyperlink{timecounter_8c_a78d943bdd3165354112ee6ba0cdefdd6}{timecounter\+\_\+read()}} to detect cycle counter wrap around. Initialize with \mbox{\hyperlink{timecounter_8c_aa38ae2f60a77da096c8930cb43c08331}{timecounter\+\_\+init()}}. Also used to convert cycle counts into the corresponding nanosecond counts with \mbox{\hyperlink{timecounter_8c_a0f1d61242408b6f5af8cc33c0254d1d5}{timecounter\+\_\+cyc2time()}}. Users of this code are responsible for initializing the underlying cycle counter hardware, locking issues and reading the time more often than the cycle counter wraps around. \mbox{\hyperlink{classThe}{The}} nanosecond counter will only wrap around after $\sim$585 years.

@cc\+: the cycle counter used by this instance @cycle\+\_\+last\+: most recent cycle counter value seen by \mbox{\hyperlink{timecounter_8c_a78d943bdd3165354112ee6ba0cdefdd6}{timecounter\+\_\+read()}} @nsec\+: continuously increasing count @mask\+: bit mask for maintaining the \textquotesingle{}frac\textquotesingle{} field @frac\+: accumulated fractional nanoseconds
