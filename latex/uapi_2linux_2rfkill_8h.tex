D\+OC\+: Extensibility

Originally, we had planned to allow backward and forward compatible changes by just adding fields at the end of the structure that are then not reported on older kernels on \mbox{\hyperlink{ring__buffer__benchmark_8c_a414a71904272e5b5fce01917028fb426}{read()}}, and not written to by older kernels on write(), with the kernel reporting the size it did accept as the result.

This would have allowed userspace to detect on \mbox{\hyperlink{ring__buffer__benchmark_8c_a414a71904272e5b5fce01917028fb426}{read()}} and write() which kernel structure version it was dealing with, and if was just recompiled it would have gotten the new fields, but obviously not accessed them, but things should\textquotesingle{}ve continued to work.

Unfortunately, while actually exercising this mechanism to add the hard block reasons field, we found that userspace (notably systemd) did all kinds of fun things not in line with this scheme\+:


\begin{DoxyEnumerate}
\item treat the (expected) short writes as an error;
\item ask to read sizeof(struct rfkill\+\_\+event) but then compare the actual return value to R\+F\+K\+I\+L\+L\+\_\+\+E\+V\+E\+N\+T\+\_\+\+S\+I\+Z\+E\+\_\+\+V1 and treat any mismatch as an error.
\end{DoxyEnumerate}

As a consequence, just recompiling with a new struct version caused things to no longer work correctly on old and new kernels.

Hence, we\textquotesingle{}ve rolled back \&struct \mbox{\hyperlink{structrfkill__event}{rfkill\+\_\+event}} to the original version and added \&struct \mbox{\hyperlink{structrfkill__event__ext}{rfkill\+\_\+event\+\_\+ext}}. This effectively reverts to the old behaviour for all userspace, unless it explicitly opts in to the rules outlined here by using the new \&struct \mbox{\hyperlink{structrfkill__event__ext}{rfkill\+\_\+event\+\_\+ext}}.

Userspace using \&struct \mbox{\hyperlink{structrfkill__event__ext}{rfkill\+\_\+event\+\_\+ext}} must adhere to the following rules


\begin{DoxyEnumerate}
\item accept short writes, optionally using them to detect that it\textquotesingle{}s running on an older kernel;
\item accept short reads, knowing that this means it\textquotesingle{}s running on an older kernel;
\item treat reads that are as long as requested as acceptable, not checking against R\+F\+K\+I\+L\+L\+\_\+\+E\+V\+E\+N\+T\+\_\+\+S\+I\+Z\+E\+\_\+\+V1 or such. 
\end{DoxyEnumerate}\mbox{\Hypertarget{uapi_2linux_2rfkill_8h_a9bd2fda60a33e999edc5a0737b4e4869}\label{uapi_2linux_2rfkill_8h_a9bd2fda60a33e999edc5a0737b4e4869}}
