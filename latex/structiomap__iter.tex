\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structiomap__iter}{iomap\+\_\+iter}} -\/ Iterate through a range of a file @inode\+: Set at the start of the iteration and should not change. @pos\+: \mbox{\hyperlink{classThe}{The}} current file position we are operating on. It is updated by calls to \mbox{\hyperlink{include_2linux_2iomap_8h_ada19c60b2a8506563b8de75344d0437c}{iomap\+\_\+iter()}}.
