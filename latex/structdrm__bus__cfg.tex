\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdrm__bus__cfg}{drm\+\_\+bus\+\_\+cfg}} -\/ bus configuration

This structure stores the configuration of a physical bus between two components in an output pipeline, usually between two bridges, an encoder and a bridge, or a bridge and a connector.

\mbox{\hyperlink{classThe}{The}} bus configuration is stored in \&\mbox{\hyperlink{structdrm__bridge__state}{drm\+\_\+bridge\+\_\+state}} separately for the input and output buses, as seen from the point of view of each bridge. \mbox{\hyperlink{classThe}{The}} bus configuration of a bridge output is usually identical to the configuration of the next bridge\textquotesingle{}s input, but may differ if the signals are modified between the two bridges, for instance by an inverter on the board. \mbox{\hyperlink{classThe}{The}} input and output configurations of a bridge may differ if the bridge modifies the signals internally, for instance by performing format conversion, or modifying signals polarities.
