\doxysubsection{Detailed Description}
D\+OC\+: Virtual Engine u\+A\+PI

Virtual engine is a concept where userspace is able to configure a set of physical engines, submit a batch buffer, and let the driver execute it on any engine from the set as it sees fit.

This is primarily useful on parts which have multiple instances of a same class engine, like for example G\+T3+ Skylake parts with their two V\+CS engines.

For instance userspace can enumerate all engines of a certain class using the previously described {\ttfamily Engine Discovery u\+A\+PI}\+\_\+. After that userspace can create a G\+EM context with a placeholder slot for the virtual engine (using {\ttfamily I915\+\_\+\+E\+N\+G\+I\+N\+E\+\_\+\+C\+L\+A\+S\+S\+\_\+\+I\+N\+V\+A\+L\+ID} and {\ttfamily I915\+\_\+\+E\+N\+G\+I\+N\+E\+\_\+\+C\+L\+A\+S\+S\+\_\+\+I\+N\+V\+A\+L\+I\+D\+\_\+\+N\+O\+NE} for class and instance respectively) and finally using the {\ttfamily I915\+\_\+\+C\+O\+N\+T\+E\+X\+T\+\_\+\+E\+N\+G\+I\+N\+E\+S\+\_\+\+E\+X\+T\+\_\+\+L\+O\+A\+D\+\_\+\+B\+A\+L\+A\+N\+CE} extension place a virtual engine in the same reserved slot.
