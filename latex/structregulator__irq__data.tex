\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structregulator__irq__data}{regulator\+\_\+irq\+\_\+data}} -\/ regulator error/notification status data

@states\+: Status structs for each of the associated regulators. @num\+\_\+states\+: Amount of associated regulators. @data\+: Driver data pointer given at \mbox{\hyperlink{structregulator__irq__desc}{regulator\+\_\+irq\+\_\+desc}}. @opaque\+: Value storage for IC driver. Core does not update this. I\+Cs may want to store status register value here at map\+\_\+event and compare contents at \textquotesingle{}renable\textquotesingle{} callback to see if new problems have been added to status. If that is the case it may be desirable to return R\+E\+G\+U\+L\+A\+T\+O\+R\+\_\+\+E\+R\+R\+O\+R\+\_\+\+C\+L\+E\+A\+R\+ED and not R\+E\+G\+U\+L\+A\+T\+O\+R\+\_\+\+E\+R\+R\+O\+R\+\_\+\+ON to allow I\+RQ fire again and to generate notifications also for the new issues.

This structure is passed to \textquotesingle{}map\+\_\+event\textquotesingle{} and \textquotesingle{}renable\textquotesingle{} callbacks for reporting regulator status to core.
