Unfortunately (for us), we need to precisely identify each unique error code, e.\+g. the action taken if E\+WB fails varies based on the type of fault and on the exact S\+GX error code, i.\+e. we can\textquotesingle{}t simply convert all faults to -\/E\+F\+A\+U\+LT.
