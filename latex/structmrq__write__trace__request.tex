\doxysubsection{Detailed Description}

Used by M\+R\+Q\+\_\+\+W\+R\+I\+T\+E\+\_\+\+T\+R\+A\+CE calls to ask the recipient to copy trace data from the recipient\textquotesingle{}s local buffer to the output buffer. \mbox{\hyperlink{structmrq__write__trace__request_aea2d03a0dde3db9c9eedc97b3c0ce07b}{area}} is treated as a byte-\/aligned pointer in the recipient\textquotesingle{}s address space.
