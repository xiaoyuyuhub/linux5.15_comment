\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structiio__enum}{iio\+\_\+enum}} -\/ Enum channel info attribute @items\+: An array of strings. @num\+\_\+items\+: Length of the item array. @set\+: Set callback function, may be N\+U\+LL. @get\+: Get callback function, may be N\+U\+LL.

\mbox{\hyperlink{classThe}{The}} \mbox{\hyperlink{structiio__enum}{iio\+\_\+enum}} struct can be used to implement enum style channel attributes. Enum style attributes are those which have a set of strings which map to unsigned integer values. \mbox{\hyperlink{classThe}{The}} I\+IO enum helper code takes care of mapping between value and string as well as generating a \char`\"{}\+\_\+available\char`\"{} file which \mbox{\hyperlink{protocolcontains-p}{contains}} a list of all available items. \mbox{\hyperlink{classThe}{The}} set callback will be called when the attribute is updated. \mbox{\hyperlink{classThe}{The}} last parameter is the index to the newly activated item. \mbox{\hyperlink{classThe}{The}} get callback will be used to query the currently active item and is supposed to return the index for it.
