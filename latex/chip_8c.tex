irq\+\_\+disable -\/ Mark interrupt disabled @desc\+: irq descriptor which should be disabled

If the chip does not implement the irq\+\_\+disable callback, we use a lazy disable approach. That means we mark the interrupt disabled, but leave the hardware unmasked. That\textquotesingle{}s an optimization because we avoid the hardware access for the common case where no interrupt happens after we marked it disabled. If an interrupt happens, then the interrupt flow handler masks the line at the hardware level and marks it pending.

If the interrupt chip does not implement the irq\+\_\+disable callback, a driver can disable the lazy approach for a particular irq line by calling \textquotesingle{}irq\+\_\+set\+\_\+status\+\_\+flags(irq, I\+R\+Q\+\_\+\+D\+I\+S\+A\+B\+L\+E\+\_\+\+U\+N\+L\+A\+Z\+Y)\textquotesingle{}.
