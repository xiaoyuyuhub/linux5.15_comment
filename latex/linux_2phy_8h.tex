@\+P\+H\+Y\+\_\+\+D\+O\+WN\+: P\+HY device and driver are not ready for anything. probe should be called if and only if the P\+HY is in this state, given that the P\+HY device exists.

\end{DoxyItemize}

@\+P\+H\+Y\+\_\+\+R\+E\+A\+DY\+: P\+HY is ready to send and receive packets, but the controller is not. By default, P\+H\+Ys which do not implement probe will be set to this state by phy\+\_\+probe().

\item start will set the state to UP
\end{DoxyItemize}

@\+P\+H\+Y\+\_\+\+UP\+: \mbox{\hyperlink{classThe}{The}} P\+HY and attached device are ready to do work. Interrupts should be started here.
\begin{DoxyItemize}
\item timer moves to @\+P\+H\+Y\+\_\+\+N\+O\+L\+I\+NK or @\+P\+H\+Y\+\_\+\+R\+U\+N\+N\+I\+NG
\end{DoxyItemize}

@\+P\+H\+Y\+\_\+\+N\+O\+L\+I\+NK\+: P\+HY is up, but not currently plugged in.
\begin{DoxyItemize}
\item irq or timer will set @\+P\+H\+Y\+\_\+\+R\+U\+N\+N\+I\+NG if link comes back
\item phy\+\_\+stop moves to @\+P\+H\+Y\+\_\+\+H\+A\+L\+T\+ED
\end{DoxyItemize}

@\+P\+H\+Y\+\_\+\+R\+U\+N\+N\+I\+NG\+: P\+HY is currently up, running, and possibly sending and/or receiving packets
\begin{DoxyItemize}
\item irq or timer will set @\+P\+H\+Y\+\_\+\+N\+O\+L\+I\+NK if link goes down
\item phy\+\_\+stop moves to @\+P\+H\+Y\+\_\+\+H\+A\+L\+T\+ED
\end{DoxyItemize}

P\+HY will be poll once per second, or on interrupt for it current state. Once complete, move to UP to restart the P\+HY.
\begin{DoxyItemize}
\item phy\+\_\+stop aborts the running test and moves to @\+P\+H\+Y\+\_\+\+H\+A\+L\+T\+ED
\end{DoxyItemize}
