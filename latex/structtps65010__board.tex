\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structtps65010__board}{tps65010\+\_\+board}} -\/ packages G\+P\+IO and L\+ED lines @base\+: the G\+P\+IO number to assign to G\+P\+I\+O-\/1 @outmask\+: bit (N-\/1) is set to allow G\+P\+I\+O-\/N to be used as an (open drain) output @setup\+: optional callback issued once the G\+P\+I\+Os are valid @teardown\+: optional callback issued before the G\+P\+I\+Os are invalidated @context\+: optional parameter passed to \mbox{\hyperlink{structtps65010__board_a44e36638be49a3cb8592a98c1450b8c9}{setup()}} and \mbox{\hyperlink{structtps65010__board_a809de9c151951d4416adb40525e4362f}{teardown()}}

Board data may be used to package the G\+P\+IO (and L\+ED) lines for use in by the generic G\+P\+IO and L\+ED frameworks. \mbox{\hyperlink{classThe}{The}} first four G\+P\+I\+Os starting at gpio\+\_\+base are G\+P\+I\+O1..G\+P\+I\+O4. \mbox{\hyperlink{classThe}{The}} next two are L\+E\+D1/n\+PG and L\+E\+D2 (with hardware blinking capability, not currently exposed).

\mbox{\hyperlink{classThe}{The}} @setup callback may be used with the kind of board-\/specific glue which hands the (now-\/valid) G\+P\+I\+Os to other drivers, or which puts devices in their initial states using these G\+P\+I\+Os.
