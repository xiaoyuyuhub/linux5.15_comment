\doxysubsection{Detailed Description}
Auxiliary structure used for reading the snapshot image data and metadata from and writing them to the list of page backup entries (P\+B\+Es) which is the main data structure of swsusp.

Using struct \mbox{\hyperlink{structsnapshot__handle}{snapshot\+\_\+handle}} we can transfer the image, including its metadata, as a continuous sequence of bytes with the help of \mbox{\hyperlink{kernel_2power_2power_8h_a8ca1fd96ec28c968a8562703b9ffcc23}{snapshot\+\_\+read\+\_\+next()}} and \mbox{\hyperlink{kernel_2power_2power_8h_ad1a0c7e1a915138a60c64c6602ab197e}{snapshot\+\_\+write\+\_\+next()}}.

\mbox{\hyperlink{classThe}{The}} code that writes the image to a storage or transfers it to the user land is required to use \mbox{\hyperlink{kernel_2power_2power_8h_a8ca1fd96ec28c968a8562703b9ffcc23}{snapshot\+\_\+read\+\_\+next()}} for this purpose and it should not make any assumptions regarding the internal structure of the image. Similarly, the code that reads the image from a storage or transfers it from the user land is required to use \mbox{\hyperlink{kernel_2power_2power_8h_ad1a0c7e1a915138a60c64c6602ab197e}{snapshot\+\_\+write\+\_\+next()}}.

This may allow us to change the internal structure of the image in the future with considerably less effort.
