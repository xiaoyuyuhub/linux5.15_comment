\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structspi__mem__dirmap__info}{spi\+\_\+mem\+\_\+dirmap\+\_\+info}} -\/ Direct mapping information @op\+\_\+tmpl\+: operation template that should be used by the direct mapping when the memory device is accessed @offset\+: absolute offset this direct mapping is pointing to @length\+: length in byte of this direct mapping

These information are used by the controller specific implementation to know the portion of memory that is directly mapped and the \mbox{\hyperlink{structspi__mem__op}{spi\+\_\+mem\+\_\+op}} that should be used to access the device. A direct mapping is only valid for one direction (read or write) and this direction is directly encoded in the -\/$>$op\+\_\+tmpl.\+data.\+dir field.
