\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structfw__cdev__allocate}{fw\+\_\+cdev\+\_\+allocate}} -\/ Allocate a C\+SR in an address range @offset\+: Start offset of the address range @closure\+: To be passed back to userspace in request events @length\+: Length of the C\+SR, in bytes @handle\+: Handle to the allocation, written by the kernel @region\+\_\+end\+: First address above the address range (added in A\+BI v4, 2.\+6.\+36)

Allocate an address range in the 48-\/bit address space on the local node (the controller). This allows userspace to listen for requests with an offset within that address range. Every time when the kernel receives a request within the range, an \&\mbox{\hyperlink{structfw__cdev__event__request2}{fw\+\_\+cdev\+\_\+event\+\_\+request2}} event will be emitted. (If the kernel or the client implements A\+BI version $<$= 3, an \&\mbox{\hyperlink{structfw__cdev__event__request}{fw\+\_\+cdev\+\_\+event\+\_\+request}} will be generated instead.)

\mbox{\hyperlink{classThe}{The}} @closure field is passed back to userspace in these request events. \mbox{\hyperlink{classThe}{The}} @handle field is an out parameter, returning a handle to the allocated range to be used for later deallocation of the range.

\mbox{\hyperlink{classThe}{The}} address range is allocated on all local nodes. \mbox{\hyperlink{classThe}{The}} address allocation is exclusive except for the F\+CP command and response registers. If an exclusive address region is already in use, the ioctl fails with errno set to E\+B\+U\+SY.

If kernel and client implement A\+BI version $>$= 4, the kernel looks up a free spot of size @length inside \mbox{[}@offset..@region\+\_\+end) and, if found, writes the start address of the new C\+SR back in @offset. I.\+e. @offset is an in and out parameter. If this automatic placement of a C\+SR in a bigger address range is not desired, the client simply needs to set @region\+\_\+end = @offset + @length.

If the kernel or the client implements A\+BI version $<$= 3, @region\+\_\+end is ignored and effectively assumed to be @offset + @length.

@region\+\_\+end is only present in a kernel header $>$= 2.\+6.\+36. If necessary, this can for example be tested by \#ifdef F\+W\+\_\+\+C\+D\+E\+V\+\_\+\+E\+V\+E\+N\+T\+\_\+\+R\+E\+Q\+U\+E\+S\+T2.
