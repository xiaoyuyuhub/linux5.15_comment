\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structdevfreq__dev__status}{devfreq\+\_\+dev\+\_\+status}} -\/ Data given from devfreq user device to governors. Represents the performance statistics. @total\+\_\+time\+: \mbox{\hyperlink{classThe}{The}} total time represented by this instance of \mbox{\hyperlink{structdevfreq__dev__status}{devfreq\+\_\+dev\+\_\+status}} @busy\+\_\+time\+: \mbox{\hyperlink{classThe}{The}} time that the device was working among the total\+\_\+time. @current\+\_\+frequency\+: \mbox{\hyperlink{classThe}{The}} operating frequency. @private\+\_\+data\+: An entry not specified by the devfreq framework. A device and a specific governor may have their own \mbox{\hyperlink{protocolprotocol-p}{protocol}} with private\+\_\+data. However, because this is governor-\/specific, a governor using this will be only compatible with devices aware of it.
