\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structgcov__fn__info}{gcov\+\_\+fn\+\_\+info}} -\/ profiling meta data per function @key\+: comdat key @ident\+: unique ident of function @lineno\+\_\+checksum\+: function lineo\+\_\+checksum @cfg\+\_\+checksum\+: function cfg checksum @ctrs\+: instrumented counters

This data is generated by gcc during compilation and doesn\textquotesingle{}t change at run-\/time.

Information about a single function. This uses the trailing array idiom. \mbox{\hyperlink{classThe}{The}} number of counters is determined from the merge pointer array in \mbox{\hyperlink{structgcov__info}{gcov\+\_\+info}}. \mbox{\hyperlink{classThe}{The}} key is used to detect which of a set of comdat functions was selected -- it points to the \mbox{\hyperlink{structgcov__info}{gcov\+\_\+info}} object of the object file containing the selected comdat function.
