\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structmbox__chan__ops}{mbox\+\_\+chan\+\_\+ops}} -\/ methods to control mailbox channels @send\+\_\+data\+: \mbox{\hyperlink{classThe}{The}} A\+PI asks the M\+B\+OX controller driver, in atomic context try to transmit a message on the bus. Returns 0 if data is accepted for transmission, -\/E\+B\+U\+SY while rejecting if the remote hasn\textquotesingle{}t yet read the last data sent. Actual transmission of data is reported by the controller via mbox\+\_\+chan\+\_\+txdone (if it has some TX A\+CK irq). It must not sleep. @flush\+: Called when a client requests transmissions to be blocking but the context doesn\textquotesingle{}t allow sleeping. Typically the controller will implement a busy loop waiting for the data to flush out. @startup\+: Called when a client requests the chan. \mbox{\hyperlink{classThe}{The}} controller could ask clients for additional parameters of communication to be provided via client\textquotesingle{}s chan\+\_\+data. This call may block. After this call the Controller must forward any data received on the chan by calling mbox\+\_\+chan\+\_\+received\+\_\+data. \mbox{\hyperlink{classThe}{The}} controller may do stuff that need to sleep. @shutdown\+: Called when a client relinquishes control of a chan. This call may block too. \mbox{\hyperlink{classThe}{The}} controller must not forward any received data anymore. \mbox{\hyperlink{classThe}{The}} controller may do stuff that need to sleep. @last\+\_\+tx\+\_\+done\+: If the controller sets \textquotesingle{}txdone\+\_\+poll\textquotesingle{}, the A\+PI calls this to poll status of last TX. \mbox{\hyperlink{classThe}{The}} controller must give priority to I\+RQ method over polling and never set both txdone\+\_\+poll and txdone\+\_\+irq. Only in polling mode \textquotesingle{}send\+\_\+data\textquotesingle{} is expected to return -\/E\+B\+U\+SY. \mbox{\hyperlink{classThe}{The}} controller may do stuff that need to sleep/block. Used only if txdone\+\_\+poll\+:=true \&\& txdone\+\_\+irq\+:=false @peek\+\_\+data\+: Atomic check for any received data. Return true if controller has some data to push to the client.
