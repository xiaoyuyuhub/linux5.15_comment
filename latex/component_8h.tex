component\+\_\+match\+\_\+add -\/ add a component match entry @master\+: device with the aggregate driver @matchptr\+: pointer to the list of component matches @compare\+: compare function to match against all components @compare\+\_\+data\+: opaque pointer passed to the @compare function

Adds a new component match to the list stored in @matchptr, which the @master aggregate driver needs to function. \mbox{\hyperlink{classThe}{The}} list of component matches pointed to by @matchptr must be initialized to N\+U\+LL before adding the first match. This only matches against components added with \mbox{\hyperlink{component_8h_aec7a5784c8f000de8d9f80aeeb476bbc}{component\+\_\+add()}}.

\mbox{\hyperlink{classThe}{The}} allocated match list in @matchptr is automatically released using devm actions.
