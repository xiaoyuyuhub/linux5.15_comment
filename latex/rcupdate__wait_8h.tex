This macro waits concurrently for multiple types of R\+CU grace periods. For example, \mbox{\hyperlink{rcupdate__wait_8h_aae2053b8304e26b1bd3e43dc0b333070}{synchronize\+\_\+rcu\+\_\+mult(call\+\_\+rcu, call\+\_\+rcu\+\_\+tasks)}} would wait on concurrent R\+CU and R\+C\+U-\/tasks grace periods. Waiting on a given S\+R\+CU domain requires you to write a wrapper function for that S\+R\+CU domain\textquotesingle{}s \mbox{\hyperlink{srcutiny_8c_a5e78f1e39878d4f7ed37018fd66f8a50}{call\+\_\+srcu()}} function, with this wrapper supplying the pointer to the corresponding \mbox{\hyperlink{structsrcu__struct}{srcu\+\_\+struct}}.

\mbox{\hyperlink{classThe}{The}} first argument tells Tiny R\+CU\textquotesingle{}s \mbox{\hyperlink{rcupdate__wait_8h_aad4a272ce7e05ca1c0d27bfa5b4dffb0}{\+\_\+wait\+\_\+rcu\+\_\+gp()}} not to bother waiting for R\+CU. \mbox{\hyperlink{classThe}{The}} reason for this is because anywhere \mbox{\hyperlink{rcupdate__wait_8h_aae2053b8304e26b1bd3e43dc0b333070}{synchronize\+\_\+rcu\+\_\+mult()}} can be called is automatically already a full grace period. \mbox{\Hypertarget{rcupdate__wait_8h_aa458a55ba66535914b1fe1313df1c1bb}\label{rcupdate__wait_8h_aa458a55ba66535914b1fe1313df1c1bb}}
