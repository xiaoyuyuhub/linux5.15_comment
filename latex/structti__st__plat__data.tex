\doxysubsection{Detailed Description}
struct \mbox{\hyperlink{structti__st__plat__data}{ti\+\_\+st\+\_\+plat\+\_\+data}} -\/ platform data shared between ST driver and platform specific board file which adds the ST device. @nshutdown\+\_\+gpio\+: Host\textquotesingle{}s G\+P\+IO line to which chip\textquotesingle{}s B\+T\+\_\+\+EN is connected. @dev\+\_\+name\+: \mbox{\hyperlink{classThe}{The}} U\+A\+R\+T/\+T\+TY name to which chip is interfaced. (eg\+: /dev/tty\+S1) @flow\+\_\+cntrl\+: Should always be 1, since U\+A\+RT\textquotesingle{}s C\+T\+S/\+R\+TS is used for PM purposes. @baud\+\_\+rate\+: \mbox{\hyperlink{classThe}{The}} baud rate supported by the Host U\+A\+RT controller, this will be shared across with the chip via a H\+CI VS command from User-\/\+Space Init Mgr application. @suspend\+: @resume\+: legacy PM routines hooked to platform specific board file, so as to take chip-\/host interface specific action. @chip\+\_\+enable\+: @chip\+\_\+disable\+: Platform/\+Interface specific mux mode setting, G\+P\+IO configuring, Host side PM disabling etc.. can be done here. @chip\+\_\+asleep\+: @chip\+\_\+awake\+: Chip specific deep sleep states is communicated to Host specific board-\/xx.\+c to take actions such as cut U\+A\+RT clocks when chip asleep or run host faster when chip awake etc..
